Отрицательные примеры и вероятности отбора

Два дизайна, две цели​

Сокращение таблицы показов. Есть зрелые наблюдаемые строки с бинарной меткой. Все единицы сохраняются, часть известных нулей случайно удаляется ради стоимости. Можно стремиться восстановить исходный аддитивный риск на этой конечной таблице.

Выбор контрастных объектов. Для позитивного взаимодействия выбираются альтернативы из допустимого каталога. Их реальный исход при показе неизвестен. Такая выборка задаёт обучающую цель сравнения или приближает сумму по объектам; она не создаёт наблюдаемые нули. Pairwise, contrastive и sampled-softmax цели будут подробно введены вместе с моделями.

У этих процедур разные пространства случайности. Вероятность включения строки πj\pi_jπj​ не равна вероятности одного извлечения объекта q(i∣q0)q(i\mid q_0)q(i∣q0​) с возвращением. Обозначим запрос как q0q_0q0​, чтобы не путать его с распределением выборки.

Восстановление аддитивного риска​

Пусть исходная таблица имеет известный размер NNN, потери ℓj\ell_jℓj​ фиксированы для рассматриваемой модели. Строка jjj включается с известной вероятностью πj>0\pi_j>0πj​>0, индикатор включения SjS_jSj​. Для единиц πj=1\pi_j=1πj​=1, для нулей в нашем примере πj=ρ=1/4\pi_j=\rho=1/4πj​=ρ=1/4.

Теорема · Взвешенная сумма#

Оценка R^=1N∑jSjℓj/πj\widehat R=\frac1N\sum_j S_j\ell_j/\pi_jR=N1​∑j​Sj​ℓj​/πj​ имеет ожидание 1N∑jℓj\frac1N\sum_j\ell_jN1​∑j​ℓj​ по дизайну отбора. Независимость индикаторов для этого равенства не требуется. Для независимых Bernoulli-индикаторов её дисперсия равна N−2∑j(1−πj)ℓj2/πjN^{-2}\sum_j(1-\pi_j)\ell_j^2/\pi_jN−2∑j​(1−πj​)ℓj2​/πj​.

Доказательство

E[Sj]=πj\E[S_j]=\pi_jE[Sj​]=πj​ даёт несмещённость линейностью ожидания. При независимости ковариации обнуляются; Var⁡(Sj)=πj(1−πj)\operatorname{Var}(S_j)=\pi_j(1-\pi_j)Var(Sj​)=πj​(1−πj​), после деления на πj2\pi_j^2πj2​ получается формула дисперсии.

□

Знаменатель здесь исходное NNN, а не случайное число сохранённых строк и не сумма весов. Нормировка по сумме весов даёт другую, обычно смещённую конечновыборочную оценку отношения. Теорема относится к фиксированной модели; оптимизация по той же случайной выборке не делает качество выбранного оптимума несмещённым автоматически. Маленькие вероятности увеличивают разброс.

Эти веса исправляют наш технический отбор строк, а не смещение исторической политики показов. Поправки к exposure требуют других вероятностей и причинных предпосылок.

Как меняется вероятность класса​

Пусть p(x)=Pr⁡(Y=1∣X=x)p(x)=\Pr(Y=1\mid X=x)p(x)=Pr(Y=1∣X=x) в исходных показах; единицы всегда сохраняются, нули независимо сохраняются с постоянной вероятностью ρ\rhoρ. Тогда по формуле Байеса

ps(x)=p(x)p(x)+ρ(1−p(x)),p(x)=ρps(x)1−ps(x)+ρps(x).p_s(x)=\frac{p(x)}{p(x)+\rho(1-p(x))},\qquad p(x)=\frac{\rho p_s(x)}{1-p_s(x)+\rho p_s(x)}.ps​(x)=p(x)+ρ(1−p(x))p(x)​,p(x)=1−ps​(x)+ρps​(x)ρps​(x)​.

Если p=0,1p=0{,}1p=0,1 и ρ=0,25\rho=0{,}25ρ=0,25, после отбора ps=4/13≈0,308p_s=4/13\approx0{,}308ps​=4/13≈0,308, а не 0,1. При вероятностях строго между нулём и единицей logit⁡p=logit⁡ps+log⁡ρ\operatorname{logit}p=\operatorname{logit}p_s+\log\rhologitp=logitps​+logρ. Обратное преобразование верно для корректно оценённого распределения отбора; оно не обещает калибровку произвольной ошибочной модели. Если отбор зависит от xxx, нужна соответствующая ρ(x)\rho(x)ρ(x).

Выбор объектов с возвращением​

Пусть B=Aq0∖{i+}\mathcal B=\mathcal A_{q_0}\setminus\{i^+\}B=Aq0​​∖{i+} — выбранная область контрастных объектов. При J1,…,Jm∼q(⋅∣q0)J_1,\ldots,J_m\sim q(\cdot\mid q_0)J1​,…,Jm​∼q(⋅∣q0​) независимо с возвращением и положительной вероятности на всей области

для фиксированного аддитивного ggg. Это непосредственно следует из суммы ∑iq(i)g(i)/q(i)\sum_i q(i)g(i)/q(i)∑i​q(i)g(i)/q(i). Повторные извлечения сохраняются: удаление дублей меняет дизайн. При mmm извлечениях вероятность хотя бы одного включения объекта равна 1−(1−q(i))m1-(1-q(i))^m1−(1−q(i))m; она отличается от q(i)q(i)q(i).

Не следует переносить эту несмещённость суммы на нелинейный логарифм нормировочной суммы softmax или на top-K метрику. Ожидание нелинейной функции обычно не равно функции ожидания. Hard negatives меняют распределение и могут иметь нулевую поддержку на остальной области; перед применением весов нужно определить цель и фактические вероятности. In-batch объекты наследуют распределение batch, а не становятся равномерными по каталогу.

Откуда берётся распределение объектов​

Равномерный отбор даёт одинаковую вероятность всем объектам допустимой области. Популярностный может задаваться как q(i)∝(ci+ε)γq(i)\propto(c_i+\varepsilon)^\gammaq(i)∝(ci​+ε)γ, где cic_ici​ — разрешённый исторический счётчик, ε>0\varepsilon>0ε>0, а γ\gammaγ фиксируется при разработке. Счётчик по всему будущему журналу нарушает этот временной контракт. Смесь равномерного и трудного отбора может сохранять положительную поддержку, но её фактическая вероятность должна учитывать обе компоненты.

Hard mining использует модель или индекс для поиска похожих альтернатив. Версия этой модели тоже должна быть обучена на разрешённых данных. Если выбирается детерминированный top-K, у остальных объектов вероятность отбора нулевая; вес 1/q1/q1/q не восстанавливает сумму по всему каталогу. Если точная вероятность сложного sampler неизвестна, нельзя объявлять числовой вес корректной importance-поправкой.

Контрастный объект может оказаться подходящим пользователю: это называют ложным отрицательным примером относительно скрытой релевантности. Удаление текущего позитивного ID устраняет тривиальное противоречие с целью, но не решает эту неопределённость. Несколько известных позитивных объектов целевого запроса можно учитывать в определении обучающей цели. Однако фильтровать альтернативы по позитивам будущих тестовых запросов, скрытым от данного обучения, нельзя: это новый канал информации из теста. Наличие у пользователя будущего взаимодействия не даёт разрешения использовать его при построении прошлого sampler.

Код​

sampling.py
"""Разные вероятности для разных дизайнов выборки; цели не взаимозаменяемы."""
import math
import random


def retain_rows(rows, negative_keep, seed=17):
    if not 0 < negative_keep <= 1:
        raise ValueError("Нужна положительная вероятность включения")
    rng = random.Random(seed)
    selected = []
    for row in sorted(rows, key=lambda r: r["id"]):
        if row["y"] not in (0, 1):
            raise ValueError("Требуется известная бинарная метка")
        inclusion = 1.0 if row["y"] == 1 else negative_keep
        if inclusion == 1 or rng.random() < inclusion:
            selected.append(dict(row, inclusion=inclusion, weight=1/inclusion))
    return selected


def population_probability(sampled_p, negative_keep):
    if not 0 <= sampled_p <= 1 or not 0 < negative_keep <= 1:
        raise ValueError("Неверная вероятность")
    return negative_keep*sampled_p/(1-sampled_p+negative_keep*sampled_p)


def ht_mean(selected, population_size, loss):
    if population_size <= 0:
        raise ValueError("Нужен известный размер исходной таблицы")
    return math.fsum(loss(row)/row["inclusion"] for row in selected)/population_size


def sample_items(pool, positive, weights, draws, seed=17):
    # С возвращением. q — вероятность одного извлечения, не включения строки.
    if draws <= 0 or len(pool) != len(set(pool)) or len(pool) != len(weights):
        raise ValueError("Неверная область или число извлечений")
    choices = [(item, w) for item, w in zip(pool, weights) if item != positive]
    if not choices or any(not math.isfinite(w) or w <= 0 for _, w in choices):
        raise ValueError("Нужна непустая область с положительными весами")
    total = math.fsum(w for _, w in choices)
    items, mass = zip(*choices)
    q = dict((item, w/total) for item, w in choices)
    sampled = random.Random(seed).choices(items, weights=mass, k=draws)
    return [dict(item=item, q=q[item]) for item in sampled]

retain_rows сортирует ключи и использует отдельный PRNG. Сохраняются inclusion и weight. sample_items сначала удаляет текущий позитивный объект из уже допустимого каталога, затем нормирует положительные веса и делает извлечения с возвращением. Другие ранее потреблённые объекты остаются по контракту этого примера.

Стабильный seed воспроизводит результат при одинаковых входах и реализации генератора. Он не задаёт вероятности вместо описания алгоритма. При изменении входного множества возможны другие извлечения; для независимого аудита сохраняем и область, и полученные ID.

Упражнение · Точный перебор

Есть потери 1, 4, 9. Первая строка всегда сохраняется, остальные независимо с вероятностью 1/21/21/2. Выпишите четыре взвешенные оценки среднего и проверьте их среднее.

Разбор

Оценки равны 1/31/31/3, 9/39/39/3, 19/319/319/3, 27/327/327/3; каждая имеет вероятность 1/41/41/4. Их среднее 14/314/314/3 совпадает с (1+4+9)/3(1+4+9)/3(1+4+9)/3. Отдельная оценка может быть больше истинного среднего; несмещённость относится к повторениям дизайна.

Упражнение · Извлечение и включение

При q(i)=1/4q(i)=1/4q(i)=1/4 сделаны два независимых извлечения. Чему равна вероятность включения объекта хотя бы раз? Почему нельзя молча использовать 1/41/41/4 как inclusion probability после удаления дублей?

Разбор

Вероятность 1−(3/4)2=7/161-(3/4)^2=7/161−(3/4)2=7/16. После удаления дублей строка появляется с этой вероятностью. Вес для оценки суммы по уникальным включённым объектам должен соответствовать этому дизайну; формула с qqq относилась к списку извлечений с кратностями.
