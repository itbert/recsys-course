От истории к линейной реконструкции

Что получает модель​

Зафиксируем снимок в момент TTT и словарь из mmm объектов. В X∈Rn×mX\in\R^{n\times m}X∈Rn×m строки соответствуют nnn обучающим профилям, столбцы — объектам. Для бинарного входа Xui=1X_{ui}=1Xui​=1, если до TTT зарегистрировано хотя бы одно допустимое событие пользователя uuu по объекту iii. Ноль означает отсутствие такого события в снимке. Его семантику задаёт контракт событий. Например, отсутствие показа и показ без клика могут дать одинаковый ноль.

Определение · Линейная модель по объектам#

Матрица B∈Rm×mB\in\R^{m\times m}B∈Rm×m задаёт оценки x^=xB\hat{x}=xBx^=xB для строки x∈R1×mx\in\R^{1\times m}x∈R1×m. Вес BijB_{ij}Bij​ умножает значение входного объекта iii при вычислении оценки целевого объекта jjj.

x^j=∑i:xi≠0xiBij,B:j∈Rm.\hat x_j=\sum_{i:x_i\ne 0} x_i B_{ij}, \qquad B_{:j}\in\R^m.x^j​=i:xi​=0∑​xi​Bij​,B:j​∈Rm.

При бинарном профиле достаточно сложить строки BBB соответствующих объектов. Например, пусть x=(1,0,1)x=(1,0,1)x=(1,0,1), B12=−1/8B_{12}=-1/8B12​=−1/8 и B32=3/8B_{32}=3/8B32​=3/8. Тогда оценка второго объекта равна 1/41/41/4. Если в истории есть только первый, его вклад для второго равен −1/8-1/8−1/8.

Простейший вариант обучения минимизирует квадрат ошибки реконструкции ∥X−XB∥F2\|X-XB\|_F^2∥X−XB∥F2​. Норма Фробениуса в квадрате суммирует квадраты по всем ячейкам. При этой цели модель штрафуется и за расхождения на нулях. Она учится предсказывать представление журнала, поэтому оценкам нужна отдельная проверка на будущих событиях. Для явных рейтингов из части 9 ошибка по маске наблюдений задаёт другую задачу.

Диагональ и масштаб​

Лемма · Копирование входа#

При отсутствии штрафа и ограничений B=ImB=I_mB=Im​ глобально минимизирует ошибку реконструкции. Для такого решения все объекты с xj=0x_j=0xj​=0 получают оценку 0.

Доказательство

Подстановка даёт XIm=XXI_m=XXIm​=X, а сумма квадратов неотрицательна. При прогнозе xIm=xxI_m=xxIm​=x, откуда следует вторая часть.

□

Чтобы предсказывать координату через другие объекты, можно наложить diag⁡(B)=0\operatorname{diag}(B)=0diag(B)=0. Тогда при фиксированном jjj получаем регрессию X:jX_{:j}X:j​ на остальные столбцы. Сумма потерь по jjj связывает в одной записи независимые регрессии. Штрафы, разделимые по столбцам, сохраняют эту независимость.

На обучении и в запросах нужно согласовать представление профиля. Если для всех входов заменить XXX на aXaXaX, то квадрат ошибки умножится на a2a^2a2. Чтобы сохранить ту же задачу для BBB, коэффициенты штрафа тоже умножаются на a2a^2a2. Если вместо бинарного входа использовать счётчики, веса ошибок меняются неодинаково. Такой переход проверяют на новом временном срезе с одинаковым преобразованием истории при обучении и в запросах.

Сопоставление с соседскими методами​

В item-kNN при аддитивном правиле BijB_{ij}Bij​ можно заполнить весом соседства от iii к jjj. SLIM и EASE подбирают коэффициенты совместно для каждого jjj. В результате вес BijB_{ij}Bij​ зависит и от доступности других признаков, которые объясняют тот же столбец. Пригодность линейной формы для выдачи проверяется фиксированными кандидатами и метриками ранжирования.

Упражнение · Дублирующиеся объекты

Пусть X:1=X:2≠0X_{:1}=X_{:2}\ne0X:1​=X:2​=0. Может ли каждый из этих столбцов быть реконструирован без ошибки при нулевой диагонали?

Разбор

Да. Достаточно положить B12=B21=1B_{12}=B_{21}=1B12​=B21​=1 и обнулить остальные входы для двух целей. Поэтому нулевая диагональ убирает прямое копирование, а коррелированные столбцы по-прежнему могут передавать почти тот же сигнал. Величина ошибки на новых запросах зависит от того, сохраняется ли связь вне обучения.
