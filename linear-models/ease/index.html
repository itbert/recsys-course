EASE и закрытое решение ridge

От отдельных регрессий к одной системе​

В EASE сохраняется запрет на диагональ, веса могут иметь любой знак. Введём G=X⊤XG=X^\top XG=X⊤X и A=G+λImA=G+\lambda I_mA=G+λIm​, где λ>0\lambda>0λ>0. Для каждой цели jjj в регрессии на остальных объектах условия стационарности имеют вид

A−j,−j B−j,j=G−j,j.A_{-j,-j}\, B_{-j,j}=G_{-j,j}.A−j,−j​B−j,j​=G−j,j​.

Если решать эти mmm систем отдельно плотным разложением, каждая использует свою главную подматрицу. EASE получает все столбцы из одного решения с AAA. Steck, 2019, уравнения 1–4.

Теорема · Решение EASE#

Для A=G+λImA=G+\lambda I_mA=G+λIm​ и P=A−1P=A^{-1}P=A−1 задача

min⁡diag⁡(B)=0(∥X−XB∥F2+λ∥B∥F2)\min_{\operatorname{diag}(B)=0} \bigl(\|X-XB\|_F^2+\lambda\|B\|_F^2\bigr)diag(B)=0min​(∥X−XB∥F2​+λ∥B∥F2​)

имеет единственное решение Bjj=0B_{jj}=0Bjj​=0 и Bij=−Pij/PjjB_{ij}=-P_{ij}/P_{jj}Bij​=−Pij​/Pjj​ при i≠ji\ne ji=j. Если штраф заменить на ∑iλi∥Bi:∥22\sum_i \lambda_i\|B_{i:}\|_2^2∑i​λi​∥Bi:​∥22​ при λi>0\lambda_i>0λi​>0, формула сохраняется с A=G+diag⁡(λ1,…,λm)A=G+\operatorname{diag}(\lambda_1,\ldots,\lambda_m)A=G+diag(λ1​,…,λm​).

Для любого v≠0v\ne0v=0 выполнено v⊤Av=∥Xv∥22+λ∥v∥22>0v^\top A v=\|Xv\|_2^2+\lambda\|v\|_2^2>0v⊤Av=∥Xv∥22​+λ∥v∥22​>0. Обозначим через eje_jej​ единичный вектор координаты jjj. Половина цели на столбце bjb_jbj​ с точностью до константы равна 12bj⊤Abj−bj⊤Gej\tfrac12 b_j^\top A b_j - b_j^\top G e_j21​bj⊤​Abj​−bj⊤​Gej​. Ограничение есть ej⊤bj=0e_j^\top b_j=0ej⊤​bj​=0. При множителе Лагранжа νj\nu_jνj​ стационарность даёт

Abj=Gej−νjej=Aej−(λ+νj)ej.A b_j = G e_j-\nu_j e_j = A e_j - (\lambda + \nu_j)e_j .Abj​=Gej​−νj​ej​=Aej​−(λ+νj​)ej​.

Умножение слева на PPP даёт bj=ej−(λ+νj)Pejb_j=e_j-(\lambda+\nu_j)P e_jbj​=ej​−(λ+νj​)Pej​. Условие ej⊤bj=0e_j^\top b_j=0ej⊤​bj​=0 означает λ+νj=1/Pjj\lambda+\nu_j=1/P_{jj}λ+νj​=1/Pjj​. Число PjjP_{jj}Pjj​ положительно, поскольку PPP положительно определена. Подстановка даёт нужный столбец. Строгая выпуклость обеспечивает единственность и достаточность условий. При диагональном штрафе в этом выводе λ\lambdaλ заменяется на λj\lambda_jλj​, а положительная определённость остаётся.

Реализация и проверка​

ease.py
"""Закрытое решение с нулевой диагональю и диагональным штрафом."""

import numpy as np
from scipy.linalg import cho_factor, cho_solve
from scipy.sparse import issparse


def gram_matrix(x):
    """Вернуть плотную матрицу Грама объектов."""
    if issparse(x):
        x = x.astype(float, copy=False)
        return (x.T @ x).toarray()
    x = np.asarray(x, dtype=float)
    return x.T @ x


def ridge_system(gram, penalty):
    gram = np.asarray(gram, dtype=float)
    if gram.ndim != 2 or gram.shape[0] != gram.shape[1]:
        raise ValueError("expected a square item Gram matrix")
    diagonal = np.broadcast_to(np.asarray(penalty, dtype=float), gram.shape[0])
    if not np.isfinite(diagonal).all() or np.any(diagonal <= 0):
        raise ValueError("penalty must be finite and strictly positive")
    system = gram.copy()
    system[np.diag_indices_from(system)] += diagonal
    return system


def ease_weights(gram, penalty):
    system = ridge_system(gram, penalty)
    factor = cho_factor(system, lower=True)
    precision = cho_solve(factor, np.eye(len(system)))
    weights = -precision / precision.diagonal()[None, :]
    np.fill_diagonal(weights, 0)
    return weights


def dropout_penalty(gram, dropout, ridge=0):
    """Ожидаемый штраф от инвертированного dropout и добавка ridge."""
    if not 0 <= dropout < 1 or not np.isfinite(ridge) or ridge < 0:
        raise ValueError("expected 0 <= dropout < 1 and finite ridge >= 0")
    return dropout / (1 - dropout) * np.diag(gram) + ridge

gram_matrix принимает плотный или разреженный вход. ridge_system добавляет один скаляр или отдельное число для каждой строки весов. cho_factor вычисляет треугольный фактор положительно определённой системы. cho_solve решает AP=ImAP=I_mAP=Im​ с этим фактором. Это способ вычислить все элементы PPP через линейные системы. Нормирование precision.diagonal()[None, :] делит каждый столбец на его собственный диагональный элемент. dropout_penalty понадобится в главе о зашумлении.

Для независимой проверки на малых входах решите mmm систем A−j,−jb=G−j,jA_{-j,-j}b=G_{-j,j}A−j,−j​b=G−j,j​ напрямую. Сверьте значения и невязки A−j,−jB−j,j−G−j,jA_{-j,-j}B_{-j,j}-G_{-j,j}A−j,−j​B−j,j​−G−j,j​ и отдельно проверьте диагональ. Тест на симметричных по популярности признаках может пропустить деление по неверной оси, поэтому полезен пример с различными значениями PjjP_{jj}Pjj​.
