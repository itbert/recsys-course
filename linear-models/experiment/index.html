Воспроизводимое сравнение линейных моделей

Протокол​

Повторяем неявную задачу части 9. Синтетический генератор строит события и позднюю релевантность на общей латентной геометрии. Модели не видят её параметры. В срез T=100T=100T=100 входит 2016 доступных событий. После бинаризации остаётся 1417 уникальных пар. Обучающий словарь содержит 40 объектов. На запросе к ним добавляются четыре новых ID. Всего 136 запросов, из них 112 с историей и 24 без неё.

Кандидаты одинаковы для всех методов. Из каталога исключены уже наблюдавшиеся объекты, двум отложенным позитивам назначены степени 2 и 1. Результаты популярности, item-kNN, WALS и BPR пересчитываются кодом части 9. WALS получает счётчики событий по своей постановке. Новые операторы получают один и тот же бинарный вход. Ранг 6, λ1=2\lambda_1=2λ1​=2, λ2=8\lambda_2=8λ2​=8 и p=0,2p=0{,}2p=0,2 фиксируются до расчёта. Для EASE и ridge-аппроксимации штраф равен 8I8I8I, для двух вариантов EDLAE — 8I+14diag⁡(G11,…,Gmm)8I+\tfrac14\operatorname{diag}(G_{11},\ldots,G_{mm})8I+41​diag(G11​,…,Gmm​).

На этом срезе BPR лидирует по NDCG@5, а низкоранговый ridge — по Recall@5. EASE опережает сжатый EDLAE по обеим метрикам. Сравнение EASE со сжатым EDLAE меняет сразу два фактора, штраф и ранг. При фиксированном штрафе пара EDLAE с ограничением и без ограничения ранга показывает результат сжатия именно для выбранного f=6f=6f=6. Для общего вывода нужен подбор на внутренних временных срезах и отдельная итоговая проверка.

У всех методов NDCG@5 на запросах без истории равен 0.141 из-за общего резерва по популярности. Четыре новых объекта не получили ни одной позиции в top-5. По выбранному правилу у каждого запроса хватило ранее наблюдавшихся в обучении кандидатов. Это свойство политики, поэтому по таблице нельзя оценить способность моделей рекомендовать новые объекты после расширения retrieval.

Диагностика обучения​

SLIM оставил ненулевыми 34.3% внедиагональных весов. Наибольшая KKT-невязка по целям равна 9.89e-8 при пороге 10−710^{-7}10−7. Самая долгая регрессия потребовала 60 проходов. У EASE отрицательны 38.3% внедиагональных весов. Эти проценты относятся к одному набору событий и выбранным штрафам. Невязка характеризует точность решения обучающей задачи SLIM. Для качества выдачи используются будущие события.

Запустить самостоятельно​

linear_lab.py
"""Сравнение на неизменном синтетическом временном срезе части 9."""

from collections import defaultdict
import hashlib
import json
import math
from pathlib import Path
import platform

import numpy as np
import scipy
from scipy.sparse import csr_matrix

from baselines import popularity, snapshot
from associations import profiles
from experiment import K, OLD_ITEMS, ORIGIN, SEED, USERS, evaluate_ranking, fixture, rank_factor_scores
from ranking import ranking_metrics

from ease import dropout_penalty, ease_weights, gram_matrix
from low_rank import compress_teacher, low_rank_ridge, score
from slim import fit_slim

L1, L2 = 2., 8.
DROPOUT, RANK = .2, 6


def run():
    events, _, _, _, requests = fixture()
    observed = snapshot(events, ORIGIN)
    history, popular = profiles(observed), popularity(observed)
    pairs = [(u, i) for u, items in history.items() for i in sorted(items)]
    users, items = zip(*pairs)
    x = csr_matrix((np.ones(len(pairs)), (users, items)), shape=(USERS, OLD_ITEMS))
    gram = gram_matrix(x)

    slim, diagnostics = fit_slim(x, L1, L2)
    ease = ease_weights(gram, L2)
    penalty = dropout_penalty(gram, DROPOUT, ridge=L2)
    edlae = ease_weights(gram, penalty)
    ridge_factors = low_rank_ridge(gram, L2, RANK)
    edlae_factors = compress_teacher(gram, penalty, edlae, RANK)
    models = {
        "slim": (x @ slim).toarray(),
        "ease": x @ ease,
        "edlae_full": x @ edlae,
        "ridge_rank": score(x, *ridge_factors),
        "edlae_rank": score(x, *edlae_factors),
    }

    stats = defaultdict(list)
    for u, _, candidates, grades in requests:
        seen = bool(history.get(u))
        for name, scores in models.items():
            learned = {i: float(scores[u, i]) for i in candidates if i in popular} if seen else {}
            order = rank_factor_scores(candidates, learned, popular)
            m = ranking_metrics(order, grades, K)
            stats[name].append((seen, m["ndcg"], m["recall"], sum(i >= OLD_ITEMS for i in order)))

    results, _, _ = evaluate_ranking(events, requests)
    for name, values in stats.items():
        warm = [ndcg for seen, ndcg, _, _ in values if seen]
        cold = [ndcg for seen, ndcg, _, _ in values if not seen]
        results[name] = {
            "ndcg": math.fsum(v for _, v, _, _ in values) / len(values),
            "recall": math.fsum(r for _, _, r, _ in values) / len(values),
            "warm_ndcg": math.fsum(warm) / len(warm),
            "cold_ndcg": math.fsum(cold) / len(cold),
            "cold_slots": sum(n for _, _, _, n in values),
        }

    off_diagonal = OLD_ITEMS * (OLD_ITEMS - 1)
    root = Path(__file__).parent
    return {
        "manifest": {
            "python": platform.python_version(), "numpy": np.__version__, "scipy": scipy.__version__,
            "seed": SEED, "cutoff": ORIGIN, "k": K,
            "parameters": {"l1": L1, "l2": L2, "dropout": DROPOUT, "rank": RANK},
            "source_sha256": {
                name: hashlib.sha256((root / name).read_bytes()).hexdigest()
                for name in ("slim.py", "ease.py", "low_rank.py", "linear_lab.py")
            },
            "data_sha256": hashlib.sha256(json.dumps([
                [[e.user, e.item, e.t, e.available] for e in events], requests
            ], sort_keys=True).encode()).hexdigest(),
        },
        "sizes": {
            "events": len(observed), "binary_interactions": x.nnz,
            "warm_requests": len(history), "cold_requests": USERS - len(history),
            "training_items": OLD_ITEMS, "eligible_items": max(max(row[2]) for row in requests) + 1,
        },
        "weights": {
            "slim_density": slim.nnz / off_diagonal,
            "slim_max_kkt": max(error for _, error in diagnostics),
            "slim_max_sweeps": max(sweeps for sweeps, _ in diagnostics),
            "ease_negative": np.count_nonzero(ease < 0) / off_diagonal,
            "edlae_negative": np.count_nonzero(edlae < 0) / off_diagonal,
        },
        "ranking": results,
    }


if __name__ == "__main__":
    report = run()
    serialized = json.dumps(report, ensure_ascii=False, indent=2, allow_nan=False) + "\n"
    Path(__file__).with_name("report.json").write_text(serialized)
    print(serialized, end="")

В run бинарная CSR-матрица строится по множествам profiles из доступных событий. Пары с повтором уже объединены, поэтому каждой присваивается единица. После обучения models хранит плотные массивы оценок всего учебного среза. В реальной системе обычно считают строки на запросах либо малых пакетах. rank_factor_scores разрешает ничьи и применяет резерв к целям без оценки. Допустимость задана списком candidates, поэтому копирующие диагональные члены низкоранговых моделей не попадают в проверяемые оценки.

Сохраните linear_lab.py, slim.py, ease.py и low_rank.py рядом. Из части 9 нужны experiment.py, explicit.py, implicit.py, pairwise.py, probability.py и их зависимости из частей 7 и 8, перечисленные рядом с кодом эксперимента. Из корня репозитория запустите команду ниже. Проверенная среда — Python 3.13.3, NumPy 2.5.5 и SciPy 1.18.1. Запуск записывает report.json с хешами входа и исходников части 10.
