Зашумление и диагональный штраф

Линейный denoising autoencoder (DLAE) предсказывает чистую строку xxx по зашумлённой x~\tilde xx~. Пусть DuiD_{ui}Dui​ — независимые бернуллиевские индикаторы сохранения с вероятностью 1−p1-p1−p, 0≤p<10\le p<10≤p<1. Положим X~ui=XuiDui/(1−p)\tilde X_{ui}=X_{ui}D_{ui}/(1-p)X~ui​=Xui​Dui​/(1−p). Множитель 1/(1−p)1/(1-p)1/(1−p) сохраняет условное среднее входа. Обучающий снимок XXX считаем фиксированным, ожидание берём только по маскам. Steck, 2020.

Ошибка только при скрытой целевой координате​

В DLAE часть потери измеряется, когда значение целевого объекта присутствует во входе. При 0<p<10<p<10<p<1 можно вместо этого для каждой цели jjj условиться на событии Duj=0D_{uj}=0Duj​=0 и затем усреднить по остальным маскам. В статье этот вариант обозначен EDLAE. Определим M(B)=B−diag⁡(B11,…,Bmm)M(B)=B-\operatorname{diag}(B_{11},\ldots,B_{mm})M(B)=B−diag(B11​,…,Bmm​).
