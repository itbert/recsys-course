Информация, функции потерь и устойчивые вычисления

Вероятностные модели часто обучаются через отрицательный логарифм вероятности наблюдений. Такая запись связана с информационными величинами, но её математическая эквивалентность не гарантирует численной устойчивости прямой реализации.

Энтропия и перекрёстная энтропия​

Рассмотрим конечное множество категорий и распределения p,qp,qp,q. Все логарифмы натуральные; единица информации — нат. Используем соглашение 0log⁡0=00\log0=00log0=0.

H(p)=−∑ipilog⁡pi,H(p,q)=−∑ipilog⁡qi.H(p)=-\sum_i p_i\log p_i, \qquad H(p,q)=-\sum_i p_i\log q_i.H(p)=−i∑​pi​logpi​,H(p,q)=−i∑​pi​logqi​.

Первая величина — энтропия распределения ppp, вторая — cross-entropy при оценке событий из ppp распределением qqq. При pi>0,qi=0p_i>0,q_i=0pi​>0,qi​=0 cross-entropy бесконечна. Дивергенция Кульбака—Лейблера задаётся как

DKL(p∥q)=∑i:pi>0pilog⁡piqi.D_{\mathrm{KL}}(p\Vert q)=\sum_{i:p_i>0}p_i\log\frac{p_i}{q_i}.DKL​(p∥q)=i:pi​>0∑​pi​logqi​pi​​.

Если qqq положительно на носителе ppp, то H(p,q)=H(p)+DKL(p∥q)H(p,q)=H(p)+D_{\mathrm{KL}}(p\Vert q)H(p,q)=H(p)+DKL​(p∥q). KL не является метрикой: в частности, порядок аргументов существенен.

Теорема · Неотрицательность KL#

Для конечных распределений p,qp,qp,q выполняется DKL(p∥q)≥0D_{\mathrm{KL}}(p\Vert q)\ge0DKL​(p∥q)≥0. Равенство достигается тогда и только тогда, когда p=qp=qp=q.

Доказательство

Если qi=0q_i=0qi​=0 при pi>0p_i>0pi​>0, результат следует из бесконечного значения. Иначе используем −log⁡z≥1−z-\log z\ge1-z−logz≥1−z для z>0z>0z>0, с равенством только при z=1z=1z=1. Суммирование по носителю ppp даёт

DKL(p∥q)≥∑i:pi>0(pi−qi)=1−∑i:pi>0qi≥0.D_{\mathrm{KL}}(p\Vert q) \ge\sum_{i:p_i>0}(p_i-q_i) =1-\sum_{i:p_i>0}q_i\ge0.DKL​(p∥q)≥i:pi​>0∑​(pi​−qi​)=1−i:pi​>0∑​qi​≥0.

Для равенства необходимо qi=piq_i=p_iqi​=pi​ на носителе ppp и отсутствие оставшейся массы qqq за его пределами; этого также достаточно.

□

Отсюда для mmm категорий H(p)≤log⁡mH(p)\le\log mH(p)≤logm: подставим равномерное qi=1/mq_i=1/mqi​=1/m. Максимум достигается на равномерном распределении. Условная энтропия усредняет энтропию условных распределений, а взаимная информация I(X;Y)=DKL(pXY∥pXpY)I(X;Y)=D_{\mathrm{KL}}(p_{XY}\Vert p_Xp_Y)I(X;Y)=DKL​(pXY​∥pX​pY​) неотрицательна и равна нулю при независимости. Эти дискретные формулы не переносятся без изменений на дифференциальную энтропию непрерывных величин.

Категориальная модель и softmax​

Для конечных логитов z1,…,zmz_1,\ldots,z_mz1​,…,zm​ определим

qi=ezi∑jezj.q_i=\frac{e^{z_i}}{\sum_j e^{z_j}}.qi​=∑j​ezj​ezi​​.

Это распределение на одной выбранной категории. Отрицательный логарифм вероятности метки yyy равен −log⁡qy-\log q_y−logqy​. Независимые бинарные действия по нескольким объектам не становятся таким категориальным выбором автоматически: у них может быть несколько положительных исходов.

Общий сдвиг логитов не меняет softmax: множитель eae^aea сокращается в числителе и знаменателе. Поэтому вычисление нормировки можно переписать как

LSE⁡(z)=a+log⁡∑jezj−a,a=max⁡jzj.\operatorname{LSE}(\vect{z}) =a+\log\sum_j e^{z_j-a},\qquad a=\max_j z_j.LSE(z)=a+logj∑​ezj​−a,a=jmax​zj​.

Аргументы экспоненты теперь неположительны. Для логарифмов вероятностей особенно удобно сразу вычислять log_softmax через сдвинутые логиты, не создавая предварительно очень маленькие вероятности.

При логитах [1000, 1001, 999] нормировка в логарифмической форме равна примерно 1001,407606, а вероятности — [0.244728, 0.665241, 0.090031]. Прямая экспонента этих исходных логитов переполняет обычный float64.

Бинарная модель и устойчивая потеря​

Для бинарной метки yyy и логита zzz сигмоида равна σ(z)=1/(1+e−z)\sigma(z)=1/(1+e^{-z})σ(z)=1/(1+e−z). Бинарная cross-entropy имеет эквивалентные записи

ℓ(z,y)=−ylog⁡σ(z)−(1−y)log⁡(1−σ(z))\ell(z,y)=-y\log\sigma(z)-(1-y)\log(1-\sigma(z))ℓ(z,y)=−ylogσ(z)−(1−y)log(1−σ(z)) =log⁡(1+ez)−yz=max⁡(z,0)−yz+log⁡(1+e−∣z∣).=\log(1+e^z)-yz =\max(z,0)-yz+\log(1+e^{-|z|}).=log(1+ez)−yz=max(z,0)−yz+log(1+e−∣z∣).

Вторая строка получается подстановкой сигмоиды; последняя — вынесением eze^zez при z>0z>0z>0. Она позволяет вычислять потерю непосредственно по логиту. При ошибочном уверенном прогнозе z=1000,y=0z=1000,y=0z=1000,y=0 потеря около 1000, а не неопределённое выражение из округлённой до единицы вероятности.

Для самой сигмоиды используются две ветви: при z≥0z\ge0z≥0 исходная запись, при z<0z<0z<0 — ez/(1+ez)e^z/(1+e^z)ez/(1+ez). np.where с двумя уже вычисленными экспонентами не устранило бы переполнение, поскольку обе ветви были бы вычислены до выбора.

Проверяемая реализация​

numerics.py
"""Устойчивые вычисления для конечных вещественных логитов."""
import numpy as np


def logsumexp(values):
    values = np.asarray(values, dtype=np.float64)
    if values.ndim != 1 or values.size == 0 or not np.isfinite(values).all():
        raise ValueError("Нужен непустой конечный вектор")
    maximum = values.max()
    return maximum + np.log(np.exp(values - maximum).sum())


def log_softmax(values):
    values = np.asarray(values, dtype=np.float64)
    if values.ndim != 1 or values.size == 0 or not np.isfinite(values).all():
        raise ValueError("Нужен непустой конечный вектор")
    shifted = values - values.max()
    return shifted - np.log(np.exp(shifted).sum())


def sigmoid(values):
    values = np.asarray(values, dtype=np.float64)
    result = np.empty_like(values)
    positive = values >= 0
    result[positive] = 1.0 / (1.0 + np.exp(-values[positive]))
    exp_value = np.exp(values[~positive])
    result[~positive] = exp_value / (1.0 + exp_value)
    return result


def binary_loss(logits, targets):
    logits = np.asarray(logits, dtype=np.float64)
    targets = np.asarray(targets, dtype=np.float64)
    if logits.shape != targets.shape:
        raise ValueError("Формы логитов и меток должны совпадать")
    if not np.isfinite(logits).all() or not np.isin(targets, [0.0, 1.0]).all():
        raise ValueError("Нужны конечные логиты и бинарные метки")
    return np.maximum(logits, 0) - targets * logits + np.log1p(np.exp(-np.abs(logits)))


if __name__ == "__main__":
    logits = np.array([1000.0, 1001.0, 999.0])
    print("logsumexp:", round(float(logsumexp(logits)), 6))
    print("softmax:", np.round(np.exp(log_softmax(logits)), 6))
    print("extreme sigmoid:", sigmoid(np.array([-1000.0, 0.0, 1000.0])))
    print("binary loss:", binary_loss(np.array([1000.0, -1000.0]), np.array([0.0, 1.0])))

log1p(a) вычисляет log⁡(1+a)\log(1+a)log(1+a) с учётом малых aaa. Сигмоида использует булевы индексы, поэтому экспоненты вычисляются только на нужной части массива. binary_loss требует совпадающих форм, чтобы ошибка broadcasting не изменила критерий. Она возвращает поэлементные потери; способ усреднения задаётся вызывающим кодом.

Программы проверены на логитах порядка ±1000\pm1000±1000. Устойчивая запись уменьшает определённые виды переполнения и потери точности, но не отменяет конечный диапазон числового типа. Даже конечные входы около его предела могут породить непредставимую разность или сумму. При очень малых математических вероятностях вычисленная сигмоида также может округлиться до 0 или 1; поэтому логарифм вероятности предпочтительно вычислять через логит.

Нормировка потери тоже существенна. Среднее по элементам и сумма отличаются множителем; при неизменённом коэффициенте регуляризации это меняет относительный вес штрафа. Функция библиотеки должна использовать то же соглашение, что и математическая запись.

Упражнения​

Упражнение · Сдвиг и распределение#

Изменится ли softmax после прибавления 1000 ко всем логитам? Почему вычислять сначала вероятности, а затем их логарифмы может быть менее устойчиво, чем сразу log_softmax?

Решение

Математическое распределение не изменится. При промежуточном вычислении вероятности некоторые значения могут округлиться до нуля, после чего логарифм даст минус бесконечность. Прямой логарифмический расчёт может сохранить конечное отрицательное значение, если оно представимо выбранным типом.

Упражнение · Интерпретация cross-entropy#

Пусть p=(1/2,1/2)p=(1/2,1/2)p=(1/2,1/2), q=(3/4,1/4)q=(3/4,1/4)q=(3/4,1/4). Выразите H(p)H(p)H(p), H(p,q)H(p,q)H(p,q) и KL. Почему cross-entropy не может быть меньше энтропии при этих условиях?

Решение

H(p)=log⁡2H(p)=\log2H(p)=log2, H(p,q)=−12log⁡(3/16)H(p,q)=-\tfrac12\log(3/16)H(p,q)=−21​log(3/16), KL равна 12log⁡(4/3)>0\tfrac12\log(4/3)>021​log(4/3)>0. Разность cross-entropy и энтропии — неотрицательная KL.
