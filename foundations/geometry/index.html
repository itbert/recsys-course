Геометрия векторов и матричные вычисления

Векторное представление связывает признаки объекта с операциями геометрии. Однако геометрическая близость зависит от определения оценки. Скалярное произведение, косинус и евклидово расстояние могут задавать разные порядки объектов.

Скалярное произведение и нормы​

Для u,v∈Rd\vect{u},\vect{v}\in\R^du,v∈Rd определим

⟨u,v⟩=uTv=∑j=1dujvj,∥u∥2=∑j=1duj2.\inner{\vect{u}}{\vect{v}}=\vect{u}^{\mathsf T}\vect{v} =\sum_{j=1}^d u_jv_j, \qquad \norm{\vect{u}}_2=\sqrt{\sum_{j=1}^d u_j^2}.⟨u,v⟩=uTv=j=1∑d​uj​vj​,∥u∥2​=j=1∑d​uj2​​.

Используются также ∥u∥1=∑j∣uj∣\norm{\vect{u}}_1=\sum_j|u_j|∥u∥1​=∑j​∣uj​∣ и ∥u∥∞=max⁡j∣uj∣\norm{\vect{u}}_\infty=\max_j|u_j|∥u∥∞​=maxj​∣uj​∣. Норма измеряет длину относительно выбранного определения. Метрика d(u,v)=∥u−v∥2d(\vect{u},\vect{v})=\norm{\vect{u}-\vect{v}}_2d(u,v)=∥u−v∥2​ измеряет расстояние между двумя векторами.

Скалярное произведение может быть отрицательным; норма отрицательной быть не может. Само присвоение координатам названий «интерес» и «тема» не доказывает, что эта геометрия соответствует пользовательскому поведению. Такую связь задают построение признаков, обучение и проверка модели.

Теорема · Неравенство Коши—Буняковского#

Для любых u,v∈Rd\vect{u},\vect{v}\in\R^du,v∈Rd выполняется

∣⟨u,v⟩∣≤∥u∥2∥v∥2.|\inner{\vect{u}}{\vect{v}}|\le\norm{\vect{u}}_2\norm{\vect{v}}_2.∣⟨u,v⟩∣≤∥u∥2​∥v∥2​.
Доказательство

При v=0\vect{v}=0v=0 обе части равны нулю. Иначе неотрицательность квадрата нормы даёт для любого a∈Ra\in\Ra∈R

0≤∥u−av∥22=∥u∥22−2a⟨u,v⟩+a2∥v∥22.0\le\norm{\vect{u}-a\vect{v}}_2^2 =\norm{\vect{u}}_2^2-2a\inner{\vect{u}}{\vect{v}}+a^2\norm{\vect{v}}_2^2.0≤∥u−av∥22​=∥u∥22​−2a⟨u,v⟩+a2∥v∥22​.

Подстановка a=⟨u,v⟩/∥v∥22a=\inner{\vect{u}}{\vect{v}}/\norm{\vect{v}}_2^2a=⟨u,v⟩/∥v∥22​ даёт требуемое неравенство после переноса и извлечения квадратного корня.

Косинус и нулевые векторы​

Для ненулевых векторов определим косинусную оценку:

cos⁡(u,v)=⟨u,v⟩∥u∥2∥v∥2∈[−1,1].\operatorname{cos}(\vect{u},\vect{v}) =\frac{\inner{\vect{u}}{\vect{v}}}{\norm{\vect{u}}_2\norm{\vect{v}}_2}\in[-1,1].cos(u,v)=∥u∥2​∥v∥2​⟨u,v⟩​∈[−1,1].

Границы следуют из доказанного неравенства. У нулевого вектора направление не определено; делить на его норму нельзя. Подстановка малого ε\varepsilonε в знаменатель является программным соглашением и изменяет формулу около нуля. Такое соглашение требуется описывать отдельно.

Если все векторы нормированы до единичной нормы, косинус совпадает со скалярным произведением. Для единичных векторов также выполняется

∥u−v∥22=2−2⟨u,v⟩.\norm{\vect{u}-\vect{v}}_2^2=2-2\inner{\vect{u}}{\vect{v}}.∥u−v∥22​=2−2⟨u,v⟩.

Следовательно, максимизация скалярного произведения и минимизация евклидова расстояния в этом случае задают один порядок. Без нормировки равенство имеет дополнительные слагаемые норм и такой вывод в общем случае неверен.

Пример изменения порядка​

Пусть u=(1,1)T\vect{u}=(1,1)^{\mathsf T}u=(1,1)T, vA=(3,0)T\vect{v}_A=(3,0)^{\mathsf T}vA​=(3,0)T, vB=(1,1)T\vect{v}_B=(1,1)^{\mathsf T}vB​=(1,1)T. Скалярные произведения равны 3 и 2, а косинусы — 1/21/\sqrt21/2​ и 1. По первой оценке выше A, по второй — B.

import numpy as np

user = np.array([1.0, 1.0])
items = np.array([[3.0, 0.0], [1.0, 1.0]])
dot = items @ user
cosine = dot / (np.linalg.norm(items, axis=1) * np.linalg.norm(user))

Здесь items.shape == (2, 2), dot.shape == (2,). axis=1 вычисляет норму каждой строки объекта. np.linalg.norm(user) — один скаляр. Поэлементное деление согласовано по форме. В примере все нормы положительны, поэтому дополнительное правило для нулей не требуется.

Пакетное вычисление оценок​

Пусть строки P∈Rb×d\mat{P}\in\R^{b\times d}P∈Rb×d содержат bbb векторов пользователей, а строки Q∈Rm×d\mat{Q}\in\R^{m\times d}Q∈Rm×d — mmm объектов. Матрица всех скалярных произведений равна

S=PQT∈Rb×m,Sui=∑j=1dPujQij.\mat{S}=\mat{P}\mat{Q}^{\mathsf T}\in\R^{b\times m}, \qquad S_{ui}=\sum_{j=1}^d P_{uj}Q_{ij}.S=PQT∈Rb×m,Sui​=j=1∑d​Puj​Qij​.

Для массивов из главы 2.1 результат равен

(123−110).\begin{pmatrix}1&2&3\\-1&1&0\end{pmatrix}.(1−1​21​30​).

Стандартное плотное вычисление требует O(bmd)O(bmd)O(bmd) арифметических операций; сохранение всех оценок — bmbmbm чисел. Векторизация уменьшает накладные расходы интерпретатора и позволяет использовать численные библиотеки, но не устраняет размер результата. Поэтому вычисление полного произведения по большому каталогу может быть неприемлемым даже при компактных представлениях.

Когда нужны только заданные пары, правильна другая операция. При P_batch.shape == Q_batch.shape == (b, d) выражение (P_batch * Q_batch).sum(axis=1) возвращает bbb парных оценок. P_batch @ Q_batch.T вернуло бы b2b^2b2 сочетаний.

Упражнения​

Упражнение · Косинус и масштаб#

Как изменятся скалярное произведение и косинус при замене ненулевого объекта v\vect{v}v на 5v5\vect{v}5v? Что изменится при множителе −1?

Решение

При положительном множителе 5 скалярное произведение увеличится в пять раз, косинус сохранится. При множителе −1 скалярное произведение и косинус изменят знак: направление противоположно исходному.

Упражнение · Цена полного скоринга#

Сколько памяти требуют только оценки для b=1000b=1000b=1000 пользователей и m=106m=10^6m=106 объектов в float32? Какова форма результата, если оцениваются лишь 100010001000 заранее заданных пар?

Решение

Полный результат содержит 10910^9109 чисел, то есть 444 GB в десятичных единицах. Для заданных пар форма (1000,), объём самих чисел — 4000 байт. Это разные вычислительные задачи, а не два способа записи одного результата.
