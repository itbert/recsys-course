Обозначения, массивы и среда исполнения

Математическая формула определяет объекты и операции; программа дополнительно задаёт форму хранения, тип чисел и порядок вычислений. Эти уровни необходимо согласовать. В частности, одинаковые числовые значения в массивах разных форм могут породить разные функции потерь.

Соглашения об обозначениях​

Скаляр обозначаем обычной буквой: a∈Ra\in\Ra∈R. Вектор — жирной строчной: x∈Rd\vect{x}\in\R^dx∈Rd. Матрицу — жирной прописной: X∈Rn×d\mat{X}\in\R^{n\times d}X∈Rn×d. Число nnn обозначает число наблюдений в текущем наборе, ddd — число признаков. Смысл этих символов фиксируется в пределах конкретной постановки.

Вектор в формулах считаем столбцом, если не указано иное. Строка признаков наблюдения jjj записывается как xjT\vect{x}_j^{\mathsf T}xjT​, а матрица X\mat{X}X составлена из таких строк. В первой части xxx обозначал всю ситуацию запроса; численный вектор признаков получается из неё отдельным отображением, а не тождественен исходной записи.

Математические индексы обычно начинаются с единицы, индексы NumPy — с нуля. Поэтому элемент X1,2X_{1,2}X1,2​ в соответствующем массиве читается как X[0, 1]. При работе с идентификаторами пользователей сначала строится явное отображение в целочисленные индексы: строковый ID не является номером строки автоматически.

Форма и оси​

shape — кортеж размеров осей. Для матрицы признаков форма (n, d), для пакета последовательностей может быть (batch, length, features). Смысл осей задаёт программа, а не сам массив.

Форма NumPyИнтерпретация в примере
()Скаляр
(d,)Одномерный массив длины ddd
(d, 1)Матрица-столбец
(1, d)Матрица-строка
(n, d)nnn строк по ddd признаков

Одномерный массив (d,) не хранит ориентацию столбца или строки. Его .T имеет ту же форму. Для явной оси применяют x[:, None] или x[None, :]. None вставляет ось длины один, не создавая нового признака.

Для матрицы X.sum(axis=0) суммирует по наблюдениям, результат имеет форму (d,). axis=1 суммирует признаки внутри каждой строки. keepdims=True сохраняет сокращённую ось длины один. Это позволяет сделать последующее вычитание среднего по строке однозначным.

Broadcasting и ошибка постановки​

Правило broadcasting NumPy сопоставляет размеры справа налево: они должны совпадать либо один из них должен быть равен единице; отсутствующие слева размеры рассматриваются как единицы. Это правило относится к поэлементным операциям, а не определяет произвольное матричное произведение.

Пусть прогноз и метки имеют форму (4,). Их разность содержит четыре парные ошибки. Если метки случайно преобразованы в (4, 1), вычитание с прогнозом (4,) создаёт матрицу (4, 4) всех сочетаний.

Для значений примера правильный MSE равен 0,0750{,}0750,075, ошибочный — 0,3250{,}3250,325. Обе операции допустимы для NumPy. Следовательно, отсутствие исключения не доказывает соответствие программы исходной задаче. Проверка prediction.shape == target.shape здесь является проверкой математического интерфейса.

Исполняемый пример​

arrays.py
"""Формы массивов, матричное произведение и broadcasting."""
import numpy as np


def main():
    users = np.array([[1.0, 2.0], [-1.0, 1.0]], dtype=np.float64)
    items = np.array([[1.0, 0.0], [0.0, 1.0], [1.0, 1.0]])
    scores = users @ items.T
    print("shapes:", users.shape, items.shape, scores.shape)
    print("scores:\n", scores)

    prediction = np.array([0.2, 0.4, 0.7, 0.9])
    target = np.array([0.0, 0.0, 1.0, 1.0])
    correct = prediction - target
    wrong = prediction - target[:, None]
    print("residual shapes:", correct.shape, wrong.shape)
    print("MSE:", round(float(np.mean(correct**2)), 3))
    print("broadcast MSE:", round(float(np.mean(wrong**2)), 3))


if __name__ == "__main__":
    main()

np.array создаёт массив; dtype=np.float64 явно задаёт вещественный тип. Оператор @ выполняет матричное произведение для используемых двумерных массивов. * умножает элементы с broadcasting. В коде users @ items.T имеет форму (2, 3): каждой паре строк «пользователь — объект» соответствует одно скалярное произведение. Подробный вывод дан в следующей главе.

Вывод разностей подтверждает формы (4,) и (4, 4). Печать с округлением используется только для представления; в расчётах массивы не округляются.

Тип чисел и память​

float32 занимает четыре байта на элемент, float64 — восемь. Плотный массив из mmm элементов с размером элемента bbb требует mbmbmb байт для самих данных, без метаданных и временных результатов. Например, матрица 106×10510^6\times10^5106×105 из float32 содержит 101110^{11}1011 элементов и требует 400400400 GB в десятичных единицах.

В этой части для численных сверок используется float64. Это не универсальная рекомендация для обучения всех моделей: выбор точности зависит от задачи, аппаратуры и допустимой ошибки. Индексы и логические маски имеют иной смысл и могут использовать другие типы.

Срез может быть представлением исходной памяти. Изменение такого представления способно изменить исходный массив. Если требуется независимый буфер, его создание следует указывать явно через .copy(); правила копирования описаны в документации NumPy.

Упражнения​

Упражнение · Формы и оси#

Пусть X.shape == (5, 3), w.shape == (3,). Укажите формы X @ w, X * w, X.mean(axis=1) и X.mean(axis=1, keepdims=True). Какая форма среднего подходит для вычитания среднего своей строки из X?

Решение

Формы равны (5,), (5, 3), (5,), (5, 1). Для вычитания по строкам подходит (5, 1): ось признаков расширяется по правилу broadcasting. Вектор (5,) не совместим с (5, 3) справа налево.

Упражнение · Перестановка меток#

Почему ошибочная функция с матрицей всех сочетаний не меняется при перестановке меток, а правильная парная функция в общем случае меняется?

Разбор

В матрице всех сочетаний перестановка меток только переставляет строки; сумма по всем элементам сохраняется. В парной функции перестановка меняет соответствие наблюдения и метки. Поэтому ошибочная функция теряет существенную информацию о парах.
