Градиенты и оптимизация

Обучение требует выбрать критерий и алгоритм его оптимизации. Низкая обучающая потеря не доказывает качество на целевом распределении; здесь рассматривается вычислительная задача минимизации конкретной функции на фиксированных данных.

Градиент и направленная производная​

Для дифференцируемой функции f:Rd→Rf:\R^d\to\Rf:Rd→R градиент ∇f(w)\nabla f(\vect{w})∇f(w) содержит частные производные. При малом приращении h\vect{h}h

f(w+h)=f(w)+⟨∇f(w),h⟩+o(∥h∥2).f(\vect{w}+\vect{h})=f(\vect{w})+\inner{\nabla f(\vect{w})}{\vect{h}}+o(\norm{\vect{h}}_2).f(w+h)=f(w)+⟨∇f(w),h⟩+o(∥h∥2​).

Среди направлений единичной евклидовой нормы наименьшую линейную часть даёт −∇f/∥∇f∥2-\nabla f/\norm{\nabla f}_2−∇f/∥∇f∥2​, если градиент ненулевой. Это следует из неравенства Коши—Буняковского. Такое локальное утверждение не гарантирует уменьшение при произвольно большом шаге.

Единая постановка примера​

Пусть X∈Rn×d\mat{X}\in\R^{n\times d}X∈Rn×d, y∈{0,1}n\vect{y}\in\{0,1\}^ny∈{0,1}n, n≥1n\ge1n≥1. Параметры w∈Rd\vect{w}\in\R^dw∈Rd задают логиты z=Xw\vect{z}=\mat{X}\vect{w}z=Xw и вероятности pj=σ(zj)p_j=\sigma(z_j)pj​=σ(zj​). Минимизируем

F(w)=1n∑j=1nℓ(xjTw,yj)+λ2∥w∥22,λ≥0,F(\vect{w})=\frac1n\sum_{j=1}^n\ell(\vect{x}_j^{\mathsf T}\vect{w},y_j) +\frac\lambda2\norm{\vect{w}}_2^2,\qquad \lambda\ge0,F(w)=n1​j=1∑n​ℓ(xjT​w,yj​)+2λ​∥w∥22​,λ≥0,

где ℓ\ellℓ — бинарная потеря из предыдущей главы. Штраф здесь применяется ко всем координатам, включая коэффициент константного признака. Исключение intercept из штрафа было бы другой постановкой.

Дифференцирование log⁡(1+ez)−yz\log(1+e^z)-yzlog(1+ez)−yz даёт ∂ℓ/∂z=σ(z)−y\partial\ell/\partial z=\sigma(z)-y∂ℓ/∂z=σ(z)−y. По цепному правилу

∇F(w)=1nXT(p−y)+λw.\nabla F(\vect{w})=\frac1n\mat{X}^{\mathsf T}(\vect{p}-\vect{y})+\lambda\vect{w}.∇F(w)=n1​XT(p−y)+λw.

Формы: (d,n)⋅(n,)(d,n)\cdot(n,)(d,n)⋅(n,) дают (d,)(d,)(d,), поэтому и штраф добавляется вектором той же формы. Проверка размерностей не заменяет вывод, но обнаруживает ряд ошибок его реализации.

Гессиан и регуляризация​

Поскольку σ′(z)=σ(z)(1−σ(z))\sigma'(z)=\sigma(z)(1-\sigma(z))σ′(z)=σ(z)(1−σ(z)), гессиан равен

∇2F=1nXTDX+λI,Djj=pj(1−pj)∈[0,1/4].\nabla^2F=\frac1n\mat{X}^{\mathsf T}\mat{D}\mat{X}+\lambda\mat{I}, \qquad D_{jj}=p_j(1-p_j)\in[0,1/4].∇2F=n1​XTDX+λI,Djj​=pj​(1−pj​)∈[0,1/4].

Для любого вектора v\vect{v}v соответствующая квадратичная форма не меньше λ∥v∥22\lambda\norm{\vect{v}}_2^2λ∥v∥22​. При λ=0\lambda=0λ=0 функция выпукла; существование конечного минимума при этом не гарантировано, например на линейно разделимых данных. При λ>0\lambda>0λ>0 функция сильно выпукла, а неотрицательность бинарной потери даёт F(w)≥λ∥w∥22/2F(\vect{w})\ge\lambda\norm{\vect{w}}_2^2/2F(w)≥λ∥w∥22​/2. Непрерывность и рост на бесконечности обеспечивают существование минимума, сильная выпуклость — его единственность.

Сверху гессиан ограничен в спектральной норме величиной

L0=∥X∥224n+λ.L_0=\frac{\norm{\mat{X}}_2^2}{4n}+\lambda.L0​=4n∥X∥22​​+λ.

Поэтому градиент глобально L0L_0L0​-липшицев: ∥∇F(a)−∇F(b)∥2≤L0∥a−b∥2\norm{\nabla F(\vect{a})-\nabla F(\vect{b})}_2\le L_0\norm{\vect{a}-\vect{b}}_2∥∇F(a)−∇F(b)∥2​≤L0​∥a−b∥2​. Число L0L_0L0​ здесь обозначает границу кривизны, а не длину рекомендательного списка.

NumPy: ручной градиент​

optimization.py
"""Полный градиентный спуск для логистической модели с L2-штрафом."""
import numpy as np
from numerics import binary_loss, sigmoid


def problem():
    features = np.column_stack([np.ones(4), [-1.5, -0.5, 0.5, 1.5]])
    targets = np.array([0.0, 0.0, 1.0, 1.0])
    return features, targets


def loss_and_gradient(weights, features, targets, l2=0.2):
    if features.ndim != 2 or len(features) == 0:
        raise ValueError("Матрица признаков должна иметь непустую ось наблюдений")
    if weights.shape != (features.shape[1],) or targets.shape != (len(features),):
        raise ValueError("Несогласованные формы")
    if l2 < 0:
        raise ValueError("Коэффициент регуляризации должен быть неотрицательным")
    logits = features @ weights
    value = binary_loss(logits, targets).mean() + l2 / 2 * (weights @ weights)
    gradient = features.T @ (sigmoid(logits) - targets) / len(features) + l2 * weights
    return float(value), gradient


def train(features, targets, steps=200, rate=0.2, l2=0.2):
    weights = np.zeros(features.shape[1], dtype=np.float64)
    losses = []
    for _ in range(steps):
        loss, gradient = loss_and_gradient(weights, features, targets, l2)
        losses.append(loss)
        weights -= rate * gradient
    losses.append(loss_and_gradient(weights, features, targets, l2)[0])
    return weights, np.array(losses)


if __name__ == "__main__":
    features, targets = problem()
    initial = loss_and_gradient(np.zeros(2), features, targets)
    weights, losses = train(features, targets)
    print("initial loss:", round(initial[0], 6))
    print("initial gradient:", initial[1])
    print("final weights:", np.round(weights, 6))
    print("final loss:", round(float(losses[-1]), 6))

Нужен файл numerics.py из предыдущей главы. problem() создаёт четыре строки: первая координата равна единице, вторая принимает −1,5; −0,5; 0,5; 1,5. Метки — 0, 0, 1, 1. Используются λ=0,2\lambda=0{,}2λ=0,2, η=0,2\eta=0{,}2η=0,2, 200 шагов из нулевого вектора.

В начальной точке логиты нулевые, вероятности равны 0,5. Потеря равна log⁡2≈0,693147\log2\approx0{,}693147log2≈0,693147, градиент — (0,−0,5)T(0,-0{,}5)^{\mathsf T}(0,−0,5)T. Первый шаг даёт (0,0,1)T(0,0{,}1)^{\mathsf T}(0,0,1)T. После 200 шагов получаются приблизительно (0,1,079871)T(0,1{,}079871)^{\mathsf T}(0,1,079871)T и потеря 0,436506. Печатное -0. — эффект численной погрешности возле нуля.

Для этой матрицы ∥X∥22=5\norm{\mat{X}}_2^2=5∥X∥22​=5, поэтому L0=0,5125L_0=0{,}5125L0​=0,5125. Выбранный шаг удовлетворяет доказанному достаточному условию. losses сохраняет значение до каждого обновления и ещё одно значение после последнего; его длина равна 201. Убывание проверяется на этой последовательности, а не по округлённой печати.

Minibatch и распределение выбора​

Пусть индексы I1,…,IBI_1,\ldots,I_BI1​,…,IB​ выбираются независимо равномерно из 1,…,n1,\ldots,n1,…,n и независимо от истории, определившей текущие параметры. Тогда

gB=1B∑b=1B∇ℓIb(w)+λw\vect{g}_B=\frac1B\sum_{b=1}^B\nabla\ell_{I_b}(\vect{w})+\lambda\vect{w}gB​=B1​b=1∑B​∇ℓIb​​(w)+λw

удовлетворяет E[gB∣w]=∇F(w)\E[\vect{g}_B\mid\vect{w}]=\nabla F(\vect{w})E[gB​∣w]=∇F(w). Достаточно усреднить градиент одного равномерно выбранного наблюдения и применить линейность ожидания. Штраф добавляется один раз к среднему, а не делится повторно на размер пакета.

Неравномерный отбор без коррекции в общем случае задаёт другое ожидаемое направление. Перемешивание без возвращения в пределах эпохи также не тождественно независимому выбору на каждом шаге. В рекомендациях распределение негативов требует отдельного анализа; точный критерий определяется не только кодом потери.

Momentum и адаптивные обновления​

Одна из конвенций momentum использует mt=βmt−1+(1−β)gt\vect{m}_t=\beta\vect{m}_{t-1}+(1-\beta)\vect{g}_tmt​=βmt−1​+(1−β)gt​ и обновление wt+1=wt−ηmt\vect{w}_{t+1}=\vect{w}_t-\eta\vect{m}_twt+1​=wt​−ηmt​. Конвенция без множителя 1−β1-\beta1−β задаёт другой масштаб, поэтому параметры разных реализаций сравниваются с учётом формулы.

В Adam первый момент использует ту же рекурсию с β=β1\beta=\beta_1β=β1​; дополнительно накапливается vt=β2vt−1+(1−β2)gt⊙2\vect{v}_t=\beta_2\vect{v}_{t-1}+(1-\beta_2)\vect{g}_t^{\odot2}vt​=β2​vt−1​+(1−β2​)gt⊙2​, где степень означает поэлементный квадрат. При нулевых начальных моментах используются поправки m^t=mt/(1−β1t)\widehat{\vect m}_t=\vect m_t/(1-\beta_1^t)mt​=mt​/(1−β1t​), v^t=vt/(1−β2t)\widehat{\vect v}_t=\vect v_t/(1-\beta_2^t)vt​=vt​/(1−β2t​) и покоординатный шаг −ηm^t/(v^t+ε)-\eta\widehat{\vect m}_t/(\sqrt{\widehat{\vect v}_t}+\varepsilon)−ηmt​/(vt​​+ε). Здесь t≥1t\ge1t≥1, 0≤β1,β2<10\le\beta_1,\beta_2<10≤β1​,β2​<1, ε>0\varepsilon>0ε>0.

Добавление L2-штрафа к критерию и отдельное уменьшение параметров не эквивалентны в общем случае адаптивного метода. Это различие формализовано в работе об AdamW. В текущем примере выбран простой полный градиентный спуск, чтобы одинаковый критерий и одинаковые шаги можно было проверить независимо.

Упражнения​

Упражнение · Шаг на квадратичной функции#

Для f(w)=(w−1)2f(w)=(w-1)^2f(w)=(w−1)2, w0=4w_0=4w0​=4 вычислите первые два обновления при η=0,25\eta=0{,}25η=0,25, 0,75 и 1. Объясните различия по множителю ошибки.

Решение

При 0,25 получаем 2,5 и 1,75; множитель 0,5. При 0,75 — −0,5 и 1,75; множитель −0,5. При 1 — −2 и 4; множитель −1, возникает цикл.

Упражнение · Роль среднего#

Если заменить среднюю бинарную потерю суммой, оставив λ\lambdaλ и шаг неизменными, сохранится ли задача и траектория? Во сколько раз следует изменить штраф, чтобы новая функция была ровно nFnFnF?

Решение

Нет. Масштаб части, зависящей от данных, изменился относительно штрафа. Для функции nFnFnF коэффициент штрафа должен стать nλn\lambdanλ. Даже при одинаковом минимуме градиент этой функции в nnn раз больше; для сохранения траектории полного спуска шаг уменьшается в nnn раз.
