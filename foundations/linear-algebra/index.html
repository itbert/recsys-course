Ранг, спектр и линейные системы

Матричная запись позволяет выразить структуру представлений и кривизну функции потерь. Для этого необходимо различать ранг, собственные значения, сингулярные значения и свойства численного решения.

Линейное отображение и ранг​

Матрица A∈Rm×d\mat{A}\in\R^{m\times d}A∈Rm×d задаёт линейное отображение x↦Ax\vect{x}\mapsto\mat{A}\vect{x}x↦Ax. Его образ — множество достижимых выходов, ядро — множество входов, переходящих в ноль. Ранг — размерность образа; он равен числу линейно независимых столбцов и не превосходит min⁡(m,d)\min(m,d)min(m,d).

Например,

M=(1224)=(12)(12)\mat{M}=\begin{pmatrix}1&2\\2&4\end{pmatrix} =\begin{pmatrix}1\\2\end{pmatrix}\begin{pmatrix}1&2\end{pmatrix}M=(12​24​)=(12​)(1​2​)

имеет ранг один. Её столбцы зависимы, и по выходу нельзя однозначно восстановить произвольный двумерный вход. Ненулевой вектор (−2,1)T(-2,1)^{\mathsf T}(−2,1)T принадлежит ядру.

Если R=PQT\mat{R}=\mat{P}\mat{Q}^{\mathsf T}R=PQT при ddd столбцах факторов, то rank⁡(R)≤d\operatorname{rank}(\mat{R})\le drank(R)≤d: каждый столбец произведения является линейной комбинацией столбцов P\mat{P}P. Это ограничение выразительности факторного представления. Методы его обучения вводятся позднее.

Спектр симметричной матрицы​

Для квадратной матрицы собственная пара удовлетворяет Av=λv\mat{A}\vect{v}=\lambda\vect{v}Av=λv, где v≠0\vect{v}\ne0v=0. Число λ\lambdaλ — собственное значение. Для вещественной симметричной матрицы спектральная теорема даёт

A=UΛUT,UTU=I,\mat{A}=\mat{U}\mat{\Lambda}\mat{U}^{\mathsf T}, \qquad \mat{U}^{\mathsf T}\mat{U}=\mat{I},A=UΛUT,UTU=I,

где Λ\mat{\Lambda}Λ диагональна и содержит вещественные собственные значения. Здесь I\mat{I}I — единичная матрица. Спектральная теорема используется как базовый результат линейной алгебры; источник указан в конце главы.

Определение · Положительная определённость#

Вещественная симметричная матрица A\mat{A}A называется положительно полуопределённой (PSD), если xTAx≥0\vect{x}^{\mathsf T}\mat{A}\vect{x}\ge0xTAx≥0 для всех x\vect{x}x. Она положительно определена (PD), если неравенство строго для всех ненулевых x\vect{x}x.

Теорема · Спектральный критерий#

Симметричная матрица PSD тогда и только тогда, когда все её собственные значения неотрицательны. Для PD все они строго положительны.

Доказательство

Для собственного вектора v\vect{v}v квадратичная форма равна λ∥v∥22\lambda\norm{\vect{v}}_2^2λ∥v∥22​, откуда необходимость. Для достаточности разложим произвольный вектор в ортонормированном собственном базисе: x=Uz\vect{x}=\mat{U}\vect{z}x=Uz. Тогда xTAx=∑jλjzj2\vect{x}^{\mathsf T}\mat{A}\vect{x}=\sum_j\lambda_jz_j^2xTAx=∑j​λj​zj2​. При неотрицательных значениях сумма неотрицательна; при положительных она строго положительна для ненулевого вектора.

□

В частности, XTX\mat{X}^{\mathsf T}\mat{X}XTX всегда PSD, поскольку wTXTXw=∥Xw∥22\vect{w}^{\mathsf T}\mat{X}^{\mathsf T}\mat{X}\vect{w}=\norm{\mat{X}\vect{w}}_2^2wTXTXw=∥Xw∥22​. Она может быть вырожденной. Добавление λI\lambda\mat{I}λI с λ>0\lambda>0λ>0 делает её PD и сдвигает каждое собственное значение на λ\lambdaλ.

Сингулярное разложение​

Для любой вещественной матрицы A∈Rm×d\mat{A}\in\R^{m\times d}A∈Rm×d существует сокращённое SVD:

A=UΣVT,r=min⁡(m,d),\mat{A}=\mat{U}\mat{\Sigma}\mat{V}^{\mathsf T},\qquad r=\min(m,d),A=UΣVT,r=min(m,d),

где U∈Rm×r\mat{U}\in\R^{m\times r}U∈Rm×r и V∈Rd×r\mat{V}\in\R^{d\times r}V∈Rd×r имеют ортонормированные столбцы, а диагональ Σ\mat{\Sigma}Σ содержит σ1≥⋯≥σr≥0\sigma_1\ge\cdots\ge\sigma_r\ge0σ1​≥⋯≥σr​≥0. Нулевые значения допускаются; число ненулевых в точной арифметике равно рангу.

Собственные и сингулярные значения не тождественны. Сингулярные определяются и для прямоугольных матриц и всегда неотрицательны. Ненулевые значения σj2\sigma_j^2σj2​ совпадают с ненулевыми собственными значениями ATA\mat{A}^{\mathsf T}\mat{A}ATA с учётом кратности. Различие размерностей может добавлять нулевые собственные значения.

Усечение после kkk членов даёт Ak=∑j=1kσjujvjT\mat{A}_k=\sum_{j=1}^k\sigma_j\vect{u}_j\vect{v}_j^{\mathsf T}Ak​=∑j=1k​σj​uj​vjT​. Для нормы Фробениуса ∥A∥F2=∑ijAij2\norm{\mat{A}}_F^2=\sum_{ij}A_{ij}^2∥A∥F2​=∑ij​Aij2​ выполняется

∥A−Ak∥F2=∑j=k+1rσj2.\norm{\mat{A}-\mat{A}_k}_F^2=\sum_{j=k+1}^r\sigma_j^2.∥A−Ak​∥F2​=j=k+1∑r​σj2​.

Равенство следует из ортонормированности матриц ujvjT\vect{u}_j\vect{v}_j^{\mathsf T}uj​vjT​ относительно произведения Фробениуса. Оно характеризует ошибку заданного усечения. Задача подбора факторов по неполным наблюдениям отличается от SVD полностью известной матрицы; отсутствие наблюдения нельзя автоматически заменить известным нулём.

Решение системы и обусловленность​

При невырожденной квадратной A\mat{A}A уравнение Ax=b\mat{A}\vect{x}=\vect{b}Ax=b имеет единственное решение. В программе используется np.linalg.solve(A, b); явное построение inv(A) @ b для одной системы не требуется. Документация solve задаёт требования к формам и невырожденности.

Число обусловленности в спектральной норме равно κ2(A)=σmax⁡/σmin⁡\kappa_2(\mat{A})=\sigma_{\max}/\sigma_{\min}κ2​(A)=σmax​/σmin​. Для возмущения только правой части при ненулевых b,x\vect{b},\vect{x}b,x получаем

∥δx∥2∥x∥2≤κ2(A)∥δb∥2∥b∥2.\frac{\norm{\delta\vect{x}}_2}{\norm{\vect{x}}_2} \le\kappa_2(\mat{A})\frac{\norm{\delta\vect{b}}_2}{\norm{\vect{b}}_2}.∥x∥2​∥δx∥2​​≤κ2​(A)∥b∥2​∥δb∥2​​.

Это следует из δx=A−1δb\delta\vect{x}=\mat{A}^{-1}\delta\vect{b}δx=A−1δb и ∥b∥2≤∥A∥2∥x∥2\norm{\vect{b}}_2\le\norm{\mat{A}}_2\norm{\vect{x}}_2∥b∥2​≤∥A∥2​∥x∥2​. Оценка для возмущения самой матрицы требует дополнительных условий. Большая обусловленность означает потенциальное усиление ошибки, а не обязательное достижение верхней границы в любом направлении.

Исполняемая проверка​

linear_algebra.py
"""Геометрия оценок и линейные операторы."""
import numpy as np


def main():
    user = np.array([1.0, 1.0])
    items = np.array([[3.0, 0.0], [1.0, 1.0]])
    dot = items @ user
    cosine = dot / (np.linalg.norm(items, axis=1) * np.linalg.norm(user))
    print("dot:", dot)
    print("cosine:", np.round(cosine, 6))

    matrix = np.array([[1.0, 2.0], [2.0, 4.0]])
    left, singular, right_t = np.linalg.svd(matrix, full_matrices=False)
    reconstructed = (left * singular) @ right_t
    print("singular values:", np.round(singular, 6))
    print("rank:", np.linalg.matrix_rank(matrix))
    print("reconstruction error:", np.linalg.norm(matrix - reconstructed))

    positive = np.array([[2.0, 1.0], [1.0, 2.0]])
    solution = np.linalg.solve(positive, np.array([1.0, 0.0]))
    print("eigenvalues:", np.linalg.eigvalsh(positive))
    print("solution:", np.round(solution, 6))


if __name__ == "__main__":
    main()

Первый блок повторяет геометрический пример. full_matrices=False выбирает сокращённое SVD; right_t уже содержит VT\mat{V}^{\mathsf T}VT. Выражение left * singular масштабирует столбцы U\mat{U}U, после чего @ right_t восстанавливает матрицу. Для M\mat{M}M сингулярные значения равны 5 и 0 с учётом численной погрешности.

eigvalsh предназначен для симметричной задачи. У матрицы positive собственные значения 1 и 3, а решение системы равно (2/3,−1/3)T(2/3,-1/3)^{\mathsf T}(2/3,−1/3)T. При численной оценке ранга применяется допуск; точное математическое равенство нулю и малое вычисленное значение различаются. Знаки сингулярных векторов и базис при кратных значениях не обязаны совпадать в разных реализациях, хотя восстановленная матрица совпадает в пределах точности.

Упражнения​

Упражнение · PSD и обратимость#

Является ли M\mat{M}M из примера PSD и обратимой? Что изменится для M+0,1I\mat{M}+0{,}1\mat{I}M+0,1I?

Решение

M\mat{M}M PSD, её собственные значения 0 и 5; она необратима. После сдвига получаются 0,1 и 5,1: матрица PD и обратима. Число обусловленности в спектральной норме равно 51.

Упражнение · Ошибка усечения#

Сингулярные значения матрицы равны 4, 2 и 1. Какова норма Фробениуса ошибки усечения до ранга один? Можно ли перенести этот расчёт на неизвестные элементы частично наблюдаемой матрицы без дополнительных предположений?

Решение

Ошибка равна 22+12=5\sqrt{2^2+1^2}=\sqrt522+12​=5​. Формула относится к SVD заданной полной матрицы. Неизвестные элементы не определяют такую матрицу однозначно; прямой перенос не обоснован.
