Выборочные оценки и неопределённость

Значение метрики на одной выборке не характеризует её неопределённость. Необходимо различать параметр распределения, процедуру оценки и результат этой процедуры на конкретных данных.

Оценка как случайная величина​

Пусть Y1,…,YnY_1,\ldots,Y_nY1​,…,Yn​ независимы и одинаково распределены, E[Yj]=μ\E[Y_j]=\muE[Yj​]=μ, Var⁡(Yj)=σ2<∞\operatorname{Var}(Y_j)=\sigma^2<\inftyVar(Yj​)=σ2<∞. Это предпосылка iid, а не автоматическое свойство журнала событий.

Выборочное среднее Y‾=n−1∑jYj\overline Y=n^{-1}\sum_jY_jY=n−1∑j​Yj​ является оценкой μ\muμ. Смещение оценки μ^\widehat\muμ​ равно E[μ^]−μ\E[\widehat\mu]-\muE[μ​]−μ, дисперсия — E[(μ^−E[μ^])2]\E[(\widehat\mu-\E[\widehat\mu])^2]E[(μ​−E[μ​])2]. Среднеквадратичная ошибка раскладывается как

E[(μ^−μ)2]=Var⁡(μ^)+(E[μ^]−μ)2.\E[(\widehat\mu-\mu)^2] =\operatorname{Var}(\widehat\mu) +(\E[\widehat\mu]-\mu)^2.E[(μ​−μ)2]=Var(μ​)+(E[μ​]−μ)2.

Достаточно прибавить и вычесть E[μ^]\E[\widehat\mu]E[μ​] внутри квадрата; смешанное слагаемое имеет нулевое ожидание. Несмещённость означает нулевое среднее отклонение по повторным выборкам, а не отсутствие ошибки в каждом запуске.

Теорема · Среднее iid-наблюдений#

При указанных предпосылках E[Y‾]=μ\E[\overline Y]=\muE[Y]=μ и Var⁡(Y‾)=σ2/n\operatorname{Var}(\overline Y)=\sigma^2/nVar(Y)=σ2/n.

Доказательство

Первое равенство следует из линейности ожидания. Во втором независимость обнуляет ковариации разных наблюдений, поэтому дисперсия суммы равна nσ2n\sigma^2nσ2, а деление суммы на nnn уменьшает дисперсию в n2n^2n2 раз.

□

Стандартная ошибка — стандартное отклонение оценки по повторным выборкам. Для среднего это σ/n\sigma/\sqrt nσ/n​. Она не совпадает со стандартным отклонением самих наблюдений σ\sigmaσ.

Оценка дисперсии​

При n≥2n\ge2n≥2 выборочная дисперсия определяется как

s2=1n−1∑j=1n(Yj−Y‾)2.s^2=\frac1{n-1}\sum_{j=1}^n(Y_j-\overline Y)^2.s2=n−11​j=1∑n​(Yj​−Y)2.

Она несмещённо оценивает σ2\sigma^2σ2 при тех же iid-предпосылках. Для проверки используется тождество

∑j(Yj−Y‾)2=∑j(Yj−μ)2−n(Y‾−μ)2.\sum_j(Y_j-\overline Y)^2 =\sum_j(Y_j-\mu)^2-n(\overline Y-\mu)^2.j∑​(Yj​−Y)2=j∑​(Yj​−μ)2−n(Y−μ)2.

Ожидание правой части равно nσ2−σ2n\sigma^2-\sigma^2nσ2−σ2. В NumPy этот знаменатель задаётся var(ddof=1). Оценка стандартной ошибки s/ns/\sqrt ns/n​ сама случайна; её подстановка в нормальный интервал не создаёт точной гарантии покрытия для любого распределения и размера выборки.

Для последовательности из трёх единиц и пяти нулей: y‾=0,375\overline y=0{,}375y​=0,375, s2=15/56≈0,267857s^2=15/56\approx0{,}267857s2=15/56≈0,267857, оценка стандартной ошибки — около 0,1829810{,}1829810,182981.

Что означает доверительное покрытие​

Доверительная процедура строит случайный интервал C(D)C(\mathcal D)C(D) по данным. Утверждение о покрытии уровня не ниже 1−δ1-\delta1−δ означает Pμ(μ∈C(D))≥1−δ\Prob_\mu(\mu\in C(\mathcal D))\ge1-\deltaPμ​(μ∈C(D))≥1−δ при заданных предпосылках. Вероятность относится к повторным выборкам и процедуре; фиксированный неизвестный параметр в этой частотной формулировке не превращается в случайную величину после наблюдения данных.

Получим простую конечновыборочную границу для iid Бернулли. Для любого r>0r>0r>0 неравенство Маркова, применённое к (Y‾−p)2(\overline Y-p)^2(Y−p)2, даёт

P(∣Y‾−p∣≥r)≤Var⁡(Y‾)r2=p(1−p)nr2≤14nr2.\Prob(|\overline Y-p|\ge r) \le\frac{\operatorname{Var}(\overline Y)}{r^2} =\frac{p(1-p)}{nr^2}\le\frac1{4nr^2}.P(∣Y−p∣≥r)≤r2Var(Y)​=nr2p(1−p)​≤4nr21​.

Поэтому r=1/(2nδ)r=1/(2\sqrt{n\delta})r=1/(2nδ​) задаёт интервал [Y‾−r,Y‾+r]∩[0,1][\overline Y-r,\overline Y+r]\cap[0,1][Y−r,Y+r]∩[0,1] с покрытием не ниже 1−δ1-\delta1−δ. Это консервативная граница: при n=100n=100n=100, δ=0,05\delta=0{,}05δ=0,05 радиус около 0,224. Использовать её как утверждение о реальных логах можно только при выполнении предпосылок, а не по совпадению размера таблицы.

Bootstrap и его границы​

Bootstrap заменяет неизвестное распределение эмпирическим. В iid-варианте создаются повторные выборки размера nnn с возвращением из исходных nnn значений. По каждой считается оценка; квантили полученного распределения используются для анализа её изменчивости.

sample_statistics.py
"""Выборочное среднее, стандартная ошибка и bootstrap для iid-наблюдений."""
import numpy as np


def summarize(values, repetitions=5000, seed=17):
    sample = np.asarray(values, dtype=np.float64)
    if sample.ndim != 1 or len(sample) < 2 or not np.isfinite(sample).all():
        raise ValueError("Нужен конечный одномерный массив длины не менее 2")
    if repetitions < 1:
        raise ValueError("Число повторов должно быть положительным")
    rng = np.random.default_rng(seed)
    indices = rng.integers(0, len(sample), size=(repetitions, len(sample)))
    means = sample[indices].mean(axis=1)
    return {
        "mean": float(sample.mean()),
        "variance": float(sample.var(ddof=1)),
        "standard_error": float(sample.std(ddof=1) / np.sqrt(len(sample))),
        "percentile_interval": np.quantile(means, [0.025, 0.975]).tolist(),
    }


if __name__ == "__main__":
    print(summarize([1, 0, 0, 1, 0, 0, 0, 1]))

rng.integers создаёт массив индексов формы (repetitions, n). Индексирование sample[indices] строит bootstrap-выборки, а .mean(axis=1) — их средние. Здесь одновременно сохраняются все повторы; память составляет O(Bn)O(Bn)O(Bn), где BBB — число повторов. Для больших данных требуется пакетная обработка.

Для приведённой последовательности и зафиксированной версии генератора программа возвращает среднее 0,375 и percentile-интервал [0.0, 0.75]. Номинальные квантили 2,5% и 97,5% не гарантируют точное 95%-покрытие при любом nnn. Например, выборка из одних нулей даёт вырожденный iid bootstrap, хотя истинная вероятность успеха может быть положительной.

Первоначальная постановка bootstrap изложена в Efron, 1979. Здесь реализуется конкретный percentile-вариант, а не универсальная процедура для всех рекомендательных экспериментов.

Зависимость и единица наблюдения​

Без независимости формула дисперсии среднего имеет дополнительные слагаемые:

Var⁡(Y‾)=1n2(∑jVar⁡(Yj)+2∑j<kCov⁡(Yj,Yk)).\operatorname{Var}(\overline Y) =\frac1{n^2}\left(\sum_j\operatorname{Var}(Y_j) +2\sum_{j<k}\operatorname{Cov}(Y_j,Y_k)\right).Var(Y)=n21​​j∑​Var(Yj​)+2j<k∑​Cov(Yj​,Yk​)​.

Если все YjY_jYj​ совпадают с одной и той же случайной величиной ZZZ, среднее равно ZZZ, и его дисперсия не уменьшается с ростом числа строк. Повторные события одного пользователя, временная зависимость и общие внешние факторы требуют обоснования единицы ресэмплирования. Групповой и блочный bootstrap будут вводиться вместе с соответствующими протоколами оценки.

Из этого также следует, что миллион зависимых строк нельзя без обоснования интерпретировать как миллион независимых испытаний. Статистическая неопределённость не устраняет смещение отбора, описанное в первой части.

Упражнения​

Упражнение · Дублирование данных#

Каждую строку исходной таблицы скопировали десять раз. Изменится ли среднее? Правомерно ли заменить nnn на 10n10n10n в iid-формуле стандартной ошибки?

Решение

Среднее не изменится. Копии зависимы, поэтому оснований для iid-уменьшения ошибки в 10\sqrt{10}10​ раз нет. Новых независимых наблюдений операция не создаёт.

Упражнение · Интервал из нулей#

Объясните, почему интервал [0, 0] после bootstrap выборки без успехов не доказывает, что p=0p=0p=0. Какова вероятность такой выборки при iid Бернулли с p>0p>0p>0?

Решение

Ресэмплирование не создаёт значений, которых нет в исходной выборке. При истинном 0<p<10<p<10<p<1 вероятность всех нулей равна (1−p)n>0(1-p)^n>0(1−p)n>0. Поэтому вырожденность эмпирического распределения не тождественна вырожденности исходного.
