Популярность и длинный хвост

Что называется популярностью​

В этой главе популярность статьи iii — число её зарегистрированных показов nin_ini​ за фиксированный период. Можно аналогично считать клики, дочитывания, покупки или число различных пользователей, но получится другая характеристика. Показы зависят от политики экспозиции и доступности; они не являются непосредственным измерением скрытой полезности.

Пусть каталог анализа I\mathcal II содержит m>0m>0m>0 статей, N=∑ini>0N=\sum_i n_i>0N=∑i​ni​>0. Доля показов статьи равна pi=ni/Np_i=n_i/Npi​=ni​/N. Упорядочим счётчики по убыванию: n[1]≥…≥n[m]n_{[1]}\ge\ldots\ge n_{[m]}n[1]​≥…≥n[m]​. Доля первых kkk статей

Sk=∑j=1min⁡(k,m)n[j]NS_k=\frac{\sum_{j=1}^{\min(k,m)}n_{[j]}}{N}Sk​=N∑j=1min(k,m)​n[j]​​

измеряет концентрацию выбранного вида событий. При равных счётчиках состав top-kkk может зависеть от правила разрешения равенств, но сумма при фиксированном kkk остаётся той же.

Покрытие показами определим как C=∣{i:ni>0}∣/mC=|\{i:n_i>0\}|/mC=∣{i:ni​>0}∣/m. В нашем реестре показаны 18 из 20 статей, поэтому C=90%C=90\%C=90%. Это покрытие зарегистрированными показами за период, а не доля объектов, которые новая модель сумеет рекомендовать.

Кривая Лоренца и Gini​

Для x1≤…≤xmx_1\le\ldots\le x_mx1​≤…≤xm​, то есть счётчиков по возрастанию, кривая Лоренца соединяет точки

(km,∑j=1kxjN),k=0,…,m.\left(\frac{k}{m},\frac{\sum_{j=1}^k x_j}{N}\right), \quad k=0,\ldots,m.(mk​,N∑j=1k​xj​​),k=0,…,m.

Горизонтальная ось накапливает объекты от редких к частым. Диагональ соответствует равным долям. Нулевые объекты образуют начальный плоский участок.

Используем Gini без поправки на конечный размер:

G=∑i=1m∑j=1m∣xi−xj∣2mN=2∑j=1mjxjmN−m+1m.G=\frac{\sum_{i=1}^m\sum_{j=1}^m|x_i-x_j|}{2mN} =\frac{2\sum_{j=1}^m jx_j}{mN}-\frac{m+1}{m}.G=2mN∑i=1m​∑j=1m​∣xi​−xj​∣​=mN2∑j=1m​jxj​​−mm+1​.

Второе выражение следует из группировки пар с i<ji<ji<j: вклад xjx_jxj​ в сумму разностей определяется числом меньших и больших индексов. Оно позволяет считать показатель после сортировки без квадратичного перебора пар.

При равных счётчиках G=0G=0G=0. При всей массе в одном объекте G=(m−1)/mG=(m-1)/mG=(m−1)/m. Это максимум для заданного mmm: неравенство ∣xi−xj∣≤xi+xj|x_i-x_j|\le x_i+x_j∣xi​−xj​∣≤xi​+xj​ для различных индексов даёт верхнюю границу (m−1)/m(m-1)/m(m−1)/m, а указанное распределение её достигает. Умножение всех счётчиков на одну положительную константу Gini не меняет.

Почему состав каталога существенен​

Теорема · Добавление нулевых объектов#

Пусть к mmm неотрицательным счётчикам с положительной суммой добавлено zzz нулевых объектов. Тогда для принятого Gini

Gnew=mG+zm+z.G_{\mathrm{new}}=\frac{mG+z}{m+z}.Gnew​=m+zmG+z​.
Доказательство

Сумма событий NNN сохраняется. Старая двойная сумма разностей равна 2mNG2mNG2mNG. Каждая пара из старого значения xix_ixi​ и нового нуля даёт xix_ixi​ в каждом порядке, поэтому новые смешанные пары добавляют 2zN2zN2zN. Пары новых нулей дают 0. Деление 2mNG+2zN2mNG+2zN2mNG+2zN на новый знаменатель 2(m+z)N2(m+z)N2(m+z)N даёт формулу.

□

Таким образом, Gini может вырасти без изменения единого показа. Причиной будет расширение множества объектов, относительно которого измеряется неравномерность. Сравнение разных периодов требует явно указать, использован весь текущий каталог, пересечение каталогов или другая фиксированная область.

Энтропия и эффективное число объектов​

Энтропия распределения показов равна

H(p)=−∑i:pi>0pilog⁡pi,meff=exp⁡(H(p)).H(p)=-\sum_{i:p_i>0}p_i\log p_i, \qquad m_{\mathrm{eff}}=\exp(H(p)).H(p)=−i:pi​>0∑​pi​logpi​,meff​=exp(H(p)).

Используется натуральный логарифм; единица энтропии — нат. Равномерное распределение на rrr объектах имеет H=log⁡rH=\log rH=logr, поэтому meff=rm_{\mathrm{eff}}=rmeff​=r. Для неравномерного распределения это число выражает эквивалентное по энтропии число равновероятных объектов, а не фактическое число показанных статей.

Добавление нулевых вероятностей не меняет HHH и meffm_{\mathrm{eff}}meff​. Нормировка H/log⁡mH/\log mH/logm, если её использовать при m>1m>1m>1, уже зависит от размера каталога. В отчёте сохраняется ненормированная энтропия; для нашего примера meff≈8,92m_{\mathrm{eff}}\approx8{,}92meff​≈8,92 при 18 показанных статьях.

Код и границы вычисления​

metrics.py — функция concentration
def concentration(values, top=3):
    ordered = sorted(values)
    if not ordered or any(type(value) is not int or value < 0 for value in ordered):
        raise ValueError("Нужны неотрицательные целые счётчики")
    if type(top) is not int or top < 0:
        raise ValueError("top должен быть неотрицательным целым")
    size, total = len(ordered), sum(ordered)
    result = {"catalog_size": size, "covered": sum(value > 0 for value in ordered),
              "coverage": sum(value > 0 for value in ordered) / size}
    if total == 0:
        return {**result, "top_share": None, "gini": None, "entropy": None, "effective_items": None}
    entropy = -math.fsum((value / total) * math.log(value / total) for value in ordered if value)
    gini = 2 * sum((index + 1) * value for index, value in enumerate(ordered)) / (size * total) - (size + 1) / size
    return {**result, "top_share": sum(ordered[-top:]) / total if top else 0,
            "gini": gini, "entropy": entropy, "effective_items": math.exp(entropy)}


Функция продолжает модуль из предыдущей главы и использует импортированный math. Сначала проверяются счётчики и число top-объектов. При нулевой сумме покрытие равно 0, но нормированное распределение событий не определено: top_share, Gini и энтропия возвращаются как None. Определять Gini нулевого трафика по удобному соглашению можно отдельно, однако здесь такое соглашение не вводится.

В формуле Gini индексы Python увеличиваются на 1, поскольку математическая нумерация начинается с единицы. При top=0 явно возвращается 0: срез ordered[-0:] иначе выбрал бы весь массив. Сложность определяется сортировкой, O(mlog⁡m)O(m\log m)O(mlogm); все дальнейшие проходы линейны.

Длинный хвост не доказывает степенной закон​

Много редких объектов и несколько частых можно описательно назвать длинным хвостом. Это ещё не модель вида P(X=x)∝x−α\Prob(X=x)\propto x^{-\alpha}P(X=x)∝x−α на заданном диапазоне. Счётчик объекта, ранг объекта, частота таких счётчиков и вероятность превышения — разные оси графика.

Прямая на log-log рисунке не является достаточной проверкой степенной гипотезы. Clauset, Shalizi и Newman в Power-law distributions in empirical data (2009) рассматривают оценивание, диапазон хвоста, проверку согласия и сравнение альтернатив. Здесь степенная модель не оценивается: визуализация показывает фактические частоты синтетического набора.

Упражнения​

Упражнение · Новые нули#

У четырёх статей счётчики [8,4,2,2][8,4,2,2][8,4,2,2], Gini равен 0,3125. Добавьте четыре доступные статьи без показов. Найдите новое покрытие и Gini. Изменится ли энтропия показов?

Разбор

Покрытие равно 4/8=0,54/8=0{,}54/8=0,5, Gini — (4⋅0,3125+4)/8=0,65625(4\cdot0{,}3125+4)/8=0{,}65625(4⋅0,3125+4)/8=0,65625. Энтропия сохраняется: вероятности старых объектов не изменились, нули не добавляют вклад. Разные показатели зависят от состава реестра по-разному.

Упражнение · Клики вместо показов#

У A сто показов и десять кликов, у B двадцать показов и пятнадцать кликов. Какая статья популярнее по каждому счётчику? Можно ли заменить один рейтинг другим без переопределения показателя?

Разбор

По показам лидирует A, по кликам B. Доли показов с кликом равны 10% и 75%, то есть дают ещё одну характеристику. Замена счётчика меняет определение популярности; ни один из этих результатов сам по себе не устанавливает причинную полезность объекта.
