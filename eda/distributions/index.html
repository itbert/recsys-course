Распределения и устойчивые сводки

От среднего к распределению​

Среднее число показов на аккаунт не показывает, сколько аккаунтов не представлено, насколько велика типичная активность и какую долю создают самые активные. Поэтому начинаем с набора счётчиков xu=nux_u=n_uxu​=nu​ для всего заданного реестра, включая нули.

Для примера [0,1,1,2,16][0,1,1,2,16][0,1,1,2,16] среднее равно 4. В данных нет ни одного значения 4, а четыре пятых значений меньше него. Это не недостаток среднего: оно отвечает на вопрос о сумме на единицу, а не обязано быть типичным наблюдением.

Определение · Эмпирическая функция распределения#

Для конечных значений x1,…,xnx_1,\ldots,x_nx1​,…,xn​, n>0n>0n>0, определим

F^n(t)=1n∑j=1n1{xj≤t}.\widehat F_n(t)=\frac1n\sum_{j=1}^n\mathbf 1\{x_j\le t\}.Fn​(t)=n1​j=1∑n​1{xj​≤t}.

Это доля наблюдений, не превосходящих ttt. ECDF не требует выбора ширины интервалов и сохраняет скачок в нуле.

Если восемь из 41 аккаунта не имеют показов, то F^(0)=8/41≈19,51%\widehat F(0)=8/41\approx19{,}51\%F(0)=8/41≈19,51%. После удаления нулей функция описывала бы распределение условно на наличии показа. На обоих графиках ось «число показов» выглядит одинаково, но распределения относятся к разным наборам.

Квантили и соглашения​

Расположим значения в неубывающем порядке: x(1)≤…≤x(n)x_{(1)}\le\ldots\le x_{(n)}x(1)​≤…≤x(n)​. Для 0<p≤10<p\le10<p≤1 используем нижний эмпирический квантиль

Q(p)=x(⌈np⌉),Q(0)=x(1).Q(p)=x_{(\lceil np\rceil)},\qquad Q(0)=x_{(1)}.Q(p)=x(⌈np⌉)​,Q(0)=x(1)​.

Медианой в этой части называется Q(0,5)Q(0{,}5)Q(0,5), межквартильным размахом — IQR=Q(0,75)−Q(0,25)\mathrm{IQR}=Q(0{,}75)-Q(0{,}25)IQR=Q(0,75)−Q(0,25). Для [0,1,1,2,16][0,1,1,2,16][0,1,1,2,16] получаем медиану 1, IQR 1 и P90 16. Для двух значений [2,8][2,8][2,8] наш Q(0,5)Q(0{,}5)Q(0,5) равен 2, а не среднему центральных значений 5.

Иные соглашения используют интерполяцию. Различия определений в статистических пакетах систематизированы Hyndman и Fan в Sample quantiles in statistical packages (1996). Поэтому имя percentile без метода ещё не фиксирует вычисление; особенно заметны различия на маленьких выборках.

Слово «устойчивый» требует масштаба сравнения. Увеличение максимального значения 16 до 1600 сильно изменит среднее, но в данном примере не изменит медиану и IQR. Это конкретная проверка чувствительности. Она не означает, что медиана нечувствительна к любому изменению состава данных или всегда полезнее среднего.

Гистограмма и ECDF​

Гистограмма группирует значения по интервалам. Для равной ширины столбцы числа наблюдений непосредственно сопоставимы. При неравной ширине площадь, соответствующая доле наблюдений, требует высоты nb/(nΔb)n_b/(n\Delta_b)nb​/(nΔb​), где Δb\Delta_bΔb​ — ширина интервала. Столбцы абсолютных частот в неравных числовых интервалах нельзя читать как плотность без такой нормировки.

Мелкие интервалы показывают дискретность, крупные скрывают детали. Полезно проверить несколько разумных разбиений и сопоставить результат с ECDF. Ноль и пропуск при этом сохраняют разные значения: отсутствие измерения длительности не становится нулевой длительностью от помещения в гистограмму.

Логарифмическая ось может сделать большой диапазон читаемым, но нули на ней не определены. Использование log⁡(1+x)\log(1+x)log(1+x) допустимо как явно указанное преобразование; оно не совпадает с log⁡x\log xlogx и меняет геометрию расстояний. На рисунке выше использованы исходные линейные оси.

Код характеристик​

metrics.py — начало модуля
"""Описательные характеристики: явные определения и нулевые группы."""
from collections import Counter
import math


def quantile(values, probability):
    values = sorted(values)
    if not values or not 0 <= probability <= 1:
        raise ValueError("Нужны непустые данные и p из [0,1]")
    if any(not math.isfinite(value) for value in values):
        raise ValueError("Требуются конечные значения")
    return values[max(0, math.ceil(probability * len(values)) - 1)]


def ecdf(values):
    counts = Counter(values)
    if not counts:
        raise ValueError("Пустое распределение")
    total, cumulative, result = sum(counts.values()), 0, []
    for value, count in sorted(counts.items()):
        cumulative += count
        result.append((value, cumulative / total))
    return result


def summary(values):
    values = list(values)
    if not values:
        return {"n": 0, "mean": None, "median": None, "p90": None, "iqr": None}
    return {"n": len(values), "mean": math.fsum(values) / len(values),
            "median": quantile(values, .5), "p90": quantile(values, .9),
            "iqr": quantile(values, .75) - quantile(values, .25)}


def counts(rows, identifiers, field):
    result = Counter({identifier: 0 for identifier in identifiers})
    result.update(getattr(row, field) for row in rows)
    return dict(result)


quantile сортирует значения и выбирает порядковую статистику; индексация Python начинается с нуля, поэтому из номера вычитается 1. Проверка конечности не позволяет NaN незаметно участвовать в упорядочении.

ecdf объединяет равные значения счётчиком, затем накапливает частоты по сортированным ключам. Выход содержит точки скачков. summary сохраняет None для характеристик пустого набора: среднее пустоты не равно нулю. counts инициализирует реестр нулями до добавления строк; обычный подсчёт только встреченных ID потерял бы отсутствующие группы.

Сортировка требует O(nlog⁡n)O(n\log n)O(nlogn) времени. В учебном summary квантили сортируются повторно ради самостоятельности функции. При больших массивах можно один раз сохранить упорядоченный набор или использовать алгоритмы выбора; смысл квантиля при этом должен остаться тем же.

От описания к статистическому выводу​

ECDF точно описывает переданный конечный набор. Для утверждения о неизвестном распределении будущей аудитории нужны условия отбора и устойчивости во времени. Пользователи с большим числом показов не превращаются в большее число независимых пользователей. Близкие значения на двух гистограммах также не устанавливают равенство популяций.

В отчёте рядом со сводкой сохраняются число единиц, число пропусков, состав реестра, период и метод квантиля. Это позволяет восстановить смысл числа до обсуждения неопределённости и статистических тестов.

Упражнения​

Упражнение · Правило медианы#

Рассчитайте Q(0,5)Q(0{,}5)Q(0,5) и P90 по принятому определению для [0,0,3,8][0,0,3,8][0,0,3,8]. Почему другой пакет может дать иную медиану без вычислительной ошибки?

Разбор

⌈4⋅0,5⌉=2\lceil4\cdot0{,}5\rceil=2⌈4⋅0,5⌉=2, поэтому медиана равна 0; P90 использует четвёртое значение и равен 8. Интерполированное среднее двух центральных значений равно 1,5. Оба результата могут следовать разным явно заданным соглашениям; сравнение требует одинакового метода.

Упражнение · Что изменил фильтр#

В реестре 100 аккаунтов, 60 без показов. После их удаления медиана положительных счётчиков равна 5. Чему равнялась нижняя медиана по полному реестру и можно ли назвать изменение ростом?

Разбор

По полному реестру медиана равна 0: пятидесятое значение находится среди шестидесяти нулей. Медиана 5 описывает условное распределение среди представленных аккаунтов. Смена состава не подтверждает временной рост активности.
