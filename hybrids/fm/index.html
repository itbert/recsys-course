Факторизационные машины

Из чего состоит строка​

Один показ даёт признаки пользователя, кандидата и запроса. Например, ("format", "аудио", 1) — категориальный индикатор, ("length", "minutes", 0.4) — вещественная координата. В словаре ключ (поле,значение)(\text{поле},\text{значение})(поле,значение) получает индекс jjj. Поэтому идентификатор пользователя 3 и идентификатор объекта 3 не совпадают. Пусть x∈Rdx\in\R^dx∈Rd обозначает строку, где активны m=nnz⁡(x)m=\operatorname{nnz}(x)m=nnz(x) координат.

У линейной модели влияние формата одинаково в каждой ситуации. Полная квадратичная модель добавляет независимый параметр wijw_{ij}wij​ для каждой пары признаков. Factorization Machine (FM) заменяет пару на скалярное произведение параметров признаков. Один и тот же вектор viv_ivi​ участвует во всех взаимодействиях признака iii, передавая информацию между парами. Rendle, 2010.

Взаимодействия используют только различные признаки. Для one-hot строки с одним пользователем uuu и одним объектом iii остаётся формула w0+wu+wi+vu⊤viw_0+w_u+w_i+v_u^\top v_iw0​+wu​+wi​+vu⊤​vi​ из факторизации со смещениями.

Оценки пар происходят из матрицы Грама VV⊤VV^\topVV⊤ ранга не больше fff. Это утверждение о параметризации до удаления диагонали. Матрица с обнулённой диагональю может иметь более высокий ранг. Тот же эффект для линейных операторов.

Обучение и неизвестные ID​

При бинарном клике y∈{0,1}y\in\{0,1\}y∈{0,1} берём логистическую потерю log⁡(1+exp⁡s)−ys\log(1+\exp s)-yslog(1+exps)−ys. Производная по sss равна σ(s)−y\sigma(s)-yσ(s)−y. Она умножает градиент каждого члена score, к которому добавляется L2L_2L2​-поправка. В учебном SGD берётся λ\lambdaλ на каждую посещённую строку параметров в каждом примере. Для равномерной выборки это соответствует штрафу, взвешенному частотой активации. Глобальный равномерный штраф по всем строкам потребовал бы другого обновления. Веса w0w_0w0​ не штрафуются. Клик и показ без клика попадают в выборку как наблюдённые значения; значение score за пределами политики показов требует отдельной оценки.

factor_machines.py
"""Оценка и один SGD-оптимизатор для FM и FFM."""

from collections import defaultdict
from dataclasses import dataclass
from itertools import combinations

import numpy as np


class FeatureSpace:
    def __init__(self, rows):
        keys = sorted({(field, key) for row in rows for field, key, value in row if value})
        field_ids = {name: i for i, name in enumerate(sorted({field for field, _ in keys}))}
        self.indices = {key: i for i, key in enumerate(keys)}
        self.fields = np.array([field_ids[field] for field, _ in keys], dtype=int)
        self.n_fields = len(field_ids)

    def encode(self, row):
        merged = defaultdict(float)
        for field, key, value in row:
            index = self.indices.get((field, key))
            if index is not None:
                merged[index] += value
        indices = np.array(sorted(i for i, value in merged.items() if value), dtype=int)
        return indices, np.array([merged[i] for i in indices])


def fm_interaction(values, vectors):
    weighted = values[:, None] * vectors
    total = weighted.sum(axis=0)
    value = .5 * (total @ total - np.sum(weighted**2))
    gradient = values[:, None] * (total - weighted)
    return value, gradient


def ffm_interaction(values, vectors, fields):
    gradient = np.zeros_like(vectors)
    value = 0.
    for left, right in combinations(range(len(values)), 2):
        to_left, to_right = fields[left], fields[right]
        a, b = vectors[left, to_right], vectors[right, to_left]
        scale = values[left] * values[right]
        value += scale * (a @ b)
        gradient[left, to_right] += scale * b
        gradient[right, to_left] += scale * a
    return value, gradient


@dataclass
class FactorMachine:
    bias: float
    weights: np.ndarray
    vectors: np.ndarray
    fields: np.ndarray

    def evaluate(self, row):
        indices, values = row
        active = self.vectors[indices]
        if self.vectors.ndim == 2:
            value, gradient = fm_interaction(values, active)
        else:
            value, gradient = ffm_interaction(values, active, self.fields[indices])
        return self.bias + self.weights[indices] @ values + value, gradient

    def score(self, row):
        return float(self.evaluate(row)[0])


def fit(rows, labels, space, *, rank=5, field_aware=False, epochs=10,
        step=.04, regularization=.02, seed=19):
    if len(rows) != len(labels) or not rows or rank < 1 or epochs < 1:
        raise ValueError("nonempty aligned rows and positive rank and epochs required")
    if not (np.isfinite(step) and step > 0 and np.isfinite(regularization) and regularization >= 0):
        raise ValueError("invalid optimizer parameters")
    if not all(label in (0, 1) for label in labels):
        raise ValueError("binary labels required")
    rng = np.random.default_rng(seed)
    dim = len(space.indices)
    shape = (dim, space.n_fields, rank) if field_aware else (dim, rank)
    model = FactorMachine(0., np.zeros(dim), rng.normal(0., .08, size=shape), space.fields)
    for _ in range(epochs):
        for pos in rng.permutation(len(rows)):
            indices, values = rows[pos]
            score, interaction_grad = model.evaluate(rows[pos])
            # exp(-logaddexp(0, -score)) = sigmoid(score).
            residual = np.exp(-np.logaddexp(0, -score)) - labels[pos]
            model.bias -= step * residual
            model.weights[indices] -= step * (
                residual * values + regularization * model.weights[indices]
            )
            model.vectors[indices] -= step * (
                residual * interaction_grad + regularization * model.vectors[indices]
            )
    return model

FeatureSpace строится только по обучающим строкам. encode суммирует повторы координаты, удаляет нули и пропускает неизвестные ключи. Так новый ID без параметров не получает случайный вектор, а известные атрибуты и контекст остаются активными. fm_interaction возвращает значение и градиент, используя одно и то же zzz. fit вычисляет все производные на старом состоянии и только затем меняет веса. Выражение через logaddexp стабилизирует сигмоиду при больших значениях score. score использует тот же код, что и обучение. При вычислительном ограничении инференс может выполнять только прямой проход.
