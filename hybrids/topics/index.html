От слов к темам — LDA

Документ как смесь​

В TF-IDF каждая координата соответствует слову. В Latent Dirichlet Allocation (LDA) документ имеет распределение θd\theta_dθd​ по KKK скрытым темам, а тема kkk имеет распределение ϕk\phi_kϕk​ по VVV терминам. Например, документ одновременно обсуждает музыку и математику. Модель может распределить его токены между двумя темами. Метки тем задаются по словам с высокой вероятностью и могут переставляться между независимыми обучениями. Blei, Ng и Jordan, 2003.

Распределение Дирихле Dir⁡(α1,…,αK)\operatorname{Dir}(\alpha_1,\ldots,\alpha_K)Dir(α1​,…,αK​) задано на симплексе θk≥0\theta_k\ge0θk​≥0, ∑kθk=1\sum_k\theta_k=1∑k​θk​=1. Его плотность пропорциональна ∏kθkαk−1\prod_k\theta_k^{\alpha_k-1}∏k​θkαk​−1​. Если наблюдать категориальные исходы с числами nkn_knk​, их правдоподобие умножает плотность на ∏kθknk\prod_k\theta_k^{n_k}∏k​θknk​​. Поэтому апостериорные параметры равны αk+nk\alpha_k+n_kαk​+nk​, а предсказательная вероятность следующей категории — (αk+nk)/∑ℓ(αℓ+nℓ)(\alpha_k+n_k)/\sum_\ell(\alpha_\ell+n_\ell)(αk​+nk​)/∑ℓ​(αℓ​+nℓ​).

В реализации используем симметричные приоры θd∼Dir⁡(α1K)\theta_d\sim\operatorname{Dir}(\alpha\mathbf 1_K)θd​∼Dir(α1K​), ϕk∼Dir⁡(η1V)\phi_k\sim\operatorname{Dir}(\eta\mathbf 1_V)ϕk​∼Dir(η1V​). Для каждой позиции rrr в документе ddd сначала выбираем скрытую тему zdr∼Cat⁡(θd)z_{dr}\sim\operatorname{Cat}(\theta_d)zdr​∼Cat(θd​), затем слово wdr∼Cat⁡(ϕzdr)w_{dr}\sim\operatorname{Cat}(\phi_{z_{dr}})wdr​∼Cat(ϕzdr​​). Модель условно обменна по позициям в документе. Порядок слов ей недоступен.

Обновление Гиббса​

При интегрировании θ\thetaθ и ϕ\phiϕ можно сэмплировать только назначения тем zzz. Обозначим через ndk−n_{dk}^{-}ndk−​ число назначений теме kkk в документе, через nkw−n_{kw}^{-}nkw−​ число вхождений слова www в теме, а через nk⋅−n_{k\cdot}^{-}nk⋅−​ общий размер темы. Все счётчики исключают обновляемую позицию. Griffiths и Steyvers, 2004.

Лемма · Условное распределение темы#

При симметричных α,η>0\alpha,\eta>0α,η>0 для позиции со словом www вес темы kkk пропорционален

(ndk−+α)nkw−+ηnk⋅−+Vη.(n_{dk}^{-}+\alpha)\frac{n_{kw}^{-}+\eta}{n_{k\cdot}^{-}+V\eta}.(ndk−​+α)nk⋅−​+Vηnkw−​+η​.
Доказательство

Условная вероятность пары «назначение kkk, слово www» получается умножением двух предсказательных вероятностей Дирихле. Первая имеет знаменатель nd⋅−+Kαn_{d\cdot}^{-}+K\alphand⋅−​+Kα, одинаковый для всех kkk, поэтому он сокращается при нормировании. Вторая использует апостериор по словам внутри kkk. После получения весов делим каждый на их сумму. Положительные приоры сохраняют ненулевую вероятность темы и для пустых счётчиков.

topic_model.py
"""Малый LDA с симметричными приорами и collapsed Gibbs."""

import numpy as np


def fit_topics(documents, vocabulary, topics, *, alpha=.3, eta=.2, sweeps=60, seed=11):
    if not (vocabulary > 0 and topics > 0 and alpha > 0 and eta > 0 and sweeps >= 1):
        raise ValueError("positive sizes, priors and sweeps are required")
    docs = [list(document) for document in documents]
    if any(not 0 <= word < vocabulary for doc in docs for word in doc):
        raise ValueError("word outside vocabulary")
    rng = np.random.default_rng(seed)
    n_doc = np.zeros((len(docs), topics), dtype=int)
    n_word = np.zeros((topics, vocabulary), dtype=int)
    n_topic = np.zeros(topics, dtype=int)
    states = [rng.integers(topics, size=len(doc)) for doc in docs]

    for d, doc in enumerate(docs):
        for word, topic in zip(doc, states[d]):
            n_doc[d, topic] += 1
            n_word[topic, word] += 1
            n_topic[topic] += 1

    for _ in range(sweeps):
        for d, doc in enumerate(docs):
            for pos, word in enumerate(doc):
                old = states[d][pos]
                n_doc[d, old] -= 1
                n_word[old, word] -= 1
                n_topic[old] -= 1

                weights = (n_doc[d] + alpha) * (
                    (n_word[:, word] + eta) / (n_topic + vocabulary * eta)
                )
                new = rng.choice(topics, p=weights / weights.sum())
                states[d][pos] = new
                n_doc[d, new] += 1
                n_word[new, word] += 1
                n_topic[new] += 1

    theta = (n_doc + alpha) / (n_doc.sum(axis=1, keepdims=True) + topics * alpha)
    phi = (n_word + eta) / (n_topic[:, None] + vocabulary * eta)
    return theta, phi, states


def infer_topics(document, phi, *, alpha=.3, sweeps=60, seed=11):
    """Вывод для нового документа при фиксированных распределениях слов."""
    words = list(document)
    if any(not 0 <= word < phi.shape[1] for word in words):
        raise ValueError("word outside vocabulary")
    if not (alpha > 0 and sweeps >= 1 and np.all(phi > 0)):
        raise ValueError("positive priors, probabilities and sweeps are required")
    rng = np.random.default_rng(seed)
    topics = phi.shape[0]
    states = rng.integers(topics, size=len(words))
    counts = np.bincount(states, minlength=topics)
    for _ in range(sweeps):
        for pos, word in enumerate(words):
            counts[states[pos]] -= 1
            weights = (counts + alpha) * phi[:, word]
            states[pos] = rng.choice(topics, p=weights / weights.sum())
            counts[states[pos]] += 1
    return (counts + alpha) / (len(words) + topics * alpha)

Сначала fit_topics закрепляет случайную тему за каждым токеном и заполняет три массива счётчиков. На шаге старое назначение вычитается до вычисления веса, новое добавляется после сэмплирования. Один полный проход требует O(K)O(K)O(K) работы на токен. Возвращаемые θ,ϕ\theta,\phiθ,ϕ — сглаженные оценки, условные на последнем состоянии цепи. Для оценки апостериорного среднего обычно усредняют после прогрева и проверяют чувствительность к нескольким цепям и параметрам. Не нужно интерпретировать отдельную тему как установленную предметную категорию без содержательной проверки.

Новый документ и оценка качества​

В infer_topics словарь и ϕ\phiϕ заморожены. Полный счётчик корпуса больше не меняется, поэтому условный вес становится (ndk−+α)ϕkw(n_{dk}^{-}+\alpha)\phi_{kw}(ndk−​+α)ϕkw​. Неизвестные термины можно удалить при кодировании и отдельно посчитать их долю. Для пустого документа оценки тем равномерны. Это априор в выбранной модели, а для выдачи полезно хранить отдельно признак отсутствия наблюдаемых слов.

Сохраните модуль как topic_model.py и запустите пример с четырьмя токенами в словаре.

from topic_model import fit_topics, infer_topics

documents = [[0, 0, 1], [0, 1, 1], [2, 2, 3], [2, 3, 3]]
theta, phi, _ = fit_topics(documents, vocabulary=4, topics=2)
print(infer_topics([0, 0, 1], phi).round(3))

Векторы θd\theta_dθd​ можно объединять в профиль и сравнивать по косинусу. Другой пример — расстояние Йенсена–Шеннона. Вероятностное качество на отложенных токенах и качество рекомендаций оценивают раздельно. Уменьшение неопределённости о словах не гарантирует улучшения top-kkk по кликам.

Упражнение · Снять текущее назначение

Что изменится, если при обновлении не убрать старую тему токена из счётчиков?

Разбор

Старая тема получит собственный токен в числителях обоих множителей, а число токенов в теме тоже будет смещено. Получится условное распределение с использованием величины, которую как раз требуется пересэмплировать. Такой переход не соответствует формуле Гиббса.
