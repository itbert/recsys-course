Воспроизводимый эксперимент по офлайн-оценке

Данные и протокол​

Новый генератор развивает временной контракт части 6. Все числа в эксперименте синтетические. У каждого пользователя есть известная категория интереса и скрытый общий уровень активности. Для каждой допустимой пары генерируется бинарный исход, а для единиц — степень 1 или 2. Вероятность единицы зависит от совпадения темы, объекта и скрытой активности. Поэтому результаты одного пользователя образуют кластер. Два объекта случайно выбираются как показанные в каждом запросе независимо от сгенерированного исхода.

Обучение в T=100T=100T=100 использует только показанные исходы с t+6+3≤100t+6+3\le100t+6+3≤100. Это консервативная граница зрелости. Сам генератор хранит итоговую метку и не моделирует отдельный процесс доставки. Объект 10 появляется в 100, объект 11 разрешён только северному региону. Набор кандидатов строится по моменту запроса и региону, отдельно от grade. Тестовый блок [100,130)[100,130)[100,130) состоит из новых пользователей. Снимок оценки назначен на 139, когда выполнена та же граница зрелости для всего блока.

A строит сглаженную долю единиц по объекту с глобальной обучающей частотой в качестве опоры. B уточняет её по паре «заявленная тема пользователя, объект». Пусть cic_ici​ и sis_isi​ — число показов и сумма единиц объекта, p^0\hat p_0p^​0​ — доля единиц train, cx,i,sx,ic_{x,i},s_{x,i}cx,i​,sx,i​ — те же счётчики в теме xxx. Тогда

pA(i)=si+4p^0ci+4,pB(i,x)=sx,i+6pA(i)cx,i+6.p_A(i)=\frac{s_i+4\hat p_0}{c_i+4},\qquad p_B(i,x)=\frac{s_{x,i}+6p_A(i)}{c_{x,i}+6}.pA​(i)=ci​+4si​+4p^​0​​,pB​(i,x)=cx,i​+6sx,i​+6pA​(i)​.

У холодного объекта оценки опираются на обучающую частоту. Оба правила фиксированы до финальной проверки, настроек по тесту нет. В генераторе тема входит в механизм исхода, поэтому преимущество B ожидаемо. Опыт проверяет метрики и временные границы, а изучение сильных алгоритмов начнётся в части 8.

Результаты на двух областях​

Из 235 зрелых обучающих запросов получено 470 показов. В тесте 179 запросов от 48 пользователей и 358 показанных объектов с исходом. Полные списки ранжируются по всему допустимому каталогу. У двух запросов все grades нулевые. Precision, Hit и MRR используют 179 запросов, Recall, MAP и NDCG — 177. Brier, log loss, AUC и ECE считаются только на 358 одинаковых показах. В таблице среднее AP обозначено MAP.

Разности B − A составляют около 0,157 и 0,171. Это описательные числа для двух срезов. Проверка неоднородности потребовала бы интервала для разности эффектов.

Что ограничивает каскад​

Если оставить top-5 по A и допустить B только к нему, средняя candidate Recall@5 равна 0.413, сквозная NDCG@3 — 0.384, средняя oracle NDCG@3 — 0.526. Сортировка по B на полном каталоге даёт 0.407. У каскада остаётся диапазон для улучшения ranking, но достижимый максимум определяется shortlist каждого запроса. Oracle использует метки теста только после формирования shortlist, поэтому служит диагностикой и не сравнивается как предсказывающая модель.

Запуск​

experiment.py
"""Воспроизводимый офлайн-эксперимент на синтетическом каталоге."""
from collections import Counter, defaultdict
import hashlib
import json
import math
from pathlib import Path
import platform
import random

from comparison import paired_bootstrap
from prediction import binary_auc, probability_report
from ranking import catalog_coverage, diversity, novelty, ranked_ids, ranking_metrics
from sampling import expected_sampled_hit

K = 3
ORIGIN = 100
HORIZON = 6
DELAY = 3
SEED = 2718


def generate(rng, prefix, users, start, end):
    requests = []
    for u in range(users):
        topic = rng.randrange(3)
        activity = rng.uniform(-0.10, 0.10)
        north = rng.choice([False, True])
        for j in range(rng.randint(2, 6)):
            t = rng.randrange(start, end)
            # Объект 10 появляется только после обучения. Объект 11 есть лишь на севере.
            eligible = [i for i in range(12) if (i != 10 or t >= ORIGIN)
                        and (i != 11 or north)]
            grades = {}
            for item in eligible:
                chance = 0.18 + 0.34 * (item % 3 == topic) + 0.02 * (item % 4) + activity
                positive = rng.random() < chance
                grades[item] = (1 + int(rng.random() < (0.65 if item % 3 == topic else 0.25))
                                if positive else 0)
            shown = rng.sample(eligible, 2)
            requests.append({"id": f"{prefix}-{u}-{j}", "user": f"{prefix}-{u}",
                             "t": t, "topic": topic, "north": north,
                             "eligible": eligible, "shown": shown, "grades": grades})
    return sorted(requests, key=lambda q: (q["t"], q["id"]))


def fit(requests):
    counts = Counter()
    positives = Counter()
    topic_counts = Counter()
    topic_positives = Counter()
    for q in requests:
        if q["t"] + HORIZON + DELAY > ORIGIN:
            continue
        for i in q["shown"]:
            y = q["grades"][i] > 0
            counts[i] += 1
            positives[i] += y
            topic_counts[q["topic"], i] += 1
            topic_positives[q["topic"], i] += y
    prior = sum(positives.values()) / sum(counts.values())
    return counts, positives, topic_counts, topic_positives, prior


def scores(model, eligible, topic):
    counts, positives, topic_counts, topic_positives, prior = model
    base = {i: (positives[i] + 4 * prior) / (counts[i] + 4) for i in eligible}
    contextual = {}
    for i, p in base.items():
        key = topic, i
        contextual[i] = (topic_positives[key] + 6 * p) / (topic_counts[key] + 6)
    return {"A": base, "B": contextual}


def mean(values):
    known = [v for v in values if v is not None]
    return math.fsum(known) / len(known) if known else None


def run():
    rng = random.Random(SEED)
    train = generate(rng, "train", 60, 0, ORIGIN)
    # Условно на обучении это независимые новые пользовательские кластеры.
    test = generate(rng, "test", 48, ORIGIN, 130)
    model = fit(train)
    counts = {i: model[0][i] for i in range(12)}
    eligible = {i for q in test for i in q["eligible"]}
    outputs = defaultdict(list)
    deltas = []
    slate = []
    candidate_recall = []
    oracle = []
    for q in test:
        predictions = scores(model, q["eligible"], q["topic"])
        row = {}
        for name, p in predictions.items():
            order = ranked_ids(p)
            metrics = ranking_metrics(order, q["grades"], K)
            outputs[name].append((q, p, order[:K], metrics))
            row[name] = metrics["ndcg"]
        if row["B"] is not None:
            deltas.append((q["user"], row["B"] - row["A"]))
        kept = ranked_ids(predictions["A"])[:5]
        reranked = ranked_ids({i: predictions["B"][i] for i in kept})
        slate.append(ranking_metrics(reranked, q["grades"], K)["ndcg"])
        candidate_recall.append(ranking_metrics(kept, q["grades"], 5)["recall"])
        ideal = ranked_ids({i: q["grades"][i] for i in kept})
        oracle.append(ranking_metrics(ideal, q["grades"], K)["ndcg"])

    report = {}
    for name, rows in outputs.items():
        # Оценка вероятностей проводится только на показанных объектах.
        pairs = [(int(q["grades"][i] > 0), p[i]) for q, p, _, _ in rows for i in q["shown"]]
        report[name] = {
            "ranking": {m: mean([metric[m] for _, _, _, metric in rows])
                        for m in rows[0][3]},
            "ndcg_n": sum(metric["ndcg"] is not None for _, _, _, metric in rows),
            "coverage": catalog_coverage([top for _, _, top, _ in rows], eligible),
            "diversity": mean([diversity(top, lambda a, b: int(a % 3 != b % 3))
                               for _, _, top, _ in rows]),
            "novelty_bits": mean([novelty(top, counts) for _, _, top, _ in rows]),
            "probability": probability_report(pairs, bins=5),
            "auc": binary_auc(pairs),
            "ndcg_by_region": {
                region: {"mean": mean([m["ndcg"] for q, _, _, m in rows if q["north"] == north]),
                         "n": sum(q["north"] == north and m["ndcg"] is not None
                                  for q, _, _, m in rows)}
                for region, north in [("north", True), ("south", False)]
            },
        }

    sources = ("ranking.py", "prediction.py", "sampling.py", "comparison.py", "experiment.py")
    root = Path(__file__).parent
    return {
        "manifest": {
            "python": platform.python_version(), "seed": SEED, "k": K, "origin": ORIGIN,
            "horizon": HORIZON, "delay": DELAY, "test_interval": [100, 130],
            "score_cutoff": 139, "bootstrap_seed": 7, "bootstrap_draws": 2000,
            "source_sha256": {p: hashlib.sha256((root / p).read_bytes()).hexdigest() for p in sources},
            "data_sha256": hashlib.sha256(json.dumps([train, test], sort_keys=True,
                                                    separators=(",", ":")).encode()).hexdigest(),
        },
        "sizes": {"mature_train": sum(q["t"] + HORIZON + DELAY <= ORIGIN for q in train),
                  "test": len(test), "test_users": len({q["user"] for q in test}),
                  "shown_test": sum(len(q["shown"]) for q in test)},
        "models": report,
        "cascade": {"candidate_recall": mean(candidate_recall), "ndcg": mean(slate),
                    "oracle_ndcg": mean(oracle)},
        "delta": {w: paired_bootstrap(deltas, weighting=w) for w in ("request", "user")},
        "sampling": {
            "full_hit": [0.5, 0.0],
            "expected_sampled_hit": [
                float(sum(expected_sampled_hit(100, r, 10, 1) for r in ranks) / 2)
                for ranks in [(1, 100), (2, 2)]
            ],
        },
    }


if __name__ == "__main__":
    result = run()
    Path(__file__).with_name("report.json").write_text(
        json.dumps(result, ensure_ascii=False, indent=2, allow_nan=False) + "\n"
    )
    print(json.dumps({"sizes": result["sizes"], "delta": result["delta"],
                      "sampling": result["sampling"]}, ensure_ascii=False, indent=2))

Сохраните пять приведённых модулей в одной папке. Это prediction.py, ranking.py, sampling.py, comparison.py и experiment.py. В Python 3.13.3 команда python3 experiment.py создаёт report.json. В нём зафиксированы версии, моменты обучения и оценки, параметры bootstrap, хеши данных и исходников. Вычисления работают без скачивания данных.

generate задаёт каталог и истины по заданным seed и контракту. fit использует только индексы показанных объектов зрелой обучающей когорты. scores получает список допустимых ID и тему, без grade. Затем один и тот же order оценивается на независимой от скоринга разметке. paired_bootstrap получает по одной разности для каждого из 177 допустимых запросов. Смена веса влияет на финальный агрегат, сохраняя одни и те же пары оценок.

Упражнение · Перенос на неполные данные

В промышленном журнале из этого примера сохранились только два показанных объекта на запрос и их отклики. Что из отчёта можно пересчитать?

Разбор

При наличии прогнозов можно пересчитать Brier, log loss, AUC и ECE на тех же зрелых показах. При наличии самих новых списков и доступных каталогов можно посчитать покрытие и признаки состава. Полную NDCG с прежними grade и oracle всего shortlist восстановить нельзя. Потребуется новая область разметки либо другой контракт.

Упражнение · Нулевой доход от высокой полноты

Один генератор вернул каждый позитив, но соблюдение бюджета заставляет ranker оставить три места из двадцати. Следует ли из candidate Recall 1, что Recall@3 тоже может достичь 1?

Разбор

Только если число позитивов не больше трёх. При R>3R>3R>3 итоговая полнота ограничена 3/R3/R3/R, даже при идеальной сортировке. Полнота генератора относится к shortlist, а итоговый список имеет более жёсткое ограничение.
