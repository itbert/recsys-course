Полная и выборочная оценка ranking

Что означает полный каталог​

Полная оценка сортирует либо точно выбирает top-KKK по всем объектам Uq\mathcal U_qUq​. Здесь «полная» относится к области сравнения. Если релевантность известна лишь для отложенных позитивов, полнота сортировки не создаёт разметку остальных объектов. Как минимум фиксируем размер области, правила доступности и смысл нулей.

В sampled-протоколе известные позитивы объединяют с выбранными альтернативами. Позиции меняются даже при замороженных scores. Использование общей выборки для двух моделей снижает шум сравнения при положительной ковариации, но целевая метрика остаётся выборочной. Работы по оценке при выборке показывают, что различие с полной метрикой сохраняется и в ожидании. Krichene и Rendle, 2020

Точное распределение при одном позитиве​

Пусть в каталоге NNN объектов и единственный позитив занимает ранг rrr после разрешения ties. Добавим к нему mmm различных элементов, равномерно отобранных из остальных N−1N-1N−1. Обозначим через XXX число выбранных объектов, стоящих выше позитива в полной выдаче.

Лемма · Гипергеометрический ранг#

Выборочный ранг r~=1+X\widetilde r=1+Xr=1+X. При отборе без возвращения

P(X=x)=(r−1x)(N−rm−x)(N−1m),\Prob(X=x)=\frac{\binom{r-1}{x}\binom{N-r}{m-x}}{\binom{N-1}{m}},P(X=x)=(mN−1​)(xr−1​)(m−xN−r​)​,

где недопустимые сочетания дают нулевой вклад.

Доказательство

Чтобы получить xxx объектов выше позитива, выбираем xxx из r−1r-1r−1 стоящих выше и остальные m−xm-xm−x из N−rN-rN−r стоящих ниже. Делим число таких подмножеств на число равновероятных выборок размера mmm. Все выбранные объекты выше позитива и только они сдвигают его ранг на одну позицию.

При независимых извлечениях с возвращением XXX биномиален с параметрами m,(r−1)/(N−1)m,(r-1)/(N-1)m,(r−1)/(N−1) при сохранении каждой копии как отдельного сравнения. Если удалить дубли или выбирать популярные объекты с разными вероятностями, гипергеометрическая формула неприменима.

Смена победителя​

Возьмём два запроса с N=100N=100N=100. У A полные ранги позитива (1,100)(1,100)(1,100), у B (2,2)(2,2)(2,2). Полный Hit@1 равен 1/21/21/2 у A и 000 у B. При любом m≥1m\ge1m≥1 у A условные Hit всегда 1 и 0. У B единственная помеха включается с вероятностью m/99m/99m/99. Поэтому при m=10m=10m=10 ожидаемый средний Hit@1 у B равен 89/9989/9989/99, выше 1/21/21/2.

Увеличение числа повторных выборок при фиксированном mmm приближает ожидание выборочной метрики. Чтобы сравнить с полным Hit@1, нужно менять область вычисления или ввести отдельный метод оценивания, который использует дополнительные предпосылки. В частности, вес технического отбора из части 6 восстанавливает аддитивную сумму фиксированных потерь, а Hit — нелинейная функция полного ранга.

Когда среднее сохраняется​

При одном позитиве и отсутствии ties в полной выдаче AUC равна (N−r)/(N−1)(N-r)/(N-1)(N−r)/(N−1). На выборке из mmm объектов она равна 1−X/m1-X/m1−X/m. Каждый отрицательный объект включён с вероятностью m/(N−1)m/(N-1)m/(N−1), следовательно E[X]=m(r−1)/(N−1)\E[X]=m(r-1)/(N-1)E[X]=m(r−1)/(N−1). Подстановка даёт полную AUC в ожидании. Это свойство линейного подсчёта пар, и оно зависит от дизайна отбора. Для выборочного Hit аналогичный вывод не проходит. Rendle, 2019, раздел 4.5

sampling.py
"""Точное распределение выборочной позиции одного релевантного объекта."""
from fractions import Fraction
from math import comb


def sampled_rank_distribution(catalog_size, full_rank, negatives):
    n = catalog_size - 1
    if n < 1 or not 1 <= full_rank <= catalog_size or not 1 <= negatives <= n:
        raise ValueError("Нужны корректные позиция и размер непустой выборки")
    above = full_rank - 1
    below = n - above
    total = comb(n, negatives)
    return [
        (x + 1, Fraction(comb(above, x) * comb(below, negatives - x), total))
        for x in range(max(0, negatives - below), min(above, negatives) + 1)
    ]


def expected_sampled_hit(catalog_size, full_rank, negatives, k):
    if k < 1:
        raise ValueError("K должен быть положительным")
    return sum((p for rank, p in sampled_rank_distribution(catalog_size, full_rank, negatives)
                if rank <= k), Fraction(0))

Код строит только допустимую поддержку XXX и использует целые сочетания и точные дроби. Это вычисление до m+1m+1m+1 слагаемых, подходящее для учебных размеров. Для больших параметров нужна численно устойчивая реализация CDF или оценка с явно измеренной ошибкой.
