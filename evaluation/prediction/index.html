Рейтинги, вероятности и AUC

Числовой рейтинг​

Пусть yjy_jyj​ — явный рейтинг, y^j\hat y_jy^​j​ — прогноз. На nnn наблюдаемых парах считаем

MAE⁡=1n∑j=1n∣yj−y^j∣,RMSE⁡=1n∑j=1n(yj−y^j)2.\operatorname{MAE}=\frac1n\sum_{j=1}^n|y_j-\hat y_j|,\qquad \operatorname{RMSE}=\sqrt{\frac1n\sum_{j=1}^n(y_j-\hat y_j)^2}.MAE=n1​j=1∑n​∣yj​−y^​j​∣,RMSE=n1​j=1∑n​(yj​−y^​j​)2​.

Обе величины имеют единицы исходного рейтинга. RMSE сильнее реагирует на большие ошибки. При ошибках (1,1,4)(1,1,4)(1,1,4) MAE равна 222, RMSE равна 6\sqrt66​. Сильно различающиеся шкалы рейтингов требуют согласованного определения цели. Отсутствующий рейтинг сохраняет маску наблюдения, поэтому в знаменатель входят только допустимые измеренные пары. Подробный вывод условного среднего и медианы как решений соответствующих задач риска приведён в части 5.

Положим, модель для двух объектов дала истинные оценки (5,4)(5,4)(5,4) с прогнозами (3,2)(3,2)(3,2), а другая — (4,5)(4,5)(4,5). У второй MAE ниже, но она переставила объекты. Поэтому метрику выбирают после определения решения, которое будет принято по прогнозу.

Бинарная вероятность​

Для наблюдённого y∈{0,1}y\in\{0,1\}y∈{0,1} и p∈[0,1]p\in[0,1]p∈[0,1] квадратичная потеря Брайера равна (y−p)2(y-p)^2(y−p)2. Логарифмическая потеря при y=1y=1y=1 равна −log⁡p-\log p−logp, при y=0y=0y=0 равна −log⁡(1−p)-\log(1-p)−log(1−p). Если модель присвоила реализовавшемуся исходу вероятность 0, логарифмическая потеря бесконечна. Объявленный clipping даёт другой оцениваемый прогноз и должен одинаково применяться ко всем моделям.

Теорема · Строгая правильность бинарных потерь#

При истинной вероятности η\etaη математическое ожидание каждой из этих потерь минимально при p=ηp=\etap=η, включая граничные случаи η=0,1\eta=0,1η=0,1.

Для квадратичной потери E[(Y−p)2]=η(1−η)+(p−η)2\E[(Y-p)^2]=\eta(1-\eta)+(p-\eta)^2E[(Y−p)2]=η(1−η)+(p−η)2. Для логарифмической при 0<η,p<10<\eta,p<10<η,p<1 производная условного риска по ppp равна (p−η)/(p(1−p))(p-\eta)/(p(1-p))(p−η)/(p(1−p)). Она меняет знак с отрицательного на положительный только при p=ηp=\etap=η. При η=0\eta=0η=0 или 1 остаётся соответственно возрастающая или убывающая ветвь, минимум достигается на соответствующей границе.

AUC по парам​

При наличии обоих классов эмпирическая ROC AUC равна доле упорядоченных пар «позитив, негатив», в которых score первого выше, с половиной балла за равенство.

AUC^=1n+n−∑i:yi=1∑j:yj=0(1{si>sj}+121{si=sj}).\widehat{\mathrm{AUC}}=\frac{1}{n_+n_-}\sum_{i:y_i=1}\sum_{j:y_j=0} \left(\mathbf1\{s_i>s_j\}+\tfrac12\mathbf1\{s_i=s_j\}\right).AUC=n+​n−​1​i:yi​=1∑​j:yj​=0∑​(1{si​>sj​}+21​1{si​=sj​}).

Глобальная AUC включает пары из разных запросов. При сравнении внутри запроса сначала формируют пары одного qqq, затем выбирают среднее по запросам или парам. Масштабы score, безопасные для локального порядка, могут поменять глобальную AUC. При одном классе код возвращает None. Строго возрастающее преобразование score сохраняет все парные сравнения, но меняет вероятность, log loss и Brier. Высокая AUC возможна даже при ошибках во всех решающих верхних позициях, если большинство остальных пар упорядочены верно.

Precision–Recall кривая также зависит от порога, но её precision чувствительна к доле единиц. Площадь под кривой по выбранному правилу интерполяции и AP по глобальному списку требуют явного соглашения. AP@K одного запроса из следующей главы имеет другую область усреднения.

prediction.py
"""Ошибки рейтингов, вероятностные потери и группировка для калибровки."""
import math


def rating_errors(pairs):
    errors = [p - y for y, p in pairs]
    if not errors or any(not math.isfinite(e) for e in errors):
        raise ValueError("Нужны конечные пары рейтингов")
    return {
        "mae": math.fsum(map(abs, errors)) / len(errors),
        "rmse": math.sqrt(math.fsum(e * e for e in errors) / len(errors)),
    }


def probability_report(pairs, bins=5):
    pairs = list(pairs)
    if not pairs or bins < 1 or any(y not in (0, 1) or not 0 <= p <= 1 for y, p in pairs):
        raise ValueError("Нужны бинарные исходы и вероятности от 0 до 1")
    groups = [[] for _ in range(bins)]
    losses = []
    for y, p in pairs:
        groups[min(int(p * bins), bins - 1)].append((y, p))
        if y:
            losses.append(-math.log(p) if p > 0 else math.inf)
        else:
            losses.append(-math.log1p(-p) if p < 1 else math.inf)

    reliability = []
    for j, group in enumerate(groups):
        if group:
            n = len(group)
            reliability.append({"bin": j, "n": n,
                                "prediction": math.fsum(p for _, p in group) / n,
                                "frequency": sum(y for y, _ in group) / n})
    return {
        "brier": math.fsum((y - p)**2 for y, p in pairs) / len(pairs),
        "log_loss": math.fsum(losses) / len(pairs),
        "ece": math.fsum(b["n"] * abs(b["prediction"] - b["frequency"])
                         for b in reliability) / len(pairs),
        "bins": reliability,
    }


def binary_auc(pairs):
    """Одна точка на упорядоченную пару классов; совпадение score даёт половину."""
    pairs = list(pairs)
    if any(y not in (0, 1) or not math.isfinite(score) for y, score in pairs):
        raise ValueError("Нужны бинарные исходы и конечные scores")
    positive = [s for y, s in pairs if y == 1]
    negative = [s for y, s in pairs if y == 0]
    if not positive or not negative:
        return None
    wins = sum((p > n) + 0.5 * (p == n) for p in positive for n in negative)
    return wins / (len(positive) * len(negative))

rating_errors получает пары в порядке «истина, прогноз». probability_report считает потери и готовит корзины для главы о калибровке. binary_auc напрямую перебирает n+n−n_+n_-n+​n−​ пар. На больших таблицах сортировка и подсчёт блоков равных score дают вычисление за O(nlog⁡n)O(n\log n)O(nlogn).
