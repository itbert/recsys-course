Slate, покрытие, разнообразие и новизна

Полезность всего списка​

В ранжировании с DCG каждый элемент даёт аддитивный вклад, зависящий от позиции. В задаче выбора slate может быть важна совместная величина Uq(S)U_q(S)Uq​(S), например число разных удовлетворённых потребностей, хотя бы один успех или смесь нескольких ограничений. Тогда полезность объекта может зависеть от уже выбранных элементов.

Пример · Два результата об одной теме

Пусть U(S)U(S)U(S) равно числу покрытых тем. В каталоге A и B относятся к теме 1, C — к теме 2. При K=2K=2K=2 списки (A,B)(A,B)(A,B) и (A,C)(A,C)(A,C) имеют полезность 1 и 2. Все три одиночных списка имеют полезность 1.

Лемма · Совместная полезность может быть неаддитивной#

Для такой функции UUU не существует весов viv_ivi​ с U(S)=∑i∈SviU(S)=\sum_{i\in S}v_iU(S)=∑i∈S​vi​ для всех подмножеств.

Доказательство

Одиночные списки требуют vA=vB=vC=1v_A=v_B=v_C=1vA​=vB​=vC​=1. Тогда U({A,B})U(\{A,B\})U({A,B}) по сумме равнялась бы 2, хотя покрыта одна тема.

□

Офлайн можно вычислять заданную размеченную функцию списка. Если требуется наблюдаемая реакция на конкретное сочетание и порядок, история другого slate не даёт все его исходы. При фиксированных item-level метках NDCG остаётся валидным вычислением для своей аддитивной цели. Взаимодействие объектов и дизайн онлайн-проверки требуют отдельной постановки.

Внутрисписочное разнообразие​

Пусть d(i,j)∈[0,1]d(i,j)\in[0,1]d(i,j)∈[0,1] симметрична и кодирует различие по темам, категориям или признакам. Для списка фактической длины k≥2k\ge2k≥2 определим

ILD(S)=2k(k−1)∑a<bd(ia,ib).\mathrm{ILD}(S)=\frac{2}{k(k-1)}\sum_{a<b}d(i_a,i_b).ILD(S)=k(k−1)2​a<b∑​d(ia​,ib​).

При длине меньше двух ILD пропускается. Публикуется и доля таких списков. При d=1−simd=1-\mathrm{sim}d=1−sim среднее расстояние равно единице минус среднее сходство при одинаковой нормировке пар. Если использовать d=1−cos⁡d=1-\cosd=1−cos на произвольных векторах, диапазон будет [0,2][0,2][0,2]. Для диапазона [0,1][0,1][0,1] можно взять (1−cos⁡)/2(1-\cos)/2(1−cos)/2 и явно задать правило для нулевых векторов. Базовая идея внутрисписочного сходства развита в работе по тематической диверсификации. Ziegler и соавторы, 2005

Для трёх объектов с темами (1,1,2)(1,1,2)(1,1,2) и индикатором различия ILD равна 2/32/32/3. Можно дать больший вес парам на верхних позициях, но знаменатель тогда равен сумме весов пар. Код использует равные веса и перебирает k(k−1)/2k(k-1)/2k(k−1)/2 пар.

Покрытие и концентрация​

Для когорты запросов QQQ пусть U∪=⋃q∈QUq\mathcal U_\cup=\bigcup_{q\in Q}\mathcal U_qU∪​=⋃q∈Q​Uq​. Покрытие каталога равно

Coverage=∣⋃q∈Q{i:i∈Sq}∣∣U∪∣.\mathrm{Coverage}=\frac{|\bigcup_{q\in Q}\{i:i\in S_q\}|}{|\mathcal U_\cup|}.Coverage=∣U∪​∣∣⋃q∈Q​{i:i∈Sq​}∣​.

Это доля объектов, показанных хотя бы раз. Размер когорты, глубина и распределение контекстов влияют на показатель. Объект, недоступный всем запросам когорты, не входит в знаменатель. User coverage использует иной знаменатель, например долю запросов с непустым допустимым результатом. Для сравнения фиксируют обе области и правило обработки отказов.

Покрытие не различает одну экспозицию и тысячи. Если eie_iei​ — число рекомендованных слотов объекта, полезно дополнительно анализировать доли ei/∑jeje_i/\sum_j e_jei​/∑j​ej​, концентрацию и хвост из части 4. Один длинный хвост редких показов может сосуществовать с высокой долей экспозиций у небольшого числа объектов. Для позиции можно ввести заранее заданный вес, измеряя уже взвешенную экспозицию.

Новизна и калибровка состава​

Обозначим cic_ici​ исторический счётчик показов, NNN — размер его справочника, α>0\alpha>0α>0 — сглаживание. В учебном коде

pi=ci+α∑jcj+αN,Novelty(S)=1∣S∣∑i∈S−log⁡2pi.p_i=\frac{c_i+\alpha}{\sum_j c_j+\alpha N},\qquad \mathrm{Novelty}(S)=\frac1{|S|}\sum_{i\in S}-\log_2 p_i.pi​=∑j​cj​+αNci​+α​,Novelty(S)=∣S∣1​i∈S∑​−log2​pi​.

Единица — бит. Для нового объекта ci=0c_i=0ci​=0 остаётся конечный положительный шанс. Эти числа описывают редкость относительно исторических показов. Индивидуальная новизна требует истории конкретного пользователя, а удачная неожиданность требует ещё определения полезности. Различные модели новизны, релевантности и позиционных весов обсуждаются в оригинальной статье. Vargas и Castells, 2011

Если задачу формулируют как соответствие тематических долей списка целевому профилю pup_upu​, можно измерять 12∑c∣pu(c)−p^S(c)∣\tfrac12\sum_c|p_u(c)-\widehat p_S(c)|21​∑c​∣pu​(c)−p​S​(c)∣. Например, для профиля (0,8,0,2)(0{,}8,0{,}2)(0,8,0,2) и списка (0,5,0,5)(0{,}5,0{,}5)(0,5,0,5) расстояние равно 0,30{,}30,3. Целевой профиль и его происхождение задаются до сравнения. Это оценка состава рекомендаций. Проверка вероятностей бинарного исхода требует другого определения из следующей главы.

Упражнение · Одинаковые списки на всём трафике

Каждому пользователю выдаются одни и те же четыре объекта разных тем из 100 допустимых. Каковы ILD и покрытие?

Разбор

ILD равна 1 по индикатору различия тем. Покрытие равно 4/100=0,044/100=0{,}044/100=0,04. Первая метрика относится к списку, вторая — к объединению списков.

Упражнение · Один бит

При фиксированном историческом распределении заменили один объект в списке длины 4 на объект вдвое меньшей вероятности. Как изменится средняя новизна?

Разбор

Новый вклад выше на −log⁡2(p/2)+log⁡2p=1-\log_2(p/2)+\log_2 p=1−log2​(p/2)+log2​p=1 бит. Средняя по списку вырастет на 1/41/41/4 бита. Из этого ничего не следует о релевантности замены.
