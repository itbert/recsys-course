Счётчики и процесс Пуассона

События вместо значений на сетке​

Пусть события происходят в моменты 0<t1<t2<…0<t_1<t_2<\ldots0<t1​<t2​<…. Считающий процесс

N(t)=∑i1{ti≤t}N(t)=\sum_i\mathbf1\{t_i\le t\}N(t)=i∑​1{ti​≤t}

хранит число событий к времени ttt. У простого процесса в точном времени нет одновременных событий; траектория не убывает и имеет единичные скачки. Если источник округляет время и появляются совпадения отметок, нужно отдельно определить измерение: математическая простота не исправляется произвольной перестановкой равных времён.

Счётчик N(t)N(t)N(t) и интервальное приращение N(t+h)−N(t)N(t+h)-N(t)N(t+h)−N(t) — разные величины. Первый накапливается, второй описывает события отдельного окна. Стационарные приращения не означают стационарности самого накопленного N(t)N(t)N(t).

Пуассоновское распределение​

Для параметра a>0a>0a>0 величина K∼Pois⁡(a)K\sim\operatorname{Pois}(a)K∼Pois(a) имеет вероятности

P(K=k)=e−aakk!,k=0,1,….\Prob(K=k)=e^{-a}\frac{a^k}{k!},\quad k=0,1,\ldots.P(K=k)=e−ak!ak​,k=0,1,….

Её среднее и дисперсия равны aaa. Первое равенство получается сдвигом индекса в сумме ∑kke−aak/k!\sum_k k e^{-a}a^k/k!∑k​ke−aak/k!. Аналогично E[K(K−1)]=a2\E[K(K-1)]=a^2E[K(K−1)]=a2, откуда Var⁡(K)=a\operatorname{Var}(K)=aVar(K)=a. При a=0a=0a=0 величина равна нулю с вероятностью 1.

Определение · Однородный процесс Пуассона#

При N(0)=0N(0)=0N(0)=0 процесс с интенсивностью λ≥0\lambda\ge0λ≥0 имеет независимые приращения на непересекающихся интервалах и

N(t+h)−N(t)∼Pois⁡(λh),h≥0.N(t+h)-N(t)\sim\operatorname{Pois}(\lambda h),\qquad h\ge0.N(t+h)−N(t)∼Pois(λh),h≥0.

Распределение приращения зависит от длины, но не от положения интервала.

Интенсивность измеряется в событиях на единицу времени. Она может быть больше 1 и не является вероятностью. Для малого hhh вероятность одного события равна λh+o(h)\lambda h+o(h)λh+o(h), а вероятность двух и более — o(h)o(h)o(h).

Эта модель задаёт сильные ограничения. Недельный календарный профиль или зависимость событий от истории ей непосредственно не соответствуют. Из хорошего среднего счётчика ещё не следует независимость приращений.

Время ожидания​

Лемма · Первое ожидание при λ > 0#

Если WWW — время до первого события однородного процесса Пуассона, то

P(W>s)=e−λs,fW(s)=λe−λs,s>0.\Prob(W>s)=e^{-\lambda s},\qquad f_W(s)=\lambda e^{-\lambda s},\quad s>0.P(W>s)=e−λs,fW​(s)=λe−λs,s>0.

Среднее ожидание равно 1/λ1/\lambda1/λ.

Доказательство

Условие W>sW>sW>s эквивалентно отсутствию событий к sss. Вероятность N(s)=0N(s)=0N(s)=0 равна e−λse^{-\lambda s}e−λs. Производная функции распределения даёт плотность, а интеграл функции выживания ∫0∞e−λs ds\int_0^\infty e^{-\lambda s}\,ds∫0∞​e−λsds — среднее.

□

Функцией выживания называется P(W>s)\Prob(W>s)P(W>s): здесь речь идёт о ненаступлении события, а не обязательно о физическом выживании. Для экспоненциального ожидания P(W>s+u∣W>s)=e−λu\Prob(W>s+u\mid W>s)=e^{-\lambda u}P(W>s+u∣W>s)=e−λu. Оно не помнит уже прошедшего ожидания. Другие законы длительности в общем случае этим свойством не обладают.

При U∼Uniform⁡(0,1)U\sim\operatorname{Uniform}(0,1)U∼Uniform(0,1) преобразование W=−log⁡(1−U)/λW=-\log(1-U)/\lambdaW=−log(1−U)/λ имеет это распределение. Независимые такие ожидания позволяют строить пуассоновскую последовательность; функция ниже реализует сам шаг преобразования.

Оценивание и наблюдаемое окно​

При наблюдении упорядоченных точных времён nnn событий в (0,T)(0,T)(0,T) без скрытой части интервала правдоподобие по λ\lambdaλ имеет вид

L(λ)=λne−λT,ℓ(λ)=nlog⁡λ−λT.L(\lambda)=\lambda^n e^{-\lambda T},\qquad \ell(\lambda)=n\log\lambda-\lambda T.L(λ)=λne−λT,ℓ(λ)=nlogλ−λT.

При n>0n>0n>0 производная n/λ−Tn/\lambda-Tn/λ−T даёт максимум λ^=n/T\widehat\lambda=n/Tλ=n/T. При n=0n=0n=0 максимум достигается на границе λ=0\lambda=0λ=0. Если наблюдается только суммарный счётчик, логарифм его вероятности содержит также nlog⁡T−log⁡n!n\log T-\log n!nlogT−logn!; это константа относительно λ\lambdaλ, но численно другое правдоподобие.

Обозначение и вывод через условные плотности приведены у Rasmussen в Temporal Point Processes and the Conditional Intensity Function. Наша реализация возвращает логарифм плотности упорядоченных времён, опуская только не зависящие от параметра соглашения базовой меры.

events.py — пуассоновская часть
"""Пуассоновская модель и экспоненциальная интенсивность Hawkes без предыстории."""
import math


def poisson_rate(count, duration):
    if type(count) is not int or count < 0 or not math.isfinite(duration) or duration <= 0:
        raise ValueError("Нужны count>=0 и положительная длительность")
    return count/duration


def poisson_log_likelihood(count, duration, rate):
    poisson_rate(count, duration)
    if not math.isfinite(rate) or rate < 0:
        raise ValueError("Интенсивность должна быть неотрицательной")
    if rate == 0:
        return 0.0 if count == 0 else -math.inf
    return count*math.log(rate)-rate*duration


def exponential_wait(uniform, rate):
    if not 0 < uniform < 1 or not math.isfinite(rate) or rate <= 0:
        raise ValueError("Нужны 0<U<1 и rate>0")
    return -math.log1p(-uniform)/rate


duration — фактическая длина достаточного наблюдения в выбранной единице. При потере событий оценка n/Tn/Tn/T может отражать регистрацию, а не реальную частоту. Исключение неизвестных интервалов тоже требует понимания отбора: если они чаще возникают при высоком потоке, оставшаяся часть не представляет исходный режим автоматически.

Для λ=0\lambda=0λ=0 код отдельно обрабатывает пустой и непустой паттерны, не вычисляя log⁡0\log0log0. log1p сохраняет точность преобразования ожидания для малых UUU.

Неоднородность и экспозиция​

При заданной неслучайной функции λ(t)≥0\lambda(t)\ge0λ(t)≥0 неоднородный пуассоновский процесс имеет независимые приращения с параметром ∫abλ(s)ds\int_a^b\lambda(s)ds∫ab​λ(s)ds на интервале (a,b](a,b](a,b]. Календарная интенсивность меняется, но прошлые события сами по себе её не увеличивают.

Равенство среднего и дисперсии относится к одному заданному распределению счётчика. Смешение интервалов разных интенсивностей может дать большую общую дисперсию. Например, если K∣A∼Pois⁡(A)K\mid A\sim\operatorname{Pois}(A)K∣A∼Pois(A), то по полной дисперсии Var⁡(K)=EA+Var⁡(A)\operatorname{Var}(K)=\E A+\operatorname{Var}(A)Var(K)=EA+Var(A). Поэтому избыток вариации сам по себе ещё не доказывает самовозбуждение.

Для кликов среди фиксированных nnn показов простая модель независимых ответов даёт биномиальное распределение, ограниченное сверху nnn. Пуассоновская модель допускает любые неотрицательные числа и может быть только отдельной моделью или приближением при соответствующих условиях. Время, показы и доступность не являются взаимозаменяемыми знаменателями интенсивности.

Упражнения​

Упражнение · Единицы интенсивности#

Интенсивность равна 2 событиям в минуту. Найдите среднее ожидание в секундах и вероятность отсутствия события за 30 секунд. Почему число 2 допустимо как интенсивность?

Разбор

Среднее ожидание 1/21/21/2 минуты, то есть 30 секунд. Вероятность нуля за половину минуты равна e−2⋅0,5=e−1e^{-2\cdot0{,}5}=e^{-1}e−2⋅0,5=e−1. Интенсивность имеет размерность обратного времени; она не является безразмерной вероятностью.

Упражнение · Смешение частот#

Параметр AAA случайно равен 1 или 9 с равными вероятностями, а K∣A∼Pois⁡(A)K\mid A\sim\operatorname{Pois}(A)K∣A∼Pois(A). Найдите среднее и дисперсию KKK. Следует ли из их неравенства зависимость событий от собственной истории?

Разбор

EA=5\E A=5EA=5, Var⁡(A)=16\operatorname{Var}(A)=16Var(A)=16, поэтому EK=5\E K=5EK=5, Var⁡(K)=21\operatorname{Var}(K)=21Var(K)=21. Различие возникло из смешения интенсивностей. Этот пример не требует механизма самовозбуждения; одного отношения дисперсии к среднему недостаточно для выбора причинной истории.
