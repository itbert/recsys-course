Скрытое состояние и фильтр Калмана

Измерение и состояние​

Наблюдаемый сигнал может содержать шум, тогда как интересующий уровень меняется постепенно. Модель пространства состояний разделяет скрытую величину и измерение. В линейной форме:

Xt=FtXt−1+wt,Yt=HtXt+vt.X_t=F_tX_{t-1}+w_t,\qquad Y_t=H_tX_t+v_t.Xt​=Ft​Xt−1​+wt​,Yt​=Ht​Xt​+vt​.

XtX_tXt​ — вектор состояния, YtY_tYt​ — вектор наблюдения. Матрицы перехода и измерения задают связь величин; распределения wtw_twt​ и vtv_tvt​ задают неопределённость. Общее определение и точное гауссовское решение изложены у Särkkä в Bayesian Filtering and Smoothing, глава 4.

Такая модель может описывать агрегированный меняющийся уровень. Применение к скрытым пользовательским предпочтениям потребует отдельного механизма наблюдения действий; линейный гауссовский шум нельзя молча приписать бинарным кликам.

Скалярный локальный уровень​

Рассмотрим конкретную модель

Xt=Xt−1+wt,wt∼N(0,Q),Yt=Xt+vt,vt∼N(0,R),X_t=X_{t-1}+w_t,\quad w_t\sim N(0,Q),\qquad Y_t=X_t+v_t,\quad v_t\sim N(0,R),Xt​=Xt−1​+wt​,wt​∼N(0,Q),Yt​=Xt​+vt​,vt​∼N(0,R),

где Q≥0Q\ge0Q≥0, R>0R>0R>0, начальное состояние гауссовское, все шумы и начальное состояние взаимно независимы. Параметры пока считаются известными.

После прошлых измерений состояние описывается средним mt−1m_{t-1}mt−1​ и дисперсией Pt−1P_{t-1}Pt−1​. Сначала выполняется прогноз:

mt−=mt−1,Pt−=Pt−1+Q.m_t^-=m_{t-1},\qquad P_t^-=P_{t-1}+Q.mt−​=mt−1​,Pt−​=Pt−1​+Q.

Новое наблюдение даёт инновацию et=yt−mt−e_t=y_t-m_t^-et​=yt​−mt−​ с прогнозной дисперсией St=Pt−+RS_t=P_t^-+RSt​=Pt−​+R. Обновление имеет вид

Kt=Pt−Pt−+R,mt=mt−+Ktet,Pt=(1−Kt)Pt−.K_t=\frac{P_t^-}{P_t^-+R},\qquad m_t=m_t^-+K_te_t,\qquad P_t=(1-K_t)P_t^-.Kt​=Pt−​+RPt−​​,mt​=mt−​+Kt​et​,Pt​=(1−Kt​)Pt−​.

Коэффициент KtK_tKt​ называется усилением Калмана. Он больше при высокой неопределённости состояния относительно шума измерения. При большом RRR новое измерение получает меньший вес.

Откуда берётся усиление​

Теорема · Оптимальное линейное обновление#

Пусть ошибка прогноза состояния имеет дисперсию P−P^-P−, а независимый шум измерения — дисперсию R>0R>0R>0. Среди обновлений m=m−+K(Y−m−)m=m^-+K(Y-m^-)m=m−+K(Y−m−) минимальную среднюю квадратичную ошибку даёт

K=P−P−+R,P=P−RP−+R.K=\frac{P^-}{P^-+R},\qquad P=\frac{P^-R}{P^-+R}.K=P−+RP−​,P=P−+RP−R​.

В совместно гауссовской модели это также точные условные среднее и дисперсия состояния после измерения.

Доказательство

Обозначим ошибку до измерения через u=X−m−u=X-m^-u=X−m−. Ошибка после обновления равна (1−K)u−Kv(1-K)u-Kv(1−K)u−Kv. Независимость и нулевые средние дают

E[(X−m)2]=(1−K)2P−+K2R.\E[(X-m)^2]=(1-K)^2P^-+K^2R.E[(X−m)2]=(1−K)2P−+K2R.

Производная равна −2(1−K)P−+2KR-2(1-K)P^-+2KR−2(1−K)P−+2KR, вторая производная 2(P−+R)>02(P^-+R)>02(P−+R)>0. Единственный минимум имеет указанный KKK; подстановка даёт PPP. В гауссовском случае линейный остаток с этим коэффициентом некоррелирован с наблюдением, а совместная гауссовость превращает некоррелированность в независимость. Поэтому условный закон имеет эти моменты.

□

Без гауссовости вычисленное обновление сохраняет линейную оптимальность при заданных моментах и независимости ошибок, но не обязано совпадать с полным условным ожиданием. Для нелинейных измерений нужны другие методы или приближения.

Пропуски и разные направления времени​

При отсутствии измерения в данном шаге выполняется только прогноз: mt=mt−m_t=m_t^-mt​=mt−​, Pt=Pt−P_t=P_t^-Pt​=Pt−​. Дисперсия накапливает QQQ, поскольку состояние продолжает изменяться. Подстановка yt=0y_t=0yt​=0 вместо пропуска добавила бы вымышленное измерение и неверно уменьшила бы неопределённость.

Такой пропуск обновления предполагает, что сам механизм отсутствия не несёт дополнительной неучтённой информации о состоянии. Если измерения исчезают в зависимости от скрытого уровня, индикатор пропуска тоже может быть информативен.

Фильтрация вычисляет Xt∣Y0:tX_t\mid Y_{0:t}Xt​∣Y0:t​ по доступному прошлому. Сглаживание состояния использует также позднейшие измерения, например Xt∣Y0:TX_t\mid Y_{0:T}Xt​∣Y0:T​ при T>tT>tT>t. Сглаженная оценка прошлого может стать точнее, но её нельзя использовать как исторически доступное состояние без соответствующей задержки.

Код и ручная проверка​

state_space.py — фильтр уровня
"""Скалярная модель уровня, физическое затухание и диагностический CUSUM."""
import math
import numpy as np
from series import vector


def kalman_level(values, process_var=.15, observation_var=1, initial_mean=0, initial_var=1):
    if (not np.isfinite([process_var, observation_var, initial_mean, initial_var]).all()
            or process_var < 0 or observation_var <= 0 or initial_var < 0):
        raise ValueError("Некорректные дисперсии или начальное среднее")
    mean, variance, result = float(initial_mean), float(initial_var), []
    for value in values:
        prior_var = variance + process_var
        if value is None:
            variance = prior_var
            result.append({"mean": mean, "variance": variance, "innovation": None, "gain": 0.0})
            continue
        if not math.isfinite(value):
            raise ValueError("Нужно конечное наблюдение или None")
        innovation = float(value-mean)
        gain = prior_var/(prior_var+observation_var)
        mean += gain*innovation
        variance = (1-gain)*prior_var
        result.append({"mean": mean, "variance": variance, "innovation": innovation, "gain": gain})
    return result


Начальные initial_mean и initial_var относятся к состоянию X−1X_{-1}X−1​ до первого перехода. Поэтому перед первым измерением к дисперсии прибавляется QQQ. В каждой строке результата сохраняются оценка, её дисперсия, инновация и усиление.

Для m−1=0m_{-1}=0m−1​=0, P−1=1P_{-1}=1P−1​=1, Q=1Q=1Q=1, R=3R=3R=3 и первого измерения 5 имеем P0−=2P_0^-=2P0−​=2, K0=2/5K_0=2/5K0​=2/5, m0=2m_0=2m0​=2, P0=6/5P_0=6/5P0​=6/5. Один следующий пропуск даёт P1=11/5P_1=11/5P1​=11/5. Если третье измерение равно 1, то m2=46/31m_2=46/31m2​=46/31, P2=48/31P_2=48/31P2​=48/31.

Эти значения проверены точными дробями. Отдельно весь фильтр сопоставлен с прямым условным распределением совместного гауссовского вектора для каждого префикса наблюдений, включая пропуск. Это проверяет и индексацию переходов, и вычисление неопределённости.

В скалярном случае вычисления линейны по длине ряда. Для многомерных моделей стоимость определяется размерами состояния и линейными системами; численная устойчивость требует внимания к ковариационным матрицам. Здесь дисперсии явно контролируются как неотрицательные параметры.

Упражнения​

Упражнение · Чьё измерение точнее#

При P−=4P^-=4P−=4 сравните KKK для R=1R=1R=1 и R=16R=16R=16. Почему меньший коэффициент во втором случае не означает игнорирование самого изменения состояния?

Разбор

Коэффициенты равны 4/5=0,84/5=0{,}84/5=0,8 и 4/20=0,24/20=0{,}24/20=0,2. Во втором случае отдельное измерение шумнее относительно прогноза. Изменение состояния уже учтено в прогнозной дисперсии через QQQ; меньший вес измерения относится к его информативности, а не к запрету динамики.

Упражнение · Пять пропусков#

После измерения дисперсия состояния равна 2. Следующие пять шагов не содержат измерений, Q=0,3Q=0{,}3Q=0,3. Чему равна новая дисперсия? Что было бы ошибкой при интерпретации среднего?

Разбор

Дисперсия станет 2+5⋅0,3=3,52+5\cdot0{,}3=3{,}52+5⋅0,3=3,5. В локальном уровне прогнозное среднее сохранится, но это не означает, что истинное состояние известно неизменным. Рост неопределённости выражает возможность его изменений без новых измерений.
