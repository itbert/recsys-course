Условная интенсивность и процесс Hawkes

Интенсивность при известной истории​

В неоднородном процессе Пуассона календарная функция интенсивности задана заранее. Для зависимости от предыдущих действий нужна условная интенсивность по истории Ht−\mathcal H_{t-}Ht−​, содержащей события строго до ttt.

Для простого регулярного процесса её локальный смысл задаётся соотношениями

P(N(t+h)−N(t)=1∣Ht−)=λ(t∣Ht−)h+o(h),P(N(t+h)−N(t)≥2∣Ht−)=o(h).\begin{aligned} \Prob(N(t+h)-N(t)=1\mid\mathcal H_{t-}) &=\lambda(t\mid\mathcal H_{t-})h+o(h),\\ \Prob(N(t+h)-N(t)\ge2\mid\mathcal H_{t-})&=o(h). \end{aligned}P(N(t+h)−N(t)=1∣Ht−​)P(N(t+h)−N(t)≥2∣Ht−​)​=λ(t∣Ht−​)h+o(h),=o(h).​

Требуются существование такой локальной характеристики и отсутствие накопления бесконечного числа событий за конечное время. Это не определение для любой произвольной дискретизации или любого зависимого счётчика.

Интенсивность вычисляется по доступному прошлому, а не с включением самого прогнозируемого события. Применение к клиентским логам также требует модели наблюдения: потерянное или ещё не доставленное событие не появляется в истории автоматически.

Правдоподобие всей траектории​

Для наблюдённых времён 0<t1<…<tn<T0<t_1<\ldots<t_n<T0<t1​<…<tn​<T, известной начальной истории и подходящей условной интенсивности

log⁡L=∑i=1nlog⁡λ(ti∣Hti−)−∫0Tλ(s∣Hs−) ds.\log L=\sum_{i=1}^n\log\lambda(t_i\mid\mathcal H_{t_i-}) -\int_0^T\lambda(s\mid\mathcal H_{s-})\,ds.logL=i=1∑n​logλ(ti​∣Hti​−​)−∫0T​λ(s∣Hs−​)ds.

Первый член учитывает интенсивность перед событиями. Второй учитывает промежутки, когда событий не было. Формула получается факторизацией условных плотностей ожиданий: каждая плотность равна интенсивности на конце ожидания, умноженной на вероятность отсутствия события до него. Экспоненты интегралов по промежуткам объединяются в один интеграл, включая ожидание от последнего события до TTT.

Условия и точный вывод представлены у Rasmussen (2018), раздел 3. Конец наблюдения является частью данных: одинаковые события в окнах разной длины имеют разные свидетельства об интенсивности.

Экспоненциальный Hawkes​

Зададим линейную самовозбуждающуюся модель

λ(t∣Ht−)=μ+α∑ti<te−β(t−ti),μ>0, α≥0, β>0.\lambda(t\mid\mathcal H_{t-})= \mu+\alpha\sum_{t_i<t}e^{-\beta(t-t_i)}, \qquad \mu>0,\ \alpha\ge0,\ \beta>0.λ(t∣Ht−​)=μ+αti​<t∑​e−β(t−ti​),μ>0, α≥0, β>0.

Каждое событие добавляет к интенсивности скачок α\alphaα, вклад которого затем затухает. Параметры μ\muμ и α\alphaα имеют единицу обратного времени, β\betaβ — скорость затухания с той же размерностью. Безразмерная масса ядра

η=∫0∞αe−βsds=αβ\eta=\int_0^\infty\alpha e^{-\beta s}ds=\frac\alpha\betaη=∫0∞​αe−βsds=βα​

называется коэффициентом ветвления. В кластерном представлении это среднее число прямых потомков события. Свойства линейных Hawkes-моделей, кластерное представление и условие устойчивости разобраны у Bacry, Mastromatteo и Muzy (2015). Встречается и параметризация ηβe−βs\eta\beta e^{-\beta s}ηβe−βs: в ней коэффициент перед экспонентой имеет другой смысл, чем наш α\alphaα.

Теорема · Средняя интенсивность стационарного режима#

Если модель на всей временной оси находится в стационарном режиме с конечной средней интенсивностью λˉ\bar\lambdaλˉ, то

λˉ=μ+ηλˉ,λˉ=μ1−η.\bar\lambda=\mu+\eta\bar\lambda, \qquad \bar\lambda=\frac\mu{1-\eta}.λˉ=μ+ηλˉ,λˉ=1−ημ​.

При μ>0\mu>0μ>0 существование такого режима требует η<1\eta<1η<1.

Доказательство

В стационарном процессе ожидаемое число событий в элементе прошлого длины dsdsds равно λˉ ds\bar\lambda\,dsλˉds. Поэтому ожидаемый суммарный вклад неотрицательного ядра равен

E ⁣[∑ti<tαe−β(t−ti)]=λˉ∫0∞αe−βsds=ηλˉ.\E\!\left[\sum_{t_i<t}\alpha e^{-\beta(t-t_i)}\right] =\bar\lambda\int_0^\infty\alpha e^{-\beta s}ds =\eta\bar\lambda.E[ti​<t∑​αe−β(t−ti​)]=λˉ∫0∞​αe−βsds=ηλˉ.

Перестановка ожидания и неотрицательной суммы обосновывается монотонным приближением; это не требует независимости прошлых событий. Усреднение уравнения интенсивности даёт первое равенство. При конечной неотрицательной λˉ\bar\lambdaλˉ и μ>0\mu>0μ>0 равенство невозможно для η≥1\eta\ge1η≥1. Для η<1\eta<1η<1 решение имеет указанный вид.

□

Это вывод моментов при предположении стационарного режима. Существование устойчивого стационарного линейного процесса при субкритическом ядре — дополнительный результат теории. Конечное окно, в котором до 0 принята пустая история, не является стационарной инициализацией.

Пример фиксированной истории​

При η≥1\eta\ge1η≥1 нет конечной стационарной средней с положительным μ\muμ. Это не равнозначно утверждению о бесконечном числе событий за конечное время. Расчёт интенсивности и правдоподобия фиксированного конечного паттерна остаётся отдельной корректно определённой операцией.

Код и независимая проверка​

events.py — экспоненциальная модель Hawkes
def hawkes_parameters(mu, alpha, beta):
    if not all(math.isfinite(value) for value in (mu, alpha, beta)) or mu <= 0 or alpha < 0 or beta <= 0:
        raise ValueError("Нужны mu>0, alpha>=0, beta>0")


def hawkes_intensity(time, events, mu=.5, alpha=.4, beta=1):
    hawkes_parameters(mu, alpha, beta)
    events = list(events)
    if (not math.isfinite(time) or time < 0
            or any(not math.isfinite(t) or t <= 0 for t in events)
            or any(left >= right for left, right in zip(events, events[1:]))):
        raise ValueError("Нужны конечное время и возрастающий список положительных событий")
    return mu+alpha*sum(math.exp(-beta*(time-event)) for event in events if event < time)


def hawkes_log_likelihood(events, end, mu=.5, alpha=.4, beta=1):
    hawkes_parameters(mu, alpha, beta)
    events = list(events)
    if (not math.isfinite(end) or end <= 0 or any(not math.isfinite(t) or not 0 < t < end for t in events)
            or any(left >= right for left, right in zip(events, events[1:]))):
        raise ValueError("Нужны строго возрастающие события в (0,end)")
    previous, memory, log_events = 0.0, 0.0, 0.0
    for time in events:
        memory *= math.exp(-beta*(time-previous))
        log_events += math.log(mu+alpha*memory)  # Только строго прошлые события.
        memory += 1
        previous = time
    integrated = mu*end + (alpha/beta)*sum(-math.expm1(-beta*(end-time)) for time in events)
    return {"log_likelihood": log_events-integrated, "integrated_intensity": integrated,
            "branching_ratio": alpha/beta}

hawkes_intensity суммирует только события с event < time. В рекурсивном правдоподобии memory сначала затухает, затем используется в логарифме интенсивности, и только после этого увеличивается на единицу. Включение текущего события до логарифма искусственно повысило бы вероятность уже известного ответа.

Каждый прошлый вклад интегрируется аналитически:

∫tiTαe−β(s−ti)ds=αβ(1−e−β(T−ti)).\int_{t_i}^T\alpha e^{-\beta(s-t_i)}ds =\frac\alpha\beta\left(1-e^{-\beta(T-t_i)}\right).∫ti​T​αe−β(s−ti​)ds=βα​(1−e−β(T−ti​)).

Полученная суммарная интегральная интенсивность для рисунка равна примерно 4,523765499, log⁡L≈−6,246699413\log L\approx-6{,}246699413logL≈−6,246699413. Аналитический интеграл независимо сопоставлен с численным интегрированием SciPy, а рекурсивная интенсивность перед событиями — с прямым суммированием.

Рекурсия и компенсационный интеграл требуют O(n)O(n)O(n) времени. Состояние рекурсии имеет постоянный размер; код дополнительно хранит скопированный список входных времён. При α=0\alpha=0α=0 правдоподобие совпадает с однородным пуассоновским, что также проверяется.

Марки и интерпретация в рекомендациях​

Событие может иметь марку: тип действия, объект или другую характеристику. Для конечных типов kkk можно определить интенсивности λk(t∣H)\lambda_k(t\mid\mathcal H)λk​(t∣H); суммарная равна ∑kλk\sum_k\lambda_k∑k​λk​, а условная вероятность типа при наступлении события — λk/∑jλj\lambda_k/\sum_j\lambda_jλk​/∑j​λj​, если знаменатель положителен.

Это отделяет вопрос «когда произойдёт действие» от вопроса «какое». Модель ответов пользователей при существующей политике не является автоматически политикой выбора следующего объекта. Самовозбуждение также является формой статистической зависимости: общий внешний повод, экспозиция и скрытые изменения режима могут быть совместимы с похожей кластеризацией. Причинное влияние события требует иных предпосылок и дизайна.
