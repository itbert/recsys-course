Тренд, сезонность и временные фильтры

Разложение требует модели​

Запись Yt=Tt+St+RtY_t=T_t+S_t+R_tYt​=Tt​+St​+Rt​ разделяет медленно меняющийся уровень, сезонную компоненту и остаток. Без ограничений разложение не единственно: произвольную функцию можно прибавить к TtT_tTt​ и вычесть из StS_tSt​.

Для фиксированного периода mmm можно потребовать St+m=StS_{t+m}=S_tSt+m​=St​ и нулевую сумму по периоду. Дополнительное ограничение на класс тренда, например линейность, делает задачу определённее. Но остаток после подгонки ещё не обязан быть независимым, стационарным или гауссовским.

В мультипликативной записи Yt=TtStRtY_t=T_tS_tR_tYt​=Tt​St​Rt​ сезонные изменения выражаются относительным масштабом. Логарифм превращает произведение положительных компонентов в сумму. При нулях и отрицательных значениях такой переход не определён без нового преобразования.

Различия компонент и методов их оценивания обсуждаются в главе о декомпозиции книги Forecasting: Principles and Practice. Мы сначала используем явно заданную простую регрессию, чтобы видеть все предпосылки.

Гармоника известного периода​

Для недельного периода на дневной сетке зададим

yt=a+bt+csin⁡(2πt/7)+dcos⁡(2πt/7)+rt.y_t=a+bt+c\sin(2\pi t/7)+d\cos(2\pi t/7)+r_t.yt​=a+bt+csin(2πt/7)+dcos(2πt/7)+rt​.

Это линейная регрессия по четырём признакам, хотя признаки являются нелинейными функциями времени. Пара синуса и косинуса позволяет выбирать фазу. Амплитуда равна c2+d2\sqrt{c^2+d^2}c2+d2​, поскольку линейную комбинацию можно представить одной сдвинутой синусоидой.

Период 7 здесь задан конструкцией. Автоматический поиск периода, особенно по короткому ряду, создаёт дополнительную задачу выбора модели. Периодическая форма в графике также может отражать расписание экспозиции или доставки, а не изменение интересов.

Фильтр и время доступности​

Одностороннее среднее ширины www после получения YtY_tYt​ использует

Y~t=1w∑j=0w−1Yt−j.\widetilde Y_t=\frac1w\sum_{j=0}^{w-1}Y_{t-j}.Yt​=w1​j=0∑w−1​Yt−j​.

У центрированного среднего нечётной ширины w=2q+1w=2q+1w=2q+1 окно иное:

Y~tcenter=12q+1∑j=−qqYt+j.\widetilde Y_t^{\mathrm{center}}=\frac1{2q+1}\sum_{j=-q}^{q}Y_{t+j}.Ytcenter​=2q+11​j=−q∑q​Yt+j​.

Во втором случае нужны значения после ttt. Для описания уже наблюдённого прошлого это допустимое преобразование. В признаке решения на ttt оно недоступно без задержки расчёта до t+qt+qt+q.

Даже одностороннее окно, включающее YtY_tYt​, доступно только после измерения и получения этого значения. Если решение принимается до его появления, окно должно заканчиваться раньше. Календарный индекс не заменяет проверку доступности.

На концах ряда можно оставить пропуски, уменьшить окно или ввести дополнение. Эти правила дают разные преобразования. В нашем коде возвращается None, если полного окна нет; размер окна не меняется молча.

Что сглаживание делает с шумом​

Для независимого белого шума дисперсии σ2\sigma^2σ2 дисперсия среднего www значений равна σ2/w\sigma^2/wσ2/w. Но два соседних сглаженных значения используют общие ошибки. При сдвиге 1 у них w−1w-1w−1 общих слагаемых и ковариация (w−1)σ2/w2(w-1)\sigma^2/w^2(w−1)σ2/w2.

Следовательно, визуально более плавный ряд может иметь более сильную соседнюю зависимость. Уменьшение масштаба колебаний после фильтра не доказывает рост числа независимых наблюдений или улучшение прогнозируемости.

Для зависимого исходного шума дисперсия среднего включает ковариации из предыдущей главы. Формула σ2/w\sigma^2/wσ2/w тогда в общем случае неприменима.

Реализация​

series.py — фильтр и гармоническая регрессия
def moving_average(values, width=3, centered=False):
    values = vector(values)
    if type(width) is not int or width < 1 or width % 2 == 0:
        raise ValueError("width должна быть положительной нечётной")
    result = []
    for t in range(len(values)):
        left, right = (t-width//2, t+width//2+1) if centered else (t-width+1, t+1)
        result.append(float(values[left:right].mean()) if 0 <= left and right <= len(values) else None)
    return result


def harmonic_fit(values, period=7):
    values = vector(values, 5)
    if type(period) is not int or period < 3:
        raise ValueError("Нужен целый период не меньше 3")
    time = np.arange(len(values))
    design = np.column_stack([np.ones(len(values)), time,
                              np.sin(2*np.pi*time/period), np.cos(2*np.pi*time/period)])
    coefficients, _, rank, _ = np.linalg.lstsq(design, values, rcond=None)
    if rank != design.shape[1]:
        raise ValueError("Неединственная регрессия")
    fitted = design @ coefficients
    return {"coefficients": coefficients, "fitted": fitted, "residuals": values-fitted}


moving_average вычисляет явные индексы окна. Векторизированная свёртка могла бы ускорить расчёт, но её режим дополнения и выравнивание нужно было бы определить так же точно. Учебный прямой алгоритм требует O(nw)O(nw)O(nw) операций.

harmonic_fit строит матрицу с четырьмя столбцами. lstsq решает МНК, проверка ранга исключает неединственную оценку. Возвращаются коэффициенты, приближение и остатки. Для искусственного ряда 4+0,2t+3sin⁡(2πt/7)−2cos⁡(2πt/7)4+0{,}2t+3\sin(2\pi t/7)-2\cos(2\pi t/7)4+0,2t+3sin(2πt/7)−2cos(2πt/7) код восстанавливает коэффициенты с численным допуском.

Наличие подходящих остатков на обучающем периоде не гарантирует сохранения тренда и периода. В рекомендательной системе могут измениться каталог, политика и покрытие измерения. Это основания для диагностики и пересмотра модели, а не для автоматического продолжения линии.
