Экспоненциальное сглаживание и ETS

Простое экспоненциальное сглаживание​

SES поддерживает одно состояние уровня:

ℓt=αyt+(1−α)ℓt−1,y^t+h∣t=ℓt,0≤α≤1.\ell_t=\alpha y_t+(1-\alpha)\ell_{t-1},\qquad \widehat y_{t+h\mid t}=\ell_t,\quad 0\le\alpha\le1.ℓt​=αyt​+(1−α)ℓt−1​,y​t+h∣t​=ℓt​,0≤α≤1.

В отличие от окна фиксированной ширины, прошлые значения не удаляются в один момент: их веса убывают геометрически. На регулярной сетке параметр α\alphaα относится к одному шагу этой сетки.

Лемма · Веса истории#

При 0<α<10<\alpha<10<α<1 после ttt обновлений с начальным состоянием ℓ0\ell_0ℓ0​

ℓt=(1−α)tℓ0+α∑j=0t−1(1−α)jyt−j.\ell_t=(1-\alpha)^t\ell_0 +\alpha\sum_{j=0}^{t-1}(1-\alpha)^j y_{t-j}.ℓt​=(1−α)tℓ0​+αj=0∑t−1​(1−α)jyt−j​.

Вес начального состояния и веса наблюдений неотрицательны и в сумме равны 1.

Доказательство

Последовательно подставим предыдущее ℓ\ellℓ в рекурсию. На каждом шаге новые старые веса умножаются на 1−α1-\alpha1−α, текущему наблюдению присваивается α\alphaα. После ttt шагов получаем указанную конечную сумму. Геометрическая сумма весов наблюдений равна 1−(1−α)t1-(1-\alpha)^t1−(1−α)t, что вместе с начальным весом даёт 1.

□

Большое α\alphaα быстрее реагирует на новое измерение и сильнее передаёт его шум. Малое α\alphaα дольше сохраняет старое состояние. Это обмен реактивности и сглаживания при выбранном механизме данных, а не универсальный порядок качества.

Уровень и тренд Holt​

Добавим состояние локального наклона btb_tbt​ и коэффициент затухания 0<φ≤10<\varphi\le10<φ≤1:

ℓt=αyt+(1−α)(ℓt−1+φbt−1),bt=β∗(ℓt−ℓt−1)+(1−β∗)φbt−1,y^t+h∣t=ℓt+(∑j=1hφj)bt.\begin{aligned} \ell_t&=\alpha y_t+(1-\alpha)(\ell_{t-1}+\varphi b_{t-1}),\\ b_t&=\beta^*(\ell_t-\ell_{t-1})+(1-\beta^*)\varphi b_{t-1},\\ \widehat y_{t+h\mid t}&=\ell_t+ \left(\sum_{j=1}^{h}\varphi^j\right)b_t. \end{aligned}ℓt​bt​y​t+h∣t​​=αyt​+(1−α)(ℓt−1​+φbt−1​),=β∗(ℓt​−ℓt−1​)+(1−β∗)φbt−1​,=ℓt​+(j=1∑h​φj)bt​.​

Здесь β∗\beta^*β∗ сглаживает обновление тренда. При φ=1\varphi=1φ=1 прогноз продолжает текущий наклон как ℓt+hbt\ell_t+hb_tℓt​+hbt​. При φ<1\varphi<1φ<1 накопленный вклад тренда имеет конечный предел btφ/(1−φ)b_t\varphi/(1-\varphi)bt​φ/(1−φ).

Состояние наклона оценивается по шумным измерениям. Даже при верной форме модели случайное отклонение в конце истории может заметно повлиять на длинный прогноз. Поэтому поведение метода определяется также инициализацией и параметрами обновления.

Аддитивная сезонность Holt–Winters​

Для периода mmm храним mmm сезонных состояний. В аддитивной схеме:

ℓt=α(yt−st−m)+(1−α)(ℓt−1+φbt−1),bt=β∗(ℓt−ℓt−1)+(1−β∗)φbt−1,st=γ(yt−ℓt−1−φbt−1)+(1−γ)st−m.\begin{aligned} \ell_t&=\alpha(y_t-s_{t-m})+(1-\alpha)(\ell_{t-1}+\varphi b_{t-1}),\\ b_t&=\beta^*(\ell_t-\ell_{t-1})+(1-\beta^*)\varphi b_{t-1},\\ s_t&=\gamma(y_t-\ell_{t-1}-\varphi b_{t-1})+(1-\gamma)s_{t-m}. \end{aligned}ℓt​bt​st​​=α(yt​−st−m​)+(1−α)(ℓt−1​+φbt−1​),=β∗(ℓt​−ℓt−1​)+(1−β∗)φbt−1​,=γ(yt​−ℓt−1​−φbt−1​)+(1−γ)st−m​.​

Прогноз складывает последний уровень, накопленный затухающий тренд и последнее известное сезонное состояние нужной фазы. Здесь γ\gammaγ относится к сезонной ошибке до обновления уровня. В эквивалентной записи с yt−ℓty_t-\ell_tyt​−ℓt​ коэффициент был бы другим: γ=γ∗(1−α)\gamma=\gamma^*(1-\alpha)γ=γ∗(1−α).

Для используемой интерпретации весов выбираем 0≤β∗≤10\le\beta^*\le10≤β∗≤1, 0≤γ≤1−α0\le\gamma\le1-\alpha0≤γ≤1−α. Параметризация и варианты методов приведены в главе 8 FPP. Код ниже использует именно написанные уравнения; смешение двух разных γ\gammaγ изменило бы алгоритм.

Мультипликативная сезонность вместо суммирования масштабирует уровень. Она требует соответствующей области положительных значений и другой модели ошибки. Для нашего вещественного индекса реализуется аддитивный вариант.

Реализация с нуля​

smoothing.py
"""Аддитивные SES, Holt и Holt–Winters с явно заданной инициализацией."""
import numpy as np
from series import vector, horizon_size


def parameters(alpha, beta=0, gamma=0, damping=1):
    if (not np.isfinite([alpha, beta, gamma, damping]).all()
            or not 0 <= alpha <= 1 or not 0 <= beta <= 1
            or not 0 <= gamma <= 1-alpha or not 0 < damping <= 1):
        raise ValueError("Недопустимые параметры компонентной схемы")


def ses(values, horizon, alpha=.3):
    values = vector(values); horizon_size(horizon); parameters(alpha)
    level = float(values[0])
    for value in values[1:]:
        level = alpha*value + (1-alpha)*level
    return np.full(horizon, level)


def holt(values, horizon, alpha=.3, beta=.1, damping=1):
    values = vector(values, 2); horizon_size(horizon); parameters(alpha, beta, damping=damping)
    level, trend = float(values[1]), float(values[1]-values[0])
    for value in values[2:]:
        previous = level
        level = alpha*value + (1-alpha)*(level+damping*trend)
        trend = beta*(level-previous) + (1-beta)*damping*trend
    cumulative = np.cumsum(damping**np.arange(1, horizon+1))
    return level+cumulative*trend


def holt_winters(values, horizon, period=7, alpha=.3, beta=.1, gamma=.2, damping=1):
    values = vector(values); horizon_size(horizon); parameters(alpha, beta, gamma, damping)
    if type(period) is not int or period < 2 or len(values) < 2*period:
        raise ValueError("Для инициализации нужны два полных периода")
    first, second = values[:period].mean(), values[period:2*period].mean()
    trend = float((second-first)/period)
    center = (period-1)/2
    seasonal = np.array([((values[j]-first-trend*(j-center))
                         + (values[period+j]-second-trend*(j-center)))/2 for j in range(period)])
    level = float(second+trend*center)
    for t in range(2*period, len(values)):
        previous, old_season = level, seasonal[t % period]
        nonseasonal = level+damping*trend
        level = alpha*(values[t]-old_season) + (1-alpha)*nonseasonal
        trend = beta*(level-previous) + (1-beta)*damping*trend
        seasonal[t % period] = gamma*(values[t]-nonseasonal) + (1-gamma)*old_season
    cumulative = np.cumsum(damping**np.arange(1, horizon+1))
    return np.array([level+cumulative[h-1]*trend+seasonal[(len(values)+h-1) % period]
                     for h in range(1, horizon+1)])

ses начинает с первого измерения. holt инициализируется по первым двум значениям и обрабатывает последующие; его первые внутренние прогнозы не претендуют на предсказание ещё не использованной инициализации.

Для Holt–Winters используются два полных периода. Разность их средних даёт начальный наклон; внутри периодов он вычитается при оценке сезонных фаз. Начальный уровень переносится к концу второго периода. Затем цикл начинается с третьего, поэтому ни одно обновление не требует будущего относительно своего шага измерения. Это конкретная прозрачная инициализация, а не оптимизация всех начальных состояний по правдоподобию.

Индекс (len(values)+h-1) % period выбирает фазу будущего шага. Ошибка на единицу сдвинула бы весь сезонный прогноз. На точном ряде «линия плюс гармоника» с незатухающим трендом реализация воспроизводит продолжение с численным допуском.

После инициализации обновления требуют O(n)O(n)O(n) времени. Для сезонной схемы достаточно O(m)O(m)O(m) памяти состояний, для уровня и тренда — постоянной памяти; выходной прогноз дополнительно занимает O(H)O(H)O(H).

От метода к ETS-модели​

Рекурсия состояния сама по себе не задаёт распределения будущего. Например, для SES можно ввести модель инноваций

yt=ℓt−1+εt,ℓt=ℓt−1+αεt,y_t=\ell_{t-1}+\varepsilon_t,\qquad \ell_t=\ell_{t-1}+\alpha\varepsilon_t,yt​=ℓt−1​+εt​,ℓt​=ℓt−1​+αεt​,

с независимыми гауссовскими εt\varepsilon_tεt​. Она даёт ту же рекурсию точечной оценки, но дополнительно задаёт вероятностную модель ошибки и прогнозные распределения.

ETS обозначает Error, Trend, Seasonality: тип ошибки, тренда и сезонности. Буквы A, M, N соответствуют аддитивной, мультипликативной и отсутствующей компоненте там, где это допускается моделью; для затухающего тренда используется отдельное обозначение. SES с аддитивными ошибками — ETS(A,N,N). Параметры инновационной и компонентной записи требуют согласованного преобразования, например β=αβ∗\beta=\alpha\beta^*β=αβ∗.

В библиотечных реализациях параметры и начальные состояния часто оцениваются совместно. Наши значения фиксированы заранее и не объявляются оптимальными. Поэтому сравнительная ошибка ниже относится к конкретным настройкам, а не ко всему семейству ETS.

Упражнения​

Упражнение · Вес давнего измерения#

При α=0,2\alpha=0{,}2α=0,2 каков вес yt−3y_{t-3}yt−3​ в развёрнутой рекурсии, если оно уже входит в историю? Что означает изменение временной сетки с дня на час при сохранении того же α\alphaα?

Разбор

Вес равен 0,2⋅0,83=0,10240{,}2\cdot0{,}8^3=0{,}10240,2⋅0,83=0,1024. На часовой сетке один множитель затухания применяется за час, а не за день. Сохранение числа α\alphaα меняет физический масштаб памяти. Для одинакового масштаба нужно согласовать коэффициенты с длительностью шага.
