Нерегулярное время и смена режима

Длительность между обновлениями​

Если состояние интереса умножается на 0,9 после каждого события, за десять событий оно затухнет одинаково независимо от того, заняли ли они минуту или месяц. Это модель памяти в числе событий. Если задача относится к физическому старению информации, нужно использовать прошедшее время.

Для вклада xix_ixi​ в момент tit_iti​ зададим вес давности exp⁡(−(t−ti)/τ)\exp(-(t-t_i)/\tau)exp(−(t−ti​)/τ), где τ>0\tau>0τ>0 имеет единицу времени. За интервал τ\tauτ вес уменьшается в eee раз, период полураспада равен τlog⁡2\tau\log2τlog2.

Определение · Экспоненциально взвешенная история#

После события iii определим ненормированную сумму

Si=∑j=1ixjexp⁡ ⁣(−ti−tjτ),t1<…<ti.S_i=\sum_{j=1}^{i}x_j\exp\!\left(-\frac{t_i-t_j}{\tau}\right), \qquad t_1<\ldots<t_i.Si​=j=1∑i​xj​exp(−τti​−tj​​),t1​<…<ti​.

При xj=1x_j=1xj​=1 она описывает взвешенное число событий, а не среднее их признака.

Лемма · Рекурсивное обновление#

Эта сумма удовлетворяет

Si=e−(ti−ti−1)/τSi−1+xi,S1=x1.S_i=e^{-(t_i-t_{i-1})/\tau}S_{i-1}+x_i, \qquad S_1=x_1.Si​=e−(ti​−ti−1​)/τSi−1​+xi​,S1​=x1​.
Доказательство

Для каждого старого события показатель разлагается как ti−tj=(ti−ti−1)+(ti−1−tj)t_i-t_j=(t_i-t_{i-1})+(t_{i-1}-t_j)ti​−tj​=(ti​−ti−1​)+(ti−1​−tj​). Общий множитель нового интервала можно вынести из суммы старых вкладов. Текущий вклад имеет нулевой возраст и вес 1.

Для взвешенного среднего признака нужно аналогично обновлять знаменатель Wi=e−Δi/τWi−1+1W_i=e^{-\Delta_i/\tau}W_{i-1}+1Wi​=e−Δi​/τWi−1​+1 и использовать Si/WiS_i/W_iSi​/Wi​. Сама сумма и нормированное среднее имеют разные единицы. Наивная замена одного другим меняет смысл состояния.

Переход с учётом интервала​

Рассмотрим стационарный гауссовский марковский процесс с нулевым средним, дисперсией v>0v>0v>0 и ковариацией ve−κ∣t−s∣v e^{-\kappa|t-s|}ve−κ∣t−s∣, κ>0\kappa>0κ>0. Условный переход за интервал Δ\DeltaΔ имеет вид

X(t+Δ)=e−κΔX(t)+ηΔ,ηΔ∼N ⁣(0,v(1−e−2κΔ)).X(t+\Delta)=e^{-\kappa\Delta}X(t)+\eta_\Delta, \qquad \eta_\Delta\sim N\!\left(0,v(1-e^{-2\kappa\Delta})\right).X(t+Δ)=e−κΔX(t)+ηΔ​,ηΔ​∼N(0,v(1−e−2κΔ)).

Шум перехода независим от текущего состояния и, в этой марковской модели, от более старой истории при условии текущего состояния. Коэффициент среднего получается делением ковариации двух времён на vvv, остаточная дисперсия — вычитанием объяснённой части из vvv. Это тот же принцип гауссовского условного обновления, который использовался в предыдущей главе.

При Δ=0\Delta=0Δ=0 переход не вносит шума; при большом разрыве среднее забывает текущее состояние, а дисперсия приближается к vvv. Поэтому фиксированная дисперсия процесса на одну строку не соответствует автоматически одинаковой модели физического времени.

Этот пример задаёт конечновременные переходы без введения стохастических дифференциальных уравнений. Более подробный аппарат непрерывной динамики потребуется позднее для некоторых моделей высокочастотных данных.

Изменение режима​

Стационарная модель относится к одному установленному закону. Смена среднего, дисперсии, сезонности или механизма экспозиции может нарушить его. Наблюдаемый сдвиг остатка также может возникнуть из-за изменения регистрации, доступности объектов или состава пользователей.

Короткое скользящее окно быстрее адаптируется к новому режиму, но использует меньше данных. Длинное окно уменьшает некоторые случайные колебания и дольше смешивает старое и новое. Это не универсальная рекомендация размера: выбор зависит от цели, динамики и цены ошибок.

Для простого диагностического сигнала вверх используем односторонний CUSUM:

Gt=max⁡{0,Gt−1+yt−μ0−k},сигнал при Gt>h.G_t=\max\{0,G_{t-1}+y_t-\mu_0-k\},\qquad \text{сигнал при }G_t>h.Gt​=max{0,Gt−1​+yt​−μ0​−k},сигнал при Gt​>h.

μ0\mu_0μ0​ — опорный уровень, k≥0k\ge0k≥0 — допуск, h>0h>0h>0 — порог. Все параметры имеют согласованные единицы. Историческая работа Page — Continuous Inspection Schemes (1954); практическая постановка и калибровка описаны в NIST/SEMATECH.

Формула определяет статистику, но выбранные произвольно k,hk,hk,h не задают известной частоты ложных тревог. Зависимость ошибок, неверный опорный уровень и оценивание параметров по тем же данным меняют её поведение. Сигнал CUSUM не идентифицирует причину сдвига.

Реализация​

state_space.py — нерегулярная история и диагностика
def decayed_history(times, values, tau):
    times, values = vector(times), vector(values)
    if len(times) != len(values) or np.any(np.diff(times) <= 0) or not math.isfinite(tau) or tau <= 0:
        raise ValueError("Нужны возрастающие времена, одинаковые длины и tau>0")
    state, result = 0.0, []
    for index, (time, value) in enumerate(zip(times, values)):
        if index:
            state *= math.exp(-(time-times[index-1])/tau)
        state += value
        result.append(state)
    return result


def gaussian_decay_transition(last, delta, kappa, stationary_var):
    if (not np.isfinite([last, delta, kappa, stationary_var]).all()
            or delta < 0 or kappa <= 0 or stationary_var < 0):
        raise ValueError("Некорректный переход")
    persistence = math.exp(-kappa*delta)
    return persistence*last, stationary_var*(-math.expm1(-2*kappa*delta))


def cusum(values, reference=0, allowance=.5, threshold=5):
    values = vector(values)
    if not np.isfinite([reference, allowance, threshold]).all() or allowance < 0 or threshold <= 0:
        raise ValueError("Некорректные параметры CUSUM")
    state, result = 0.0, []
    for value in values:
        state = max(0.0, state+value-reference-allowance)
        result.append({"sum": state, "alarm": state > threshold})
    return result

decayed_history хранит одно состояние и использует реальную разность времён. Ожидаемый результат независимо проверяется прямой суммой по всей истории. Время O(n)O(n)O(n), дополнительная память состояния постоянна, кроме сохранённого выхода.

gaussian_decay_transition возвращает среднее и дисперсию перехода. expm1 сохраняет точность выражения 1−e−2κΔ1-e^{-2\kappa\Delta}1−e−2κΔ при малом интервале. Проверка композиции двух переходов сверяет итог с одним переходом на суммарное время, включая перенос дисперсии первого шума.

cusum не сбрасывает состояние после тревоги: выход alarm означает превышение порога в данном шаге. Действие после сигнала, повторное обучение и правила повторных тревог требуют отдельного протокола. Автоматическое удаление событий из-за сигнала изменило бы данные и нуждалось бы в самостоятельном обосновании.

Упражнения​

Упражнение · Полураспад#

Период полураспада интереса принят равным 7 суткам. Чему равен τ\tauτ в экспоненте e−Δ/τe^{-\Delta/\tau}e−Δ/τ и какой вес останется через 21 сутки?

Разбор

τ=7/log⁡2\tau=7/\log2τ=7/log2 суток. Через три периода полураспада вес равен 2−3=1/82^{-3}=1/82−3=1/8. Если время в коде выражено секундами, τ\tauτ также переводится в секунды; оставление числа 7 означало бы иной физический масштаб.

Упражнение · Диагноз по тревоге#

CUSUM остатков прогноза числа кликов перешёл порог. Достаточно ли этого, чтобы установить рост интереса к объектам? Какие изменения механизма наблюдения совместимы с тем же сигналом?

Разбор

Недостаточно: установлено только выполнение правила по наблюдаемой статистике. Совместимы, например, рост числа показов, смена позиции объектов, восстановление потерь кликов или изменение состава трафика. Проверка причины требует соответствующих источников, знаменателей и отдельного дизайна исследования.
