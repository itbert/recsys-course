Стационарность и временная зависимость

Стационарность является свойством модели​

Определение · Строгая и слабая стационарность#

Процесс строго стационарен, если совместный закон (Yt1,…,Ytr)(Y_{t_1},\ldots,Y_{t_r})(Yt1​​,…,Ytr​​) не меняется при любом общем допустимом сдвиге всех времён для любых конечных r,t1,…,trr,t_1,\ldots,t_rr,t1​,…,tr​.

Слабая стационарность требует конечных вторых моментов, постоянного среднего EYt=μ\E Y_t=\muEYt​=μ и ковариации, зависящей только от лага:

Cov⁡(Yt,Yt−k)=γ(k).\operatorname{Cov}(Y_t,Y_{t-k})=\gamma(k).Cov(Yt​,Yt−k​)=γ(k).

Строгая стационарность при конечных вторых моментах влечёт слабую. Обратное в общем случае неверно: первые два момента не определяют весь совместный закон. Для гауссовского процесса, у которого все конечные совместные распределения гауссовские, средних и ковариаций достаточно, поэтому слабая стационарность влечёт строгую.

На коротком графике можно искать признаки нарушения предпосылок, но ровный вид не доказывает стационарность. Стационарный процесс также не обязан быть независимым или быстро забывать прошлое. Например, при Yt=ZY_t=ZYt​=Z для всех ttt и одном случайном Z∼N(0,1)Z\sim N(0,1)Z∼N(0,1) процесс стационарен, но среднее любой траектории равно ZZZ, а не обязательно 0. Для связи временного среднего одной траектории с популяционным средним нужны дополнительные условия.

Практическая связь стационарности и преобразований рассматривается в книге Hyndman и Athanasopoulos Forecasting: Principles and Practice, глава 9. Ниже используются точные определения, а не визуальный критерий «ряд выглядит горизонтальным».

Автоковариация и ACF​

При γ(0)>0\gamma(0)>0γ(0)>0 автокорреляционная функция слабо стационарного процесса

ρ(k)=γ(k)γ(0)\rho(k)=\frac{\gamma(k)}{\gamma(0)}ρ(k)=γ(0)γ(k)​

измеряет линейную зависимость на лаге kkk. Она симметрична по знаку лага, ρ(0)=1\rho(0)=1ρ(0)=1, ∣ρ(k)∣≤1|\rho(k)|\le1∣ρ(k)∣≤1. Последнее следует из неравенства Коши–Буняковского для центрированных случайных величин одинаковой дисперсии.

Для конечного ряда используем оценку с единым знаменателем:

ρ^(k)=∑t=kn−1(yt−yˉ)(yt−k−yˉ)∑t=0n−1(yt−yˉ)2,0≤k<n.\widehat\rho(k)= \frac{\sum_{t=k}^{n-1}(y_t-\bar y)(y_{t-k}-\bar y)} {\sum_{t=0}^{n-1}(y_t-\bar y)^2},\qquad 0\le k<n.ρ​(k)=∑t=0n−1​(yt​−yˉ​)2∑t=kn−1​(yt​−yˉ​)(yt−k​−yˉ​)​,0≤k<n.

Число пар в числителе уменьшается с лагом, но знаменатель здесь не заменяется на лаговую дисперсию. Другие соглашения существуют; результаты разных реализаций нужно сопоставлять при одинаковом определении. У постоянного ряда знаменатель равен нулю, поэтому ACF не определена.

Большая выборочная корреляция исходного ряда может отражать тренд или сезонность. Это ещё не параметр стационарного остатка и не причинная связь действий.

Белый шум не обязательно независим​

Белым шумом второго порядка назовём последовательность εt\varepsilon_tεt​ с нулевым средним, постоянной конечной дисперсией σ2\sigma^2σ2 и нулевыми ковариациями при разных временах. Независимые одинаково распределённые величины с такими моментами образуют белый шум, но определение не требует независимости.

Рассмотрим независимые одинаково распределённые ZtZ_tZt​ со значениями −1,0,1-1,0,1−1,0,1 и вероятностями 1/4,1/2,1/41/4,1/2,1/41/4,1/2,1/4. Процесс εt=ZtZt−1\varepsilon_t=Z_tZ_{t-1}εt​=Zt​Zt−1​ имеет нулевое среднее, дисперсию 1/41/41/4 и нулевые ковариации при ненулевом лаге. Однако

E[εt2εt−12]=18≠116=E[εt2]E[εt−12].\E[\varepsilon_t^2\varepsilon_{t-1}^2]=\frac18 \ne\frac1{16}=\E[\varepsilon_t^2]\E[\varepsilon_{t-1}^2].E[εt2​εt−12​]=81​=161​=E[εt2​]E[εt−12​].

Следовательно, соседние величины зависимы, несмотря на нулевую ACF. Значения проверяются перебором 27 исходов трёх ZZZ. Отсутствие линейной корреляции не исключает предсказуемость иной характеристики, например масштаба колебаний.

Ошибка среднего при зависимости​

Теорема · Дисперсия временного среднего#

Для nnn последовательных наблюдений слабо стационарного процесса

Var⁡(Yˉn)=1n2[nγ(0)+2∑k=1n−1(n−k)γ(k)].\operatorname{Var}(\bar Y_n) =\frac1{n^2}\left[n\gamma(0)+2\sum_{k=1}^{n-1}(n-k)\gamma(k)\right].Var(Yˉn​)=n21​[nγ(0)+2k=1∑n−1​(n−k)γ(k)].
Доказательство

Дисперсия суммы равна сумме всех попарных ковариаций. В двойной сумме nnn диагональных членов равны γ(0)\gamma(0)γ(0). Для каждого k>0k>0k>0 есть n−kn-kn−k пар в одном порядке и столько же в обратном; каждый член равен γ(k)\gamma(k)γ(k). После группировки и деления на n2n^2n2 получается формула.

□

При нулевых ковариациях остаётся γ(0)/n\gamma(0)/nγ(0)/n. Положительные ковариации увеличивают дисперсию относительно этой величины, отрицательные способны уменьшать. Поэтому применение формулы для независимых наблюдений к последовательности действий без анализа зависимости может дать неверную неопределённость.

Если ∑k≥1∣γ(k)∣<∞\sum_{k\ge1}|\gamma(k)|<\infty∑k≥1​∣γ(k)∣<∞, из конечной формулы следует nVar⁡(Yˉn)→γ(0)+2∑k≥1γ(k)n\operatorname{Var}(\bar Y_n)\to\gamma(0)+2\sum_{k\ge1}\gamma(k)nVar(Yˉn​)→γ(0)+2∑k≥1​γ(k). При положительной предельной величине это даёт для большого nnn приближение

Var⁡(Yˉn)≈γ(0)n(1+2∑k≥1ρ(k)).\operatorname{Var}(\bar Y_n)\approx\frac{\gamma(0)}n \left(1+2\sum_{k\ge1}\rho(k)\right).Var(Yˉn​)≈nγ(0)​(1+2k≥1∑​ρ(k)).

При нулевой предельной величине ведущий порядок нужно исследовать отдельно. Формула не является универсальной заменой фактическому числу пользователей или готовым доверительным интервалом.

Код и границы интерпретации​

dependence.py — начало модуля
"""ACF с единым знаменателем и PACF из линейных проекций."""
import numpy as np
from series import vector, horizon_size


def sample_acf(values, maximum):
    values = vector(values, 2)
    if type(maximum) is not int or not 0 <= maximum < len(values):
        raise ValueError("maximum должен быть целым от 0 до n-1")
    centered = values - values.mean()
    denominator = float(centered @ centered)
    if denominator == 0:
        raise ValueError("ACF постоянного ряда не определена")
    return [float(centered[lag:] @ centered[:len(values)-lag]) / denominator
            for lag in range(maximum+1)]


def mean_variance(covariances, size):
    covariances = vector(covariances)
    if type(size) is not int or size < 1 or len(covariances) < size:
        raise ValueError("Нужны ковариации до лага size-1")
    return float((size*covariances[0]
                  + 2*sum((size-lag)*covariances[lag] for lag in range(1, size))) / size**2)


sample_acf центрирует один и тот же ряд и явно сопоставляет лаговые срезы. Для [1,2,3][1,2,3][1,2,3] результат на лагах 0, 1, 2 равен [1,0,−0,5][1,0,-0{,}5][1,0,−0,5]. mean_variance принимает модельные ковариации, а не объявляет любую выборочную ACF истинной.

На больших лагах мало пар, поэтому оценка чувствительна к отдельным наблюдениям. Стандартные ориентиры значимости на ACF-графиках имеют собственные предпосылки; их нельзя интерпретировать как доказательство независимости всех событий или качества модели. Здесь популяционные характеристики будут сопоставляться с точными формулами заданных моделей.

Упражнения​

Упражнение · Нулевая корреляция#

В примере εt=ZtZt−1\varepsilon_t=Z_tZ_{t-1}εt​=Zt​Zt−1​ почему нулевая ковариация соседних значений совместима с зависимостью их квадратов?

Разбор

В произведении εtεt−1\varepsilon_t\varepsilon_{t-1}εt​εt−1​ остаются множители с нулевыми средними из независимых крайних ZZZ. Квадраты используют общий Zt−12Z_{t-1}^2Zt−12​, и этот множитель не исчезает. Значит, линейная некоррелированность не устраняет общую случайную величину в нелинейной характеристике.

Упражнение · Два зависимых наблюдения#

Два наблюдения имеют дисперсию 4 и ковариацию 2. Чему равна дисперсия их среднего? Каков результат при необоснованной подстановке независимости?

Разбор

Правильная дисперсия равна (4+4+2⋅2)/4=3(4+4+2\cdot2)/4=3(4+4+2⋅2)/4=3. Независимая формула дала бы 4/2=24/2=24/2=2. Среднее вычислено одинаково, но предположение о совместном законе изменило оценку его неопределённости.
