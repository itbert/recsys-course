AR, MA, ARMA и частная корреляция

Авторегрессия​

В AR(ppp) текущее значение линейно связано с ppp прошлыми значениями:

Yt=c+∑j=1pϕjYt−j+εt.Y_t=c+\sum_{j=1}^p\phi_jY_{t-j}+\varepsilon_t.Yt​=c+j=1∑p​ϕj​Yt−j​+εt​.

В этой главе ошибки независимы, одинаково распределены, имеют нулевое среднее и конечную дисперсию σ2\sigma^2σ2. Для условного прогноза предполагается, что будущие ошибки независимы от доступного прошлого. Каузальная стационарная модель строится из текущих и прошлых ошибок, без использования будущих.

Если стационарное среднее существует, то μ=c/(1−∑jϕj)\mu=c/(1-\sum_j\phi_j)μ=c/(1−∑j​ϕj​) при ненулевом знаменателе. Поэтому константа ccc не является средним процесса. Для центрированного Xt=Yt−μX_t=Y_t-\muXt​=Yt​−μ свободный член исчезает.

Теорема · Стационарный каузальный AR(1)#

Пусть ошибки заданы для всех целых времён и ∣ϕ∣<1|\phi|<1∣ϕ∣<1. Для Xt=ϕXt−1+εtX_t=\phi X_{t-1}+\varepsilon_tXt​=ϕXt−1​+εt​ каузальное представление

Xt=∑j=0∞ϕjεt−jX_t=\sum_{j=0}^{\infty}\phi^j\varepsilon_{t-j}Xt​=j=0∑∞​ϕjεt−j​

сходится в среднем квадратичном, имеет нулевое среднее, Var⁡(Xt)=σ2/(1−ϕ2)\operatorname{Var}(X_t)=\sigma^2/(1-\phi^2)Var(Xt​)=σ2/(1−ϕ2) и ρ(k)=ϕ∣k∣\rho(k)=\phi^{|k|}ρ(k)=ϕ∣k∣.

Доказательство

Дисперсия хвоста ряда равна σ2∑j>mϕ2j\sigma^2\sum_{j>m}\phi^{2j}σ2∑j>m​ϕ2j и стремится к нулю. Поэтому частичные суммы образуют сходящуюся в L2L^2L2 последовательность. Сдвиг суммы проверяет уравнение AR(1). Некоррелированность разных ошибок даёт дисперсию как геометрический ряд.

Для k≥0k\ge0k≥0 общие ошибки у XtX_tXt​ и Xt−kX_{t-k}Xt−k​ дают

Cov⁡(Xt,Xt−k)=σ2∑j≥0ϕj+kϕj=ϕkσ21−ϕ2.\operatorname{Cov}(X_t,X_{t-k}) =\sigma^2\sum_{j\ge0}\phi^{j+k}\phi^j =\phi^k\frac{\sigma^2}{1-\phi^2}.Cov(Xt​,Xt−k​)=σ2j≥0∑​ϕj+kϕj=ϕk1−ϕ2σ2​.

Среднее и ковариации не зависят от абсолютного времени. При независимых одинаково распределённых ошибках сдвиг всех индексов сохраняет и совместные законы этого представления.

□

Для AR(ppp) недостаточно потребовать ∣ϕj∣<1|\phi_j|<1∣ϕj​∣<1 для каждого коэффициента. Условие каузальной устойчивости: корни 1−∑jϕjzj1-\sum_j\phi_jz^j1−∑j​ϕj​zj лежат вне единичного круга. Эквивалентно, собственные значения сопровождающей матрицы имеют модули меньше 1. Например, [1,2,−0,5][1{,}2,-0{,}5][1,2,−0,5] устойчив, а [0,9,0,9][0{,}9,0{,}9][0,9,0,9] — нет. Общее устройство ARMA описано в главе 9 FPP.

MA и ARMA​

Модель скользящего среднего ошибок имеет вид

Yt=μ+εt+∑j=1qθjεt−j.Y_t=\mu+\varepsilon_t+\sum_{j=1}^q\theta_j\varepsilon_{t-j}.Yt​=μ+εt​+j=1∑q​θj​εt−j​.

Она использует ненаблюдаемые ошибки, а не простое среднее последних YYY. Название MA здесь обозначает вероятностную модель; сглаживающий фильтр предыдущей главы — другое преобразование.

Для MA(1) имеем γ(0)=σ2(1+θ2)\gamma(0)=\sigma^2(1+\theta^2)γ(0)=σ2(1+θ2), γ(1)=θσ2\gamma(1)=\theta\sigma^2γ(1)=θσ2, γ(k)=0\gamma(k)=0γ(k)=0 при ∣k∣>1|k|>1∣k∣>1. Эти формулы следуют из общих ошибок в двух конечных суммах. При принятом знаке «плюс θ\thetaθ» условие обратимости MA(1) равно ∣θ∣<1|\theta|<1∣θ∣<1: тогда прошлые ошибки можно устойчиво восстанавливать из прошлых наблюдений бесконечным линейным фильтром.

ARMA(p,qp,qp,q) объединяет обе части:

Yt=c+∑j=1pϕjYt−j+εt+∑j=1qθjεt−j.Y_t=c+\sum_{j=1}^p\phi_jY_{t-j} +\varepsilon_t+\sum_{j=1}^q\theta_j\varepsilon_{t-j}.Yt​=c+j=1∑p​ϕj​Yt−j​+εt​+j=1∑q​θj​εt−j​.

Устойчивость AR-части и обратимость MA-части — разные ограничения. Эквивалентные или сокращающиеся полиномы также требуют внимания к идентифицируемости параметров.

PACF как линейная проекция​

Для центрированного слабо стационарного процесса рассмотрим лучший линейный прогноз XtX_tXt​ по Xt−1,…,Xt−kX_{t-1},\ldots,X_{t-k}Xt−1​,…,Xt−k​. Если ковариационная матрица положительно определена, его единственные коэффициенты решают

Γkak=(γ(1),…,γ(k))⊤,(Γk)ij=γ(∣i−j∣).\Gamma_k a_k=(\gamma(1),\ldots,\gamma(k))^\top, \qquad (\Gamma_k)_{ij}=\gamma(|i-j|).Γk​ak​=(γ(1),…,γ(k))⊤,(Γk​)ij​=γ(∣i−j∣).

Эта система получается приравниванием производных ожидаемой квадратичной ошибки нулю. Частная автокорреляция на лаге kkk — последний коэффициент ak,ka_{k,k}ak,k​.

В каузальном AR(1) ошибка εt\varepsilon_tεt​ некоррелирована со всем прошлым. Поэтому при любом k≥1k\ge1k≥1 коэффициенты проекции равны (ϕ,0,…,0)(\phi,0,\ldots,0)(ϕ,0,…,0): добавление более старых значений не улучшает линейный прогноз после Xt−1X_{t-1}Xt−1​.

Оценка и рекурсивный прогноз​

Условный МНК для AR фиксирует первые ppp наблюдений и минимизирует сумму квадратов последующих ошибок. При независимых гауссовских ошибках это соответствует условному правдоподобию при фиксированной дисперсии. Полное стационарное правдоподобие дополнительно учитывает закон начальных значений и в общем случае отличается.

autoregression.py — AR и рекурсия ошибок ARMA
def fit_ar(values, order=1):
    values = vector(values)
    if type(order) is not int or order < 1 or len(values) <= 2*order+1:
        raise ValueError("Недостаточно точек для AR с константой")
    design = np.array([[1, *values[t-order:t][::-1]] for t in range(order, len(values))])
    target = values[order:]
    coefficients, _, rank, _ = np.linalg.lstsq(design, target, rcond=None)
    if rank != design.shape[1]:
        raise ValueError("Неединственный условный МНК")
    residuals = target-design@coefficients
    return {"intercept": float(coefficients[0]), "phi": coefficients[1:], "residuals": residuals}


def ar_forecast(model, history, horizon):
    horizon_size(horizon)
    phi = vector(model["phi"])
    history = list(vector(history, len(phi)))
    forecasts = []
    for _ in range(horizon):
        value = float(model["intercept"] + phi @ np.array(history[-len(phi):][::-1]))
        history.append(value)
        forecasts.append(value)
    return np.array(forecasts)


def is_stable(phi):
    phi = vector(phi)
    companion = np.zeros((len(phi), len(phi)))
    companion[0] = phi
    if len(phi) > 1:
        companion[1:, :-1] = np.eye(len(phi)-1)
    return bool(np.max(np.abs(np.linalg.eigvals(companion))) < 1)


def conditional_arma_residuals(values, phi=(), theta=(), intercept=0):
    values = vector(values)
    phi, theta = vector(phi, 0), vector(theta, 0)
    if len(values) <= len(phi) or not np.isfinite(intercept):
        raise ValueError("Недостаточно начальных значений")
    errors = np.zeros(len(values))  # Начальные ненаблюдаемые ошибки фиксированы нулями.
    for t in range(len(phi), len(values)):
        ar = sum(coefficient*values[t-j-1] for j, coefficient in enumerate(phi))
        ma = sum(coefficient*errors[t-j-1] for j, coefficient in enumerate(theta) if t-j-1 >= 0)
        errors[t] = values[t]-intercept-ar-ma
    return errors[len(phi):]


В design лаги записываются от самого недавнего к самому старому. ar_forecast добавляет собственные прогнозы в историю. is_stable проверяет спектр матрицы; МНК сам по себе ограничение устойчивости не обеспечивает и не гарантирует несмещённость коэффициентов на конечной выборке.

conditional_arma_residuals последовательно восстанавливает ошибки при заданных коэффициентах, фиксируя начальные ненаблюдаемые ошибки нулями. При MA(1) рекурсия равна ε^t=yt−μ−θε^t−1\widehat\varepsilon_t=y_t-\mu-\theta\widehat\varepsilon_{t-1}εt​=yt​−μ−θεt−1​. Она задаёт вычисляемую условную сумму квадратов для численного поиска параметров, но не является полным точным правдоподобием с интегрированием по неизвестной предыстории. В коде рекурсия проверяется на известных искусственных ошибках.

Ошибка прогноза AR(1)​

Теорема · Многошаговые моменты#

При известных параметрах и независимости будущих ошибок от истории

E[Xt+h∣Ht]=ϕhXt,Var⁡(Xt+h∣Ht)=σ2∑j=0h−1ϕ2j.\E[X_{t+h}\mid\mathcal H_t]=\phi^hX_t, \qquad \operatorname{Var}(X_{t+h}\mid\mathcal H_t) =\sigma^2\sum_{j=0}^{h-1}\phi^{2j}.E[Xt+h​∣Ht​]=ϕhXt​,Var(Xt+h​∣Ht​)=σ2j=0∑h−1​ϕ2j.

Формулы верны и для конечного горизонта модели, инициализированной при ∣ϕ∣≥1|\phi|\ge1∣ϕ∣≥1; условие стационарности для них не требуется.

Доказательство

Повторная подстановка даёт Xt+h=ϕhXt+∑j=0h−1ϕjεt+h−jX_{t+h}=\phi^hX_t+\sum_{j=0}^{h-1}\phi^j\varepsilon_{t+h-j}Xt+h​=ϕhXt​+∑j=0h−1​ϕjεt+h−j​. Первый член известен по истории, остальные имеют нулевые условные средние и попарно независимы. Их дисперсии складываются с квадратами коэффициентов.

□

При ∣ϕ∣<1|\phi|<1∣ϕ∣<1 дисперсия приближается к σ2/(1−ϕ2)\sigma^2/(1-\phi^2)σ2/(1−ϕ2). При ϕ=1\phi=1ϕ=1 она равна hσ2h\sigma^2hσ2. Отрицательный ϕ\phiϕ меняет знак среднего по горизонтам, но в дисперсии участвует его квадрат.

dependence.py — PACF и моменты AR(1)
def pacf_from_covariances(covariances):
    covariances = vector(covariances)
    if covariances[0] <= 0:
        raise ValueError("Нужна положительная дисперсия")
    result = [1.0]
    for order in range(1, len(covariances)):
        matrix = np.array([[covariances[abs(i-j)] for j in range(order)] for i in range(order)])
        coefficients = np.linalg.solve(matrix, covariances[1:order+1])
        result.append(float(coefficients[-1]))
    return result


def sample_pacf(values, maximum):
    return pacf_from_covariances(sample_acf(values, maximum))


def ar1_moments(phi, last, innovation_var, horizon):
    horizon_size(horizon)
    if not np.isfinite([phi, last, innovation_var]).all() or innovation_var < 0:
        raise ValueError("Некорректные параметры AR(1)")
    mean, variance, result = float(last), 0.0, []
    for step in range(1, horizon+1):
        mean = phi*mean
        variance = phi**2*variance + innovation_var
        result.append({"horizon": step, "mean": mean, "variance": variance})
    return result

Линейные системы для PACF решаются отдельно для каждого порядка; это прозрачная, но не самая быстрая реализация. Оценки PACF из конечной ACF зависят от её соглашения. Рекурсия дисперсии vh=ϕ2vh−1+σ2v_h=\phi^2v_{h-1}+\sigma^2vh​=ϕ2vh−1​+σ2 избегает деления на 1−ϕ21-\phi^21−ϕ2 около единичного корня.
