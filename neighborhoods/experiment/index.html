Воспроизводимое сравнение базовых и соседских методов

Данные и временной договор​

Это синтетический эксперимент. У каждого из 180 пользователей есть скрытая предпочтительная тема из шести. Объекты принадлежат темам по остатку ID от деления на 6. Вероятность события пропорциональна учебному весу, который повышен для подходящей темы. У первых шести объектов постоянный бонус популярности. Блок объектов с ID 42–47 получает дополнительный бонус с момента 850. Механизм позволяет проверить как глобальные, так и персональные правила в одной среде.

Статистика замораживается в T=1000T=1000T=1000. В генераторе есть поздние доставки и одна запись с будущим временем действия. Из 1440 строк только 1434 входят в срез. Запросы приходят после 1000, по одному от каждого пользователя. В 144 запросах есть исторический профиль, в 36 он пуст. Каталог содержит 60 объектов, шесть новых появляются в 1000. В южном регионе объекты с остатком 5 недоступны. Повтор уже виденного объекта запрещён для всех методов.

Для каждого запроса из его допустимых объектов синтетически отбираются два различных позитива, со степенями 2 и 1. Все остальные имеют grade 0 по определению генератора. Эти метки используются только для оценки. Модели получают допустимые ID, исторические события и профиль пользователя. Темы и веса генератора в их score не входят.

Модели и итог​

Глубина K=5K=5K=5, число соседей не больше 20. Графы используют порог двух общих наблюдений и shrinkage 4. Для user-kNN применяется та же сила shrinkage после косинуса на бинарном профиле. Время полураспада равно 120 тактам. Эти значения заданы в постановке опыта. Сравнение не включает подбор параметров по итоговой когорте.

Граф lift здесь даёт около 0,177, косинусный item-kNN — около 0,165. User-kNN с IUF уступил обычному user-kNN на этой когорте. Это результаты одной модели спроса, а эффект поправок зависит от распределения и поддержки. Покрытие около 0,9 у lift сосуществует с нулём слотов для новых объектов. Почти полное агрегатное покрытие может скрывать систематическое исключение холодной части каталога.

Для заранее выбранной пары item-kNN и popularity средняя разность NDCG@5 равна около 0,053. Парная повторная выборка пользователей даёт диапазон [0,022;0,086][0{,}022;0{,}086][0,022;0,086] по 2,5-му и 97,5-му процентилям. Для этого эксперимента он показывает вариацию при повторном взвешивании той же когорты и фиксированном fit. Модель обучена и на историях части тестовых пользователей. Чтобы интерпретировать диапазон как интервал обобщения на независимые кластеры или новое обучение, нужен соответствующий дизайн, разобранный в части 7.

Отдельная матрица явных оценок​

На учебной матрице целевая оценка пользователя 0 для объекта 3 исключена. Baseline равен 3.143, user-kNN даёт 4.351, item-kNN даёт 4.445. Это демонстрация вычисления трёх прогнозов. Итоговую точность на явных рейтингах измеряют на отдельном наборе наблюдавшихся звёзд с MAE и RMSE.

Запуск и воспроизведение​

experiment.py
"""Синтетическая проверка рекомендаций новых для пользователя объектов."""
from collections import Counter
import hashlib
import json
import math
from pathlib import Path
import platform
import random

from associations import item_graph, item_scores, profiles
from baselines import Event, decayed_popularity, popularity, random_list, recommend, snapshot
from comparison import paired_bootstrap
from ranking import catalog_coverage, ranking_metrics
from ratings import baseline, fit_biases, predict_rating, residual_tables
from users import fit_users, user_scores

SEED = 82026
ORIGIN = 1000
K = 5
CATALOG = range(60)


def preference(item, topic, t):
    # Тематическое предпочтение, постоянный лидер и свежий всплеск.
    weight = 8 if item % 6 == topic else 1
    if item // 6 == 0:
        weight *= 3
    if t >= 850 and item // 6 == 7:
        weight *= 4
    return weight


def sample_without_replacement(rng, pool, weights, k):
    remaining, mass = list(pool), list(weights)
    selected = []
    for _ in range(min(k, len(remaining))):
        j = rng.choices(range(len(remaining)), weights=mass, k=1)[0]
        selected.append(remaining.pop(j))
        mass.pop(j)
    return selected


def generate():
    rng = random.Random(SEED)
    events = []
    topics = {u: rng.randrange(6) for u in range(180)}
    for u in range(144):
        for t in sorted(rng.sample(range(25, 981), rng.randint(7, 13))):
            item = rng.choices(range(54), [preference(i, topics[u], t) for i in range(54)])[0]
            events.append(Event(u, item, t, t + rng.randrange(0, 36)))

    # Одна будущая по времени строка и одна поздняя доставка для проверки среза.
    events.extend([Event(0, 54, 1001, 1002), Event(0, 53, 995, 1002)])
    history = profiles(snapshot(events, ORIGIN))
    requests = []
    for u, topic in topics.items():
        t = ORIGIN + 1 + u % 20
        north = bool(u % 2)
        candidates = [i for i in CATALOG if (north or i % 6 != 5)
                      and i not in history.get(u, ())]
        positives = sample_without_replacement(
            rng, candidates, [preference(i, topic, t) for i in candidates], 2,
        )
        grades = {i: 2 if i == positives[0] else int(i == positives[1]) for i in candidates}
        requests.append((u, t, candidates, grades))
    return events, requests


def rating_example():
    # Целевая оценка (0, 3) отсутствует в обучении.
    rows = [[5, 4, 1, None], [5, 4, 1, 5], [4, 5, 2, 4], [1, 2, 5, 1], [2, 1, 4, 2]]
    ratings = {(u, i): r for u, row in enumerate(rows) for i, r in enumerate(row) if r is not None}
    biases = fit_biases(ratings)
    users, items = residual_tables(ratings, biases)
    return {
        "base": baseline(biases, 0, 3),
        "user": predict_rating(0, 3, users, items, biases, 2, "user"),
        "item": predict_rating(0, 3, users, items, biases, 2, "item"),
    }


def mean(values):
    return math.fsum(values) / len(values)


def run():
    events, requests = generate()
    observed = snapshot(events, ORIGIN)
    history = profiles(observed)
    popular = popularity(observed)
    recent = decayed_popularity(observed, ORIGIN, half_life=120)
    graph_models = {
        name: item_graph(history.values(), metric, limit=20, min_count=2, shrink=4)
        for name, metric in [("cooccurrence", "count"), ("confidence", "confidence"),
                             ("lift", "lift"), ("item_knn", "cosine")]
    }
    user_index = fit_users(history)
    weighted_index = fit_users(history, inverse_frequency=True)
    rng = random.Random(831)
    metrics = {}
    paired = []
    exposed_pool = set()
    cold_items = set(CATALOG) - popular.keys()

    for u, _, candidates, grades in requests:
        seen = history.get(u, set())
        exposed_pool.update(candidates)
        evidence = {
            "popularity": popular,
            "time_decay": recent,
            **{name: item_scores(seen, graph) for name, graph in graph_models.items()},
            "user_knn": user_scores(seen, user_index, 20, exclude_user=u),
            "user_iuf": user_scores(seen, weighted_index, 20, exclude_user=u),
        }
        orders = {"random": random_list(candidates, K, rng)}
        orders.update({name: recommend(candidates, s, popular, K) for name, s in evidence.items()})
        for name, order in orders.items():
            values = ranking_metrics(order, grades, K)
            metrics.setdefault(name, []).append((bool(seen), order, values))
        base_ndcg = metrics["popularity"][-1][2]["ndcg"]
        item_ndcg = metrics["item_knn"][-1][2]["ndcg"]
        paired.append((u, item_ndcg - base_ndcg))

    models = {}
    for name, rows in metrics.items():
        lists = [order for _, order, _ in rows]
        models[name] = {
            "ndcg": mean([v["ndcg"] for _, _, v in rows]),
            "recall": mean([v["recall"] for _, _, v in rows]),
            "coverage": catalog_coverage(lists, exposed_pool),
            "warm_ndcg": mean([v["ndcg"] for known, _, v in rows if known]),
            "cold_ndcg": mean([v["ndcg"] for known, _, v in rows if not known]),
            "cold_slots": sum(i in cold_items for order in lists for i in order),
        }

    files = ("baselines.py", "associations.py", "users.py", "ratings.py", "experiment.py")
    root = Path(__file__).parent
    raw = [list([e.user, e.item, e.t, e.available] for e in events), requests]
    result = {
        "models": models,
        "sizes": {"events": len(events), "observed_events": len(observed),
                  "requests": len(requests), "warm_requests": len(history),
                  "cold_requests": len(requests) - len(history),
                  "cold_items": len(cold_items)},
        "item_vs_popularity": paired_bootstrap(paired, seed=8, draws=2000),
        "rating_example": rating_example(),
        "manifest": {"python": platform.python_version(), "seed": SEED, "origin": ORIGIN,
                     "time_unit": "tick", "k": K, "half_life": 120, "neighbors": 20,
                     "data_sha256": hashlib.sha256(json.dumps(raw, sort_keys=True).encode()).hexdigest(),
                     "source_sha256": {name: hashlib.sha256((root / name).read_bytes()).hexdigest()
                                       for name in files},
                     "evaluation_sha256": {name: hashlib.sha256(Path(module.__file__).read_bytes()).hexdigest()
                                           for name, module in evaluation_modules().items()}},
    }
    return result


def evaluation_modules():
    import comparison
    import ranking

    return {"ranking.py": ranking, "comparison.py": comparison}


if __name__ == "__main__":
    report = run()
    Path(__file__).with_name("report.json").write_text(
        json.dumps(report, ensure_ascii=False, indent=2, allow_nan=False) + "\n"
    )
    print(json.dumps({"sizes": report["sizes"], "models": report["models"],
                      "item_vs_popularity": report["item_vs_popularity"],
                      "rating_example": report["rating_example"]}, ensure_ascii=False, indent=2))

Для запуска сохраните в одной папке baselines.py, associations.py, users.py, ratings.py и experiment.py из этой части. Возьмите также ranking.py и comparison.py из главы о NDCG и главы о неопределённости. Модули используют стандартную библиотеку. Команда python3 experiment.py проверена на Python 3.13.3 и сохраняет report.json рядом со скриптом.

Генерация использует фиксированный seed, а случайная выдача имеет собственный генератор. Отчёт содержит размеры когорт, метрики, параметры и хеши данных и исходников. При изменении генератора, эпохи, версии runtime или таблицы связей эти сведения помогают локализовать причину расхождения. У каждой модели одинаковые запросы и знаменатели, поэтому сравнение не обусловлено различным размером области.

Упражнение · Равенство на холодном срезе

Почему item-kNN и popularity имеют одинаковую NDCG для 36 запросов без истории? Может ли это измениться при замене резервного правила?

Разбор

Из пустой истории item-kNN не накапливает весов. Все позиции заполняются тем же глобальным порядком, что у popularity, с теми же ограничениями. Если поменять резерв на time-decay, различие возникнет из fallback, и сравнение нужно так и интерпретировать.
