Сигналы и исторический срез

От журнала к профилю​

Зафиксируем время решения TTT и каталог Au,T\mathcal A_{u,T}Au,T​ из части 6. Историческое событие eee имеет пользователя ueu_eue​, объект iei_eie​, время действия tet_ete​ и время доступности aea_eae​. Для данной модели используем

HT={e:te<T, ae≤T}.\mathcal H_T=\{e:t_e<T,\ a_e\le T\}.HT​={e:te​<T, ae​≤T}.

Строгая граница действия отделяет обучение от самого запроса. Для события с запоздалой доставкой условие te<Tt_e<Tte​<T выполняется раньше условия ae≤Ta_e\le Tae​≤T. Остальные правила обработки повторов и полноты журнала задаются до построения признаков.

Для числа событий по объекту каждый канонический event учитывается отдельно. Для бинарного профиля пользователя Pu={ie:e∈HT,ue=u}P_u=\{i_e:e\in\mathcal H_T,u_e=u\}Pu​={ie​:e∈HT​,ue​=u} один объект учитывается единожды. Корзиной также может быть один заказ, сессия или неделя. Тогда повтор объекта внутри корзины даёт одну единицу, а тот же объект в другой корзине даёт новую. Эти агрегаты отвечают на разные вопросы.

Определение · Бинарная матрица профилей#

Пусть Xui=1{i∈Pu}X_{ui}=\mathbf1\{i\in P_u\}Xui​=1{i∈Pu​}. Единица означает наличие выбранного исторического сигнала. Ноль означает отсутствие такого сигнала в заданном окне наблюдения.

Ноль в XXX позволяет считать пересечения множеств. Чтобы использовать его как наблюдённый отрицательный ответ, нужен отдельный контракт показов и зрелых исходов. Для явных рейтингов храним ruir_{ui}rui​ только на маске Ω\OmegaΩ. Заполнение неизвестной оценки нулём сдвигает среднее и добавляет вымышленные совместные наблюдения. Соглашение о маске дано в части 2.

Исследование новых объектов​

В этой части сопоставим выдачи на одной области

Cu,T=Au,T∖Pu.C_{u,T}=\mathcal A_{u,T}\setminus P_u.Cu,T​=Au,T​∖Pu​.

Это договор о рекомендациях новых для пользователя объектов. Для повторной покупки или прослушивания такой фильтр может исключить именно целевое действие. В том случае те же методы обучают с другой единицей решения и разрешают повторы по её правилам. В офлайн-протоколе важно, чтобы положительные метки были определены в том же пространстве, где допускается выдача. Если часть позитивов оказалась вне области, их число сообщают отдельно и объясняют роль знаменателя.

По одинаковым score сортируем объекты по ID. Для всех сравниваемых моделей симметрично применяем региональные и временные ограничения, затем рассчитываем top-KKK. История может содержать недоступный сегодня объект и по-прежнему давать основание для поиска похожего доступного объекта.

Лемма · Неизменность замороженного среза#

Детерминированная функция HT\mathcal H_THT​ выдаёт одинаковую статистику при добавлении записей с te≥Tt_e\ge Tte​≥T или ae>Ta_e>Tae​>T.

Доказательство

Ни одна добавленная запись не удовлетворяет одновременно обоим предикатам. Входное множество остаётся тем же. Если меняется каталог в момент запроса, статистика истории сохраняется, но итоговая выдача может измениться по другому входу.

Упражнение · Три счётчика

У пользователя A было три просмотра товара 1. B один раз посмотрел товар 1, затем товар 2. Что получим для частоты товара 1, числа пользователей с товаром 1 и совместной поддержки пары (1,2)(1,2)(1,2)?

Разбор

Частота просмотренных событий равна 4. Бинарный товар 1 есть у двух пользователей. Пара появляется только в профиле B, её поддержка в абсолютных единицах равна 1.

Упражнение · Поздний сигнал

К моменту T=100T=100T=100 событие произошло в 95, а появилось в витрине в 101. Можно ли использовать его для обучения в 100 или для более поздней версии в 102?

Разбор

В первом срезе событие отсутствует. Второй удовлетворяет обоим предикатам. Дата последующего обучения не оправдывает изменение уже выпущенной версии модели 100.
