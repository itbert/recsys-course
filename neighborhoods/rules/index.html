Правила ассоциаций и Apriori

Вероятности на корзинах​

Выбираем одну из NNN исторических корзин равновероятно. Пусть AAA и BBB — непустые непересекающиеся множества объектов, nAn_AnA​ — число корзин, содержащих AAA. Правило A⇒BA\Rightarrow BA⇒B характеризуется тремя величинами:

supp⁡(A⇒B)=nA∪BN,conf⁡(A⇒B)=nA∪BnA,lift⁡(A⇒B)=NnA∪BnAnB.\operatorname{supp}(A\Rightarrow B)=\frac{n_{A\cup B}}{N},\qquad \operatorname{conf}(A\Rightarrow B)=\frac{n_{A\cup B}}{n_A},\qquad \operatorname{lift}(A\Rightarrow B)=\frac{Nn_{A\cup B}}{n_A n_B}.supp(A⇒B)=NnA∪B​​,conf(A⇒B)=nA​nA∪B​​,lift(A⇒B)=nA​nB​NnA∪B​​.

Последние две формулы требуют положительных знаменателей. Confidence оценивает вероятность совместно встретить BBB при условии AAA. Lift нормирует её на обычную вероятность BBB. Значение lift выше 1 означает положительную ассоциацию в выбранных корзинах. Оно ничего не говорит о причинности. Условие «в той же корзине» не кодирует порядок событий. Если задача прогнозирует следующий переход, нужно построить упорядоченные пары и выбрать допустимый горизонт.

В примере четырёх корзин из предыдущей главы conf⁡(A⇒B)=2/3\operatorname{conf}(A\Rightarrow B)=2/3conf(A⇒B)=2/3, conf⁡(B⇒A)=1\operatorname{conf}(B\Rightarrow A)=1conf(B⇒A)=1, а lift обоих направлений 4/34/34/3. У пары (C,D)(C,D)(C,D) всего одна совместная корзина, но lift равен 2. Фильтр по поддержке позволяет не сделать такое наблюдение ведущим правилом на всём каталоге.

Поиск наборов длиннее двух​

При III объектах число возможных непустых наборов равно 2I−12^I-12I−1. Apriori использует антимонотонность поддержки, чтобы исключить невозможные частые кандидаты. Алгоритм строит сначала одиночные наборы, затем соединяет отсортированные частые наборы уровня l−1l-1l−1 с общим префиксом длины l−2l-2l−2. Кандидат нового уровня допускается к подсчёту, только если каждое его подмножество длины l−1l-1l−1 было частым. Agrawal и Srikant, 1994

Лемма · Почему работает отсечение Apriori#

Если A⊆BA\subseteq BA⊆B, то nB≤nAn_B\le n_AnB​≤nA​. Если хотя бы одно подмножество кандидата имеет поддержку меньше порога, кандидат также ниже порога.

Доказательство

Каждая корзина, которая содержит BBB, содержит и AAA. Соответствующее множество корзин вложено в множество для AAA. Любой частый отсортированный набор длины lll можно получить соединением двух своих частых подмножеств, отличающихся последним элементом. Значит, при полном проходе по уровням никакой частый набор не теряется.

□

Из частого SSS порождаем правила A⇒S∖AA\Rightarrow S\setminus AA⇒S∖A для непустых собственных подмножеств AAA. Порог confidence применяется уже к правилам. Он не заменяет порог поддержки при генерации частых наборов. Снижение порога увеличивает число возможных кандидатов и может привести к экспоненциальному выводу. Альтернативный метод FP-growth сжимает транзакции в префиксное дерево и добывает наборы через условные базы шаблонов. Han, Pei и Yin, 2000

"""Подсчёт совместных появлений, Apriori и направленные соседи."""
from collections import Counter, defaultdict
from itertools import combinations
import math


def profiles(events):
    result = defaultdict(set)
    for e in events:
        result[e.user].add(e.item)
    return dict(result)


def cooccurrences(baskets):
    singles, pairs = Counter(), Counter()
    n = 0
    for basket in baskets:
        items = sorted(set(basket))
        n += 1
        singles.update(items)
        pairs.update(combinations(items, 2))
    return n, singles, pairs


def frequent_itemsets(baskets, min_count, max_size):
    """Учебный Apriori: соединяем только частые префиксы и проверяем подмножества."""
    if min_count < 1 or max_size < 1:
        raise ValueError("Требуются положительные min_count и max_size")
    rows = [set(b) for b in baskets]
    singletons = Counter((i,) for b in rows for i in b)
    previous = {s: count for s, count in singletons.items() if count >= min_count}
    result = dict(previous)
    for size in range(2, max_size + 1):
        candidates = []
        for a, b in combinations(sorted(previous), 2):
            if a[:-1] != b[:-1]:
                continue
            c = a + (b[-1],)
            if all(subset in previous for subset in combinations(c, size - 1)):
                candidates.append(c)
        previous = {}
        for c in candidates:
            items = set(c)
            count = sum(items <= row for row in rows)
            if count >= min_count:
                previous[c] = count
        result.update(previous)
        if not previous:
            break
    return result


def association_rules(frequent, n_baskets, min_confidence):
    if n_baskets <= 0 or not 0 <= min_confidence <= 1:
        raise ValueError("Проверьте число корзин и порог confidence")
    for both, joint in sorted(frequent.items()):
        for size in range(1, len(both)):
            for left in combinations(both, size):
                right = tuple(i for i in both if i not in left)
                confidence = joint / frequent[left]
                if confidence >= min_confidence:
                    yield (left, right, joint / n_baskets, confidence,
                           confidence / (frequent[right] / n_baskets))


def item_graph(baskets, metric="cosine", limit=20, min_count=2, shrink=4.0):
    """Дуги от объекта истории к объекту-кандидату."""
    if metric not in {"count", "cosine", "confidence", "lift"}:
        raise ValueError("Неизвестный вид сходства")
    if limit < 1 or min_count < 1 or not math.isfinite(shrink) or shrink < 0:
        raise ValueError("Проверьте размер окрестности, поддержку и shrinkage")
    n, singles, pairs = cooccurrences(baskets)
    graph = defaultdict(list)
    for (i, j), common in sorted(pairs.items()):
        if common < min_count:
            continue
        for source, target in [(i, j), (j, i)]:
            a, b = singles[source], singles[target]
            score = {
                "count": common,
                "cosine": common / math.sqrt(a * b),
                "confidence": common / a,
                "lift": common * n / (a * b),
            }[metric]
            graph[source].append((target, score * common / (common + shrink)))
    return {i: sorted(edges, key=lambda pair: (-pair[1], pair[0]))[:limit]
            for i, edges in graph.items()}


def item_scores(history, graph):
    result = defaultdict(float)
    for source in sorted(set(history)):
        for item, weight in graph.get(source, ()):
            result[item] += weight
    return dict(result)

frequent_itemsets хранит наборы отсортированными кортежами. Прямой подсчёт кандидата SSS проверяет включение в NNN корзин, примерно за O(N∣S∣)O(N|S|)O(N∣S∣) при хешированных множествах. В association_rules поддержки обеих сторон доступны, поскольку они являются подмножествами частого объединения. Код item_graph для ранжирования использует только правила с одной сущностью слева и справа и ограничивает число дуг. Например, при корзине из нескольких просмотренных объектов можно суммировать веса правил с совпавшим условием. Итоговый score обычно требует отдельной калибровки, чтобы трактоваться как вероятность.

Упражнение · Поддержка тройки

Набор {A,B,C}\{A,B,C\}{A,B,C} встречается в 2 из 10 заказов, {A,B}\{A,B\}{A,B} в 4, CCC в 5. Найдите три величины для {A,B}⇒{C}\{A,B\}\Rightarrow\{C\}{A,B}⇒{C}.

Разбор

Support 2/10=0,22/10=0{,}22/10=0,2, confidence 2/4=0,52/4=0{,}52/4=0,5, lift 0,5/(5/10)=10{,}5/(5/10)=10,5/(5/10)=1. При таком подсчёте условие A,BA,BA,B не повышает частоту C относительно общего уровня.

Упражнение · Одна отсутствующая пара

Минимум четыре корзины. Пары ABABAB и ACACAC частые, а BCBCBC встречается трижды. Сколько раз максимум может встретиться тройка?

Разбор

Не более трёх. Любая корзина с тройкой содержит BCBCBC. Apriori отсеет тройку до сканирования данных.
