Меры сходства и выбор координат

Множества и углы​

Для двух бинарных множеств с размерами a,ba,ba,b и пересечением nnn получаем

scos⁡=nab,sJ=na+b−n.s_{\cos}=\frac{n}{\sqrt{ab}},\qquad s_{\rm J}=\frac{n}{a+b-n}.scos​=ab​n​,sJ​=a+b−nn​.

Здесь косинус считается на всех координатах, где объект отсутствия имеет бинарный ноль. Для Jaccard знаменатель — размер объединения. При пустом знаменателе договоримся считать сходство нулевым, чтобы пустой профиль перешёл к fallback. Для непустых профилей значения неотрицательны и не превышают единицы.

Например, пользователь A выбрал 2 объекта, B выбрал 8, и оба объекта A входят в B. Косинус равен 2/16=0,52/\sqrt{16}=0{,}52/16​=0,5, Jaccard равен 2/8=0,252/8=0{,}252/8=0,25. Большое объединение ослабляет Jaccard сильнее. Коэффициент пересечения n/min⁡(a,b)=1n/\min(a,b)=1n/min(a,b)=1 выражает полное включение меньшего множества. Для направления «A к B» значение n/a=1n/a=1n/a=1, для «B к A» n/b=0,25n/b=0{,}25n/b=0,25. Выбор меры разрешает разные утверждения о близости.

Явные рейтинги и центрирование​

У рейтингов пустая координата неизвестна. При сравнении двух пользователей u,vu,vu,v вдоль общих объектов IuvI_{uv}Iuv​ можно вычислять корреляцию Пирсона:

suv=∑i∈Iuv(rui−rˉu∣uv)(rvi−rˉv∣uv)∑i∈Iuv(rui−rˉu∣uv)2∑i∈Iuv(rvi−rˉv∣uv)2.s_{uv}= \frac{\sum_{i\in I_{uv}}(r_{ui}-\bar r_{u|uv})(r_{vi}-\bar r_{v|uv})} {\sqrt{\sum_{i\in I_{uv}}(r_{ui}-\bar r_{u|uv})^2} \sqrt{\sum_{i\in I_{uv}}(r_{vi}-\bar r_{v|uv})^2}}.suv​=∑i∈Iuv​​(rui​−rˉu∣uv​)2​∑i∈Iuv​​(rvi​−rˉv∣uv​)2​∑i∈Iuv​​(rui​−rˉu∣uv​)(rvi​−rˉv∣uv​)​.

Средние здесь берутся по одному пересечению. Среднее по всему профилю может отличаться для разных подмножеств. Использование полных пользовательских средних в числителе и нормах даёт другую меру. Корреляция сохраняет свой знак и величину при положительном аффинном преобразовании отдельно каждого вектора. Она определена только при ненулевой дисперсии обоих векторов. Код при вырожденном случае возвращает 0 и полагается на fallback. Основы memory-based CF с корреляционными весами описаны в работе Бриза и соавторов. Breese, Heckerman и Kadie, 1998

Для item–item adjusted cosine перед сравнением столбцов вычитают среднюю оценку соответствующего пользователя. Затем на совокупности пользователей, оценивших оба объекта, берут косинус центрированных столбцов. Это устраняет аддитивный уровень пользователей. Pearson между объектами вычитал бы среднее каждого столбца по его общим наблюдениям. Выбор между ними задаёт разные допущения о шкале оценок. Sarwar и соавторы, 2001

Например, A оценил два целевых объекта на 5 и 3, его полное среднее равно 4. B поставил 3 и 1, его среднее равно 2. После вычитания уровней первые отклонения равны (1,1)(1,1)(1,1) по двум пользователям, вторые (−1,−1)(-1,-1)(−1,−1). Adjusted cosine равен −1. По исходным столбцам Pearson равен +1, поскольку оценки обоих объектов выше у A. В таком примере направления различаются из-за разных способов центрирования.

Лемма · Два совпавших наблюдения#

При двух общих оценках в каждой строке и ненулевых разностях Pearson равна +1+1+1 или −1-1−1 по знаку произведения двух разностей.

Доказательство

Вектор после центрирования имеет вид (d/2,−d/2)(d/2,-d/2)(d/2,−d/2), где ddd — разность двух оценок. Два таких вектора параллельны либо противоположно направлены. Косинус принимает соответствующее крайнее значение.

□

Поэтому значение 1 на двух объектах нельзя интерпретировать как надёжное совпадение вкусов. В примере слайдер изменяет коэффициент λ\lambdaλ в s′=s n/(n+λ)s'=s\,n/(n+\lambda)s′=sn/(n+λ). Формула и границы применимости разбираются в главе о поправках.

Упражнение · Положительно или отрицательно

На двух общих объектах пользователь A поставил (1,4)(1,4)(1,4), B — (5,3)(5,3)(5,3). Каков Pearson? Что произойдёт при равных оценках B?

Разбор

Разности противоположны, поэтому Pearson равен −1. Если оценки B одинаковы, центрированный вектор нулевой и корреляция не определена. Реализация помечает пару нулевым весом.

Упражнение · Пустые координаты

Оба пользователя оценили один общий объект на 5. У первого ещё есть оценка 1 на другом объекте, у второго оценка 1 на третьем. Почему результат Pearson зависит от заполнения пропусков?

Разбор

На одном общем объекте Pearson не определён. После заполнения нулями появляется трёхмерная пара числовых векторов, в которой пропуски считаются оценками 0. Корреляция такой пары относится к другой задаче.
