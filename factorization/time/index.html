"""Учебная фиксированная временная поправка к замороженному прогнозу."""
from collections import defaultdict


def fit_item_bins(records, cutoff, width, prior_weight):
    """records содержат (item, time, available, residual) из прошлого."""
    if width <= 0 or prior_weight <= 0:
        raise ValueError("Проверьте ширину интервала и регуляризацию")
    stats = defaultdict(lambda: [0.0, 0])
    for item, t, available, residual in records:
        if t < cutoff and available <= cutoff:
            stats[item, t // width][0] += residual
            stats[item, t // width][1] += 1
    return {key: total / (n + prior_weight) for key, (total, n) in stats.items()}


def correct(base, biases, item, time, width):
    return base + biases.get((item, time // width), 0.0)

fit_item_bins принимает готовые остатки. В честном сравнении их можно получить на следующем за обучением блоке калибровки, затем заморозить поправку ещё до отложенного теста. Включение поздних событий ограничено двумя временами. Код не переносит коэффициент прошлого интервала в неизвестный будущий. Для оценки полной модели со слагаемыми bu(t),pu(t),zu(t)b_u(t),p_u(t),z_u(t)bu​(t),pu​(t),zu​(t) потребовалось бы оптимизировать их параметры совместно и проверить временной контракт каждой компоненты.

Два способа использовать свежесть​

Умножение веса ошибки на затухающую функцию меняет важность строки, но предсказываемая функция может оставаться постоянной по времени. Временная компонента bu(t)b_u(t)bu​(t), напротив, явно меняет прогноз в зависимости от даты запроса. Обновление модели после прихода новых данных — третья операция. Разделяйте эти действия, чтобы понимать, какая часть дала эффект.

Упражнение · Та же база, другой день

Для двух остатков 1 и 2 в одном интервале, λ=1\lambda=1λ=1, какова поправка? Каков прогноз при базе 3 в неизвестном интервале?

Разбор

Поправка равна (1+2)/(2+1)=1(1+2)/(2+1)=1(1+2)/(2+1)=1. В новом интервале берётся 0, поэтому прогноз 3.

Упражнение · Доступная дата

Можно ли использовать день недели нового запроса и нельзя ли на этом основании обучить смещение будущего интервала?

Разбор

День недели известен заранее и допустим как признак. Смещение конкретного интервала требует исходов этого интервала либо явной модели переноса. Доступность номера интервала не означает доступность его меток.
