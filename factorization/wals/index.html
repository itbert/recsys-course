Implicit WALS и уверенность в наблюдениях

Предпочтение и вес​

Пусть nui≥0n_{ui}\ge0nui​≥0 — число доступных событий в обучении. Зададим бинарную цель aui=1{nui>0}a_{ui}=\mathbf1\{n_{ui}>0\}aui​=1{nui​>0} и вес cui=1+αnuic_{ui}=1+\alpha n_{ui}cui​=1+αnui​ при α≥0\alpha\ge0α≥0. WALS минимизирует

Jimp=∑u,icui(aui−pu⊤qi)2+λ(∑u∥pu∥2+∑i∥qi∥2).J_{\rm imp}=\sum_{u,i}c_{ui}(a_{ui}-p_u^\top q_i)^2+ \lambda\left(\sum_u\norm{p_u}^2+\sum_i\norm{q_i}^2\right).Jimp​=u,i∑​cui​(aui​−pu⊤​qi​)2+λ(u∑​∥pu​∥2+i∑​∥qi​∥2).

Цель для отсутствующих событий равна 0 с базовым весом 1. Ноль кодирует выбранное предположение о ненаблюдаемых парах. Реальные отказы от показа и положительно оценённые объекты без события в журнале неразличимы по этому входу. Один просмотр и десять просмотров дают одну и ту же цель 1 с разными весами. Score может выйти за [0,1][0,1][0,1]. Для вероятностной интерпретации потребовались бы свои наблюдения и калибровка.

Можно использовать насыщаемую функцию счётчика, например αlog⁡(1+nui/ε)\alpha\log(1+n_{ui}/\varepsilon)αlog(1+nui​/ε) вместо линейной добавки. В таком случае нужно объявить масштаб ε\varepsilonε и сохранить базовый вес. Конкретная форма веса меняет соотношение редких и тяжёлых наблюдений. Hu, Koren и Volinsky, 2008

Проверка цели​

При всех целях 0 сумма ошибок равна ∥PQ⊤∥F2=tr⁡((P⊤P)(Q⊤Q))\norm{PQ^\top}_F^2=\operatorname{tr}((P^\top P)(Q^\top Q))​PQ⊤​F2​=tr((P⊤P)(Q⊤Q)). Для каждой наблюдавшейся пары вычитаем её нулевую ошибку и добавляем cui(1−pu⊤qi)2c_{ui}(1-p_u^\top q_i)^2cui​(1−pu⊤​qi​)2. Это позволяет проверять монотонность проходов без хранения предсказаний по всем парам. Для больших матриц разумно вести и отдельный мониторинг удержанной когорты.

implicit.py
"""Implicit WALS. Нулевые пары учтены через матрицу Грама."""
from collections import Counter

import numpy as np


def count_lists(counts, users, items):
    user_rows = [[] for _ in range(users)]
    item_rows = [[] for _ in range(items)]
    for (u, i), n in sorted(counts.items()):
        if not (0 <= u < users and 0 <= i < items and np.isfinite(n) and n > 0):
            raise ValueError("Словарь содержит только положительные наблюдаемые счётчики")
        user_rows[u].append((i, n))
        item_rows[i].append((u, n))
    return user_rows, item_rows


def wals_system(observations, other, gram, alpha, regularization):
    normal = gram + regularization * np.eye(other.shape[1])
    right = np.zeros(other.shape[1])
    if observations:
        ids, values = zip(*observations)
        block = other[list(ids)]
        extra = alpha * np.asarray(values)
        normal += block.T @ (extra[:, None] * block)
        right = block.T @ (1 + extra)
    return normal, right


def wals_objective(counts, p, q, alpha, regularization):
    # sum_{u,i} (p_u^T q_i)^2 = trace((P^T P)(Q^T Q)).
    total = np.sum((p.T @ p) * (q.T @ q))
    for (u, i), n in counts.items():
        score = p[u] @ q[i]
        total += (1 + alpha * n) * (1 - score)**2 - score**2
    return total + regularization * (np.square(p).sum() + np.square(q).sum())


def fit_wals(counts, users, items, factors=6, sweeps=14, alpha=8, regularization=1, seed=12):
    if factors < 1 or sweeps < 1 or not np.isfinite(alpha) or alpha < 0 or regularization <= 0:
        raise ValueError("Проверьте параметры WALS")
    row, col = count_lists(counts, users, items)
    rng = np.random.default_rng(seed)
    p = rng.normal(0, .1, (users, factors))
    q = rng.normal(0, .1, (items, factors))
    p[[not r for r in row]] = 0
    q[[not c for c in col]] = 0
    losses = [wals_objective(counts, p, q, alpha, regularization)]
    for _ in range(sweeps):
        gram = q.T @ q
        for u, observations in enumerate(row):
            p[u] = np.linalg.solve(*wals_system(observations, q, gram, alpha, regularization))
        gram = p.T @ p
        for i, observations in enumerate(col):
            q[i] = np.linalg.solve(*wals_system(observations, p, gram, alpha, regularization))
        losses.append(wals_objective(counts, p, q, alpha, regularization))
    return p, q, losses


def event_counts(events):
    return Counter((event.user, event.item) for event in events)

count_lists хранит только положительные счётчики и строит две ориентации. wals_system возвращает матрицу и правую часть, так что одну строку легко проверить плотным вычислением. Отсутствие прежних событий означает нулевую правую часть. Для полностью холодного объекта или пользователя используется отдельный резерв выдачи.
