Лемма · Монотонность точных проходов ALS#

Последовательное точное обновление всех блоков одной стороны и затем другой не увеличивает общую цель JJJ.

Доказательство

На первом полуцикле прежние значения всех пользовательских блоков допустимы при той же объектной стороне. Минимум достигает не большей цели. На втором полуцикле аргумент симметричен. Тот же принцип действует при включении смещения в каждый обновляемый блок.

□

Это утверждение о значениях цели, а не о достижении глобального оптимума. Невыпуклость остаётся при одновременном изменении обеих сторон. Небольшое увеличение на уровне машинного округления возможно при сравнении вычисленных значений.

Стоимость и сравнение со SGD​

Для каждой пары формирование локальной матрицы Грама требует порядка f2f^2f2 операций, а плотное решение для блока — порядка f3f^3f3. Проход по обеим сторонам стоит O(∣Ω∣f2+(U+I)f3)O(|\Omega|f^2+(U+I)f^3)O(∣Ω∣f2+(U+I)f3), где для простоты f+1f+1f+1 обозначено тем же порядком fff. Данные обрабатываются по спискам наблюдений. ALS полезна, когда блоки можно решать независимо. SGD дешевле за строку и проще расширяется до нестандартных дифференцируемых потерь.

В отчёте сравниваются полные значения одной цели для обеих реализаций. Эпоха SGD и проход ALS выполняют разный объём работы. Сравнение по числу итераций помогает читать кривые, а сравнение по времени требует отдельного измерения.
