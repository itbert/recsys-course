SVD++ и представление из истории

Две роли обратной связи​

Рейтинг ruir_{ui}rui​ задаёт цель квадратичной ошибки. Наличие взаимодействия с объектом может быть дополнительным сигналом даже без звезды. Пусть N(u)N(u)N(u) — заранее известное множество исторических объектов. У SVD++ каждый объект jjj имеет отдельный вектор истории yjy_jyj​, а вектор прогноза пользователя принимает вид

au=pu+zu,zu=1∣N(u)∣∑j∈N(u)yj,r^ui=μ+bu+ci+qi⊤au.a_u=p_u+z_u,\qquad z_u=\frac{1}{\sqrt{|N(u)|}}\sum_{j\in N(u)}y_j,\qquad \widehat r_{ui}=\mu+b_u+c_i+q_i^\top a_u.au​=pu​+zu​,zu​=∣N(u)∣​1​j∈N(u)∑​yj​,rui​=μ+bu​+ci​+qi⊤​au​.

При пустом N(u)N(u)N(u) задаём zu=0z_u=0zu​=0. Вектор qiq_iqi​ описывает объект как цель прогнозирования, а yiy_iyi​ — как событие истории. Можно связать эти роли ограничением, но у исходного SVD++ параметры различаются. Название историческое. Обучается маскированная факторизация с историей, а не усечение сингулярного разложения. Koren, 2008

Почему квадратный корень​

Лемма · Масштаб суммы при независимых слагаемых#

Если y1,…,yny_1,\ldots,y_ny1​,…,yn​ независимы, центрированы и имеют одну ковариацию VVV, то ковариация n−1/2∑jyjn^{-1/2}\sum_j y_jn−1/2∑j​yj​ равна VVV.

Доказательство

Ковариация суммы независимых слагаемых равна nVnVnV. Домножение вектора на 1/n1/\sqrt n1/n​ домножает ковариацию на 1/n1/n1/n.

□

Обучаемые векторы реальной истории зависимы, поэтому вывод объясняет масштабирование при упрощающем допущении, а не обещает постоянную норму. Например, nnn одинаковых ненулевых векторов дадут сумму нормой n\sqrt nn​ раз больше одного.

Градиент и время истории​

При ошибке e=rui−r^uie=r_{ui}-\widehat r_{ui}e=rui​−rui​ направление уменьшения половины квадрата по yjy_jyj​ равно eqi/∣N(u)∣e q_i/\sqrt{|N(u)|}eqi​/∣N(u)∣​ для каждого j∈N(u)j\in N(u)j∈N(u). По qiq_iqi​ в той же точке берётся eaue a_ueau​. Регуляризация таких параметров распределяется по числу обучающих строк, в чьей истории встретился jjj. Этот подсчёт реализован в fit_sgd из главы SGD. При пустых историях обе реализации совпадают. Стоимость прямого обновления одной строки O(f(1+∣N(u)∣))O(f(1+|N(u)|))O(f(1+∣N(u)∣)). На больших данных используют группировку обновлений, кэширование или пакетную обработку, учитывая, какие параметры изменились внутри эпохи.

История должна быть доступна до решения. В исходной рейтинговой постановке в N(u)N(u)N(u) могут входить ID оценённых объектов без их значений. Для прогноза будущего нельзя строить такую историю из индексов всех последующих взаимодействий. В лаборатории сохранена отдельная последовательность ранних неявных событий, предшествующая всем обучающим рейтингам. При serving можно пересчитать zuz_uzu​ по актуальной допустимой истории и оставить параметры yjy_jyj​ замороженными. Для нового пользователя pu=0p_u=0pu​=0 и известные yjy_jyj​ могут дать полезный сигнал после первых действий.

Упражнение · Три объекта истории

Пусть f=1f=1f=1, pu=0,2p_u=0{,}2pu​=0,2, qi=2q_i=2qi​=2 и векторы истории 0,10{,}10,1, 0,30{,}30,3, −0,1-0{,}1−0,1. Каков факторный вклад в прогноз?

Разбор

Упражнение · Будущий объект в истории

Для оценки рейтинга в момент 100 история содержит взаимодействие из момента 105. Значение рейтинга из него удалено. Исчезла ли утечка?

Разбор

Нет. ID будущего взаимодействия ещё влияет на zuz_uzu​. Маска истории должна учитывать доступность события, даже если его числовая метка исключена.
