Байесовское усреднение и Gibbs sampling

Из вектора параметров в распределение прогнозов​

Для новой оценки среднее по апостериорному распределению имеет вид E[ruinew∣RΩ]=μ+bu+ci+E[pu⊤qi∣RΩ]\E[r_{ui}^{\rm new}\mid R_\Omega]=\mu+b_u+c_i+\E[p_u^\top q_i\mid R_\Omega]E[ruinew​∣RΩ​]=μ+bu​+ci​+E[pu⊤​qi​∣RΩ​]. Совместное ожидание произведения нельзя в общем случае заменить скалярным произведением маргинальных средних. Например, при одновременной смене знака факторов распределение без якоря может быть симметричным, так что оба средних близки к нулю, а среднее произведение вполне содержательно.

Лемма · Шум ответа и разброс латентного score#

При фиксированных смещениях и σ2\sigma^2σ2 дисперсия новой оценки условно на данных равна Var⁡(pu⊤qi∣RΩ)+σ2\operatorname{Var}(p_u^\top q_i\mid R_\Omega)+\sigma^2Var(pu⊤​qi​∣RΩ​)+σ2.

Доказательство

Условно на факторах остаётся гауссовская дисперсия σ2\sigma^2σ2. Закон полной дисперсии прибавляет дисперсию условного среднего, равную дисперсии латентного произведения.

Поэтому квантили латентного score и прогнозные квантили будущей звезды относятся к разным случайным величинам. Для моделирования будущей оценки в каждую сохранённую реализацию добавляют независимый шум и фиксированную базу.

Цепочка из условных распределений​

  1. При текущем QQQ для каждого пользователя вычисляем среднее и точность из предыдущей главы, затем генерируем новый pup_upu​.
  2. При новом PPP условно обновляем каждый qiq_iqi​.
  3. После нескольких разогревочных проходов сохраняем нужные произведения и усредняем их.

Если Λ=LL⊤\Lambda=LL^\topΛ=LL⊤ — разложение Холецкого точности, для z∼N(0,I)z\sim\mathcal N(0,I)z∼N(0,I) берём m+L−⊤zm+L^{-\top}zm+L−⊤z. Его ковариация равна L−⊤L−1=Λ−1L^{-\top}L^{-1}=\Lambda^{-1}L−⊤L−1=Λ−1. Так не требуется строить явную обратную матрицу. Блоковый Gibbs сохраняет совместное апостериорное распределение: каждый полуцикл берёт одну группу из её правильной условной плотности при фиксированной другой группе. Из этого свойства ещё не следует, что короткая цепочка уже хорошо описывает распределение.

probability.py
"""Гауссовский PMF с фиксированными гиперпараметрами и Gibbs sampling."""
import numpy as np

from explicit import observation_lists


def posterior_precision(design, target, noise_precision, prior_mean, prior_precision):
    precision = prior_precision + noise_precision * (design.T @ design)
    natural = prior_precision @ prior_mean + noise_precision * (design.T @ target)
    return np.linalg.solve(precision, natural), precision


def draw_normal(mean, precision, rng):
    # Если precision = L L^T, то L^{-T} z имеет ковариацию precision^{-1}.
    lower = np.linalg.cholesky(precision)
    return mean + np.linalg.solve(lower.T, rng.standard_normal(mean.size))


def gibbs_predictions(rows, users, items, pairs, factors=3, burn=100, draws=200,
                      noise_precision=4.0, prior_precision=1.0, seed=11):
    """rows содержат центрированные рейтинги. Возвращаются draws × len(pairs)."""
    if min(factors, draws) < 1 or burn < 0 or min(noise_precision, prior_precision) <= 0:
        raise ValueError("Проверьте размерность, число проходов и точности")
    pairs = list(pairs)
    rng = np.random.default_rng(seed)
    by_user, by_item = observation_lists(rows, users, items)
    q = rng.standard_normal((items, factors)) / np.sqrt(prior_precision)
    p = np.zeros((users, factors))
    zero, prior = np.zeros(factors), prior_precision * np.eye(factors)

    def update(block, observations, other):
        for j, entries in enumerate(observations):
            ids = [i for i, _ in entries]
            target = np.array([r for _, r in entries])
            mean, precision = posterior_precision(other[ids], target, noise_precision, zero, prior)
            block[j] = draw_normal(mean, precision, rng)

    samples = []
    for sweep in range(burn + draws):
        update(p, by_user, q)
        update(q, by_item, p)
        if sweep >= burn:
            samples.append([p[u] @ q[i] for u, i in pairs])
    return np.asarray(samples)

Код реализует Gibbs при фиксированных дисперсиях и нулевых приорных средних. Полная Bayesian PMF в работе авторов моделирует также параметры распределений факторов, включая приоры на средние и матрицы точности, и интегрирует гиперпараметры. Комбинация Normal–Wishart — совместный приор для среднего и точности многомерной нормали. Учебная версия фиксирует эти величины для прозрачного расчёта условного шага. Salakhutdinov и Mnih, 2008

Диагностика и вычисления​

Последовательные выборки зависимы. Положительный суммарный вклад автокорреляций уменьшает эффективное число независимых наблюдений. По нескольким цепочкам из разных стартов проверяют устойчивость именно прогнозов, а не совпадение знаков координат. Для вывода об интервалах полезно оценить эффективный объём, согласованность цепочек и калибровку на отложенных наблюдениях. Единственная короткая учебная цепочка демонстрирует расчёт, её квантили не гарантируют точного приближения.
