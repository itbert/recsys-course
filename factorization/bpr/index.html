BPR и парная логистическая потеря

Цель на разности score​

Для неявных данных строим тройки (u,i,j)(u,i,j)(u,i,j), где iii наблюдался, а jjj был допустимой альтернативой без выбранного события. Сравнение задаёт тренировочное предположение i≻uji\succ_u ji≻u​j. Журнал не сообщает, как пользователь отреагировал бы на показ jjj. В BPR-MF используем sui=ci+pu⊤qis_{ui}=c_i+p_u^\top q_isui​=ci​+pu⊤​qi​, Δ=sui−suj\Delta=s_{ui}-s_{uj}Δ=sui​−suj​. Постулируем P(i≻uj∣θ)=σ(Δ)\Prob(i\succ_u j\mid \theta)=\sigma(\Delta)P(i≻u​j∣θ)=σ(Δ), где σ(x)=1/(1+exp⁡(−x))\sigma(x)=1/(1+\exp(-x))σ(x)=1/(1+exp(−x)). BPR-Opt использует произведение парных вероятностей и приор параметров. На практике это даёт задачу с логистической потерей и штрафом. Rendle и соавторы, 2009

ℓ(Δ)=−log⁡σ(Δ)=log⁡(1+exp⁡(−Δ)),ℓ′(Δ)=−σ(−Δ).\ell(\Delta)=-\log\sigma(\Delta)=\log(1+\exp(-\Delta)),\qquad \ell'(\Delta)=-\sigma(-\Delta).ℓ(Δ)=−logσ(Δ)=log(1+exp(−Δ)),ℓ′(Δ)=−σ(−Δ).

Общее смещение запроса сокращается. Вероятность из этой парной модели относится к сравнению условно на допущениях. Она не является вероятностью клика. Парная потеря чувствительна ко всем семплируемым сравнениям, поэтому хорошее среднее не гарантирует высокий NDCG@5.

Шаг по тройке​

Пусть g=σ(−Δ)g=\sigma(-\Delta)g=σ(−Δ). В направлении уменьшения нештрафованной потери имеем g(qi−qj)g(q_i-q_j)g(qi​−qj​) по pup_upu​, gpug p_ugpu​ по qiq_iqi​ и −gpu-g p_u−gpu​ по qjq_jqj​. По ci,cjc_i,c_jci​,cj​ обновления получают сигналы +g,−g+g,-g+g,−g. Из каждого направления при L2 вычитается коэффициент, умноженный на старый параметр.

При Δ≥0\Delta\ge0Δ≥0 можно вычислять log⁡1p(exp⁡(−Δ))\log1p(\exp(-\Delta))log1p(exp(−Δ)). При Δ<0\Delta<0Δ<0 та же потеря равна −Δ+log⁡1p(exp⁡(Δ))-\Delta+\log1p(\exp(\Delta))−Δ+log1p(exp(Δ)).

Во втором случае вынесем exp⁡(−Δ)\exp(-\Delta)exp(−Δ) за скобку в 1+exp⁡(−Δ)1+\exp(-\Delta)1+exp(−Δ). Аргументы экспонент в обеих формулах неположительны. Это предотвращает переполнение для конечных больших margins.

Семплирование задаёт фактический риск​

Код выбирает пользователя равномерно среди тех, у кого есть и позитивы, и альтернативы. Затем выбирает один позитив и один элемент дополнения равномерно. Для пользователя с aaa позитивами и bbb альтернативами каждая его тройка имеет вероятность 1/(Uvalidab)1/(U_{\rm valid}ab)1/(Uvalid​ab). Равномерная выборка всех троек дала бы больший суммарный вес пользователю с большим ababab. Если менять распределение, меняются и градиенты в ожидании. При известных вероятностях и полной поддержке можно вводить веса для другого целевого риска. Это обсуждалось в части 6.

Hard negatives усиливают трудные сравнения, но могут чаще включать неизвестные позитивы и менять поддержку. Поздние объекты исключают из обучающего пула, а из допустимых альтернатив убирают известные позитивы по правилам временного среза. В реализации каталог фиксирован на всём обучающем интервале. Для изменяющегося каталога нужны множества альтернатив на момент события. Если задан одинаковый L2-штраф по блокам выбранной тройки, ожидаемый штраф взвешен частотой появления параметров. Такой режим и использован в коде.

pairwise.py
"""BPR-MF на тройках с известным режимом отбора."""
import math

import numpy as np


def loss_and_signal(delta):
    # Для loss=softplus(-delta) градиент по delta равен -signal.
    if delta >= 0:
        z = math.exp(-delta)
        return math.log1p(z), z / (1 + z)
    z = math.exp(delta)
    return -delta + math.log1p(z), 1 / (1 + z)


def bpr_step(p, q, bias, u, i, j, step, regularization):
    u_old, i_old, j_old = p[u].copy(), q[i].copy(), q[j].copy()
    difference = i_old - j_old
    margin = float(bias[i] - bias[j] + u_old @ difference)
    loss, signal = loss_and_signal(margin)
    p[u] += step * (signal * difference - regularization * u_old)
    q[i] += step * (signal * u_old - regularization * i_old)
    q[j] += step * (-signal * u_old - regularization * j_old)
    bias[i] += step * (signal - regularization * bias[i])
    bias[j] += step * (-signal - regularization * bias[j])
    return loss


def fit_bpr(positives, training_catalog, users, items, factors=6, epochs=16,
            updates=3000, step=.035, regularization=.025, seed=18):
    """Каталог фиксирован на обучающем интервале и общий для всех пользователей."""
    if min(factors, epochs, updates) < 1 or step <= 0 or regularization < 0:
        raise ValueError("Проверьте параметры BPR")
    catalog = set(training_catalog)
    if any(not 0 <= i < items for i in catalog):
        raise ValueError("Некорректный каталог обучения")
    samples = []
    for u, positive in sorted(positives.items()):
        if not 0 <= u < users or not positive <= catalog:
            raise ValueError("Некорректный положительный профиль")
        negative = catalog - positive
        if positive and negative:
            samples.append((u, sorted(positive), sorted(negative)))
    if not samples:
        raise ValueError("Нет пользователей с допустимыми тройками")
    rng = np.random.default_rng(seed)
    p = np.zeros((users, factors))
    q = np.zeros((items, factors))
    p[[u for u, _, _ in samples]] = rng.normal(0, .1, (len(samples), factors))
    q[sorted(catalog)] = rng.normal(0, .1, (len(catalog), factors))
    bias = np.zeros(items)
    online_loss = []
    for _ in range(epochs):
        total = 0.0
        for _ in range(updates):
            u, positive, negative = samples[rng.integers(len(samples))]
            i = positive[rng.integers(len(positive))]
            j = negative[rng.integers(len(negative))]
            total += bpr_step(p, q, bias, u, i, j, step, regularization)
        online_loss.append(total / updates)
    return p, q, bias, online_loss

Один шаг стоит O(f)O(f)O(f). Учебный sampler заранее материализует допустимые альтернативы для каждого пользователя. Для большого каталога это может потребовать почти UIUIUI памяти. Можно выбирать из общего допустимого списка и отклонять известные позитивы. При доле альтернатив b/Ib/Ib/I среднее число попыток равно I/bI/bI/b, поэтому для очень плотных историй нужен другой режим. Сравнивайте методы на одинаковом полном списке кандидатов, независимо от способа получения учебных троек.
